## 🏠 ANH Hello 首页

命令面板搜索 <strong>"Andrea Novel Helper: 打开 ANH Hello"</strong>，或从包管理器的"常用功能"进入。

ANH Hello 是一个全新的<strong>统一入口页面</strong>，解决"扩展功能很多但入口分散"的问题：

- **推荐扩展**：内置 22 款写作相关扩展推荐（拼写检查、主题、字体、Typst、Git 等），实时检测哪些已经安装，一键查看详情和安装。
- **Git 配置**：直接查看 Git 安装状态和版本，设置全局/本地 Git 用户名与邮箱，一键初始化仓库。
- **工作区管理**：快速创建新工作区、打开现有文件夹、追踪最近打开的 8 个工作区。
- **项目状态卡片**：一目了然地看到当前工作区是否已初始化——绿色表示就绪，黄色表示待补全，红色表示未初始化，悬停还可查看缺少哪些文件。
- **首次设置引导**：新用户第一次打开时会弹出引导弹窗，帮助确认"保持 Hello 可用"和"启动时自动显示"。
- **常见问题**：内置 FAQ 区域，解答命令面板入口、资源管理器、设置位置、工作区概念等新手问题。

## � 批量导出面板

命令面板搜索 <strong>"Andrea Novel Helper: 批量导出"</strong>，或从 Hello 首页的"批量导出"卡片进入。

全新的批量导出界面，让你一次性将多个章节文件导出为目标格式：

- **树形文件选择**：以与写作资源管理器完全一致的排序展示工作区中的 `.md` / `.txt` 文件，支持勾选文件或整个文件夹——勾选文件夹时会递归选中所有子目录和文件。
- **多格式导出**：支持 PDF、PNG、SVG、HTML 和纯文本（TXT）五种格式。选择纯文本时自动跳过 Typst 编译，直接提取文本内容。
- **保留目录结构**：默认开启，导出时在输出目录下自动创建子目录，保持原始文件的层级结构；关闭后所有文件平铺到输出目录根。
- **模板选择**：使用 Typst 格式导出时可选择渲染模板，纯文本模式下模板选择器自动灰掉。
- **状态持久化**：你的选择（展开的目录、勾选的文件、格式、输出目录）会在面板关闭后自动保存，下次打开时恢复。

## �📝 笔记侧边栏

命令面板搜索 <strong>"Andrea Novel Helper: 打开笔记侧边栏"</strong>。

全新的笔记管理视图，集成在活动栏中，提供三种笔记组织方式：

- **跟踪目录大纲**：直接镜像工作区 `novel-helper/` 下的目录结构，过滤掉内部数据和忽略路径。点击目录打开目录大纲编辑器，点击文件打开章节大纲——与你正在写的章节保持同步。
- **自由大纲**：独立的文件树，基于 `novel-helper/outline`（路径可配置）和自由笔记目录，适合存放不跟目录绑定的创意碎片。
- **每日计划**：基于 `novel-helper/dashboard/plan`，自动根据文件名日期、文件 Frontmatter 或修改时间按年月分组，让长期写作计划一目了然。

每个视图都支持创建、重命名、删除、刷新笔记，新建文件会自动写入 Markdown 模板并立即打开编辑器。

## 📦 格式扩展：TOML 角色库

角色库、敏感词库、词汇库现在支持 **TOML 格式**（`.toml`）：

- 包管理器可正确识别 `.toml` 角色文件并显示角色数量，新建文件时可直接选择 TOML 格式。
- 右键从选择的文本**创建角色、添加敏感词、添加词汇**时，文件列表和新建文件均支持 `.toml`。
- 使用 `[[roles]]` 数组表定义角色，结构清晰、语法严格，非常适合手工编辑。
- 完整兼容字段别名系统，中英文键名自动映射；保存时会按规范顺序输出字段。
- 文档中心已更新格式指南，说明 TOML 在角色管理中的使用方式。

如果你更喜欢 TOML 的简洁语法而不是 JSON5 的括号嵌套，现在可以无缝切换。

## 🤖 MCP 服务器大幅增强

AI 助手（VS Code Copilot、Claude Desktop 等）现在能做的事情更多了：

- **时间线管理**：AI 可以读取、保存和向 `.tjson5` 时间线文件追加事件，协助你管理故事时间轴。
- **关系文件管理**：AI 可以读写 `.rjson5` 关系文件，维护角色关系数据。
- **角色库结构一览**：AI 可以获取 `novel-helper` 目录的完整文件树，自动识别其中有多少角色文件、关系文件、时间线文件和 TOML 文件。
- **通用角色文件读写**：支持对 json5/ojson5/md/csv/toml 全格式的角色文件进行读取和单角色更新。
- **批注管理**：AI 可以修改批注状态、追加批注消息。
- **安全边界**：所有文件操作限制在 `novel-helper` 目录内，防止越界访问。

## 📊 Typst 导出与脚本扩展

Typst 导出现在支持<strong>渲染器切换</strong>：内置 Liquid 模板、外部 Typst CLI、或脚本注册的自定义渲染器。

脚本系统新增<strong>扩展能力</strong>：

- **纯文本处理器**：编写脚本自定义导出前的文本处理流程（如特殊格式转换）。
- **Typst 渲染器**：编写脚本接管 Typst 编译过程，实现自定义模板引擎。
- **Hook 机制**：在 Typst 渲染前后插入自定义逻辑，链式修改生成内容。

<strong>渲染器模板模式（templateMode）</strong> — 外部处理器注册时声明三种模式之一，导出时自动按声明处理：

- **`post-process`** — 先 Liquid 渲染模板，把渲染后的 Typst 内容传给处理器做后处理。适合在现有排版基础上微调。
- **`source`** — 把模板源文件（.liquid）的原始内容传给处理器，让处理器自行解析和渲染。适合实现完全不同的模板语法。
- **`none`** — 处理器完全自主，不需要任何模板输入。导出时会自动跳过模板选择步骤。

脚本运行器现在会自动检测脚本类型——是普通笔记、可执行脚本、扩展插件、纯文本处理器还是 Typst 渲染器——并在标签上显示对应标识，右键菜单也会根据类型显示合适的操作按钮。

## 📖 Patchouli 分页预览阅读器

命令面板搜索 <strong>"Andrea Novel Helper: 打开写作预览"</strong>，或在编辑 Markdown 时自动激活。

全新打造的 <strong>Patchouli 预览阅读器</strong>，内置自研 Patchouli.js 排版引擎，将你的小说章节像实体书一样排版展示：

- **分页阅读**：内容按页面自动分割，支持翻页导航（上一页/下一页/跳转页码），也可切换为传统滚动模式。
- **排版设置**：浮动控制面板支持调节字体大小、行距、页边距，选择主题色（亮色/暗色/跟随 VS Code），实时预览效果。
- **块级元素完整分割**：代码块、列表、引用等块级元素在分页时保持结构完整，不会被不当截断。
- **嵌入式设置面板**：预览侧边栏内嵌设置面板，无需弹窗即可调整所有预览参数。

## 🏷️ Obsidian 兼容：标签索引与角色追踪

新增完整的 <strong>Obsidian 风格标签和 Wiki 链接</strong>支持，让你在 VS Code 中获得类似 Obsidian 的知识管理体验：

- **标签高亮**：`#标签名` 在编辑器中获得语法高亮，通过 TextMate 语法注入实现，与 VS Code 主题完美融合。
- **标签资源管理器**：侧边栏新增标签树视图，自动索引工作区中所有 `#tag` 引用，按标签名分组显示，点击跳转到具体使用位置。
- **角色追踪视图**：展示角色在各文件中的引用关系——"谁提到了这个角色"和"这个角色提到了谁"，双向追踪帮助你理清人物关系网。
- **Wiki 链接**：支持 `[[文件名]]` 语法的语法高亮和解析。
- **标签索引后台构建**：标签索引在 Web Worker 中构建，不阻塞编辑器操作。
- **新配置项**：Obsidian 兼容功能的标签索引、.gitignore 遵循、.wcignore 遵循等开关均可在包管理器中直接控制。

## ✏️ JSON5 无损编辑

编辑角色文件、关系文件和时间线文件时，<strong>保存不再破坏你精心排好的格式</strong>：

- **保留原始风格**：缩进方式（Tab/空格）、注释内容、尾逗号、字段顺序——保存后和保存前一模一样。
- **精确字段更新**：只修改你实际改动的字段，其余内容原样保留，不再全量重排整个文件。
- **覆盖所有编辑器**：角色 JSON5 编辑器、关系 JSON5 编辑器、时间线 JSON5 编辑器、MCP 工具均支持无损写回。

## 🎭 全局角色面板增强

全局角色面板（搜索 <strong>"Andrea Novel Helper: 打开全局角色面板"</strong>）新增多项能力：

- **原始源文件编辑**：点击角色条目可直接在面板中查看和编辑其 JSON5/Markdown 源文件，支持实时保存。
- **Markdown 富文本渲染**：角色描述中的 Markdown 内容直接渲染为富文本显示，不再需要切换到编辑器查看格式化效果。
- **角色层级解析**：支持从角色文件的 Markdown 标题层级（`## 子角色`）和关系文件中推断父子关系，建立角色家族谱系。
- **角色血统追踪**：沿关系链推算角色的家族血统，帮助你维护复杂的世界观设定。

## 🎭 角色管理优化

- **Markdown 解析器增强**：更好地兼容旧文档结构（如 `#敏感词表 → ##分组标题 → ###详细条目`），标量字段自动跳过引用注释行，避免 `>` 开头的引用内容污染字段值。
- **UUID 管理器优化**：如果文件内容没有实际变化，跳过写盘和缓存刷新，减少不必要的磁盘操作；修复同一文件中多个角色时 UUID 字段更新位置错误的问题。
- **右键添加角色修复**：消除异步/同步遗留问题，角色创建后编辑器状态保持同步，高亮不再短暂丢失。
