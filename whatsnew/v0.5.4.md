## 📊 写作统计更实时

写作统计仪表盘的“全文”和“累计用时”现在会把当前正在编辑文件的实时会话叠加进去。

- 正在编辑时，仪表盘不再必须等待实时统计停止才刷新。
- 全文统计、累计用时、当前文件会话数据之间的显示更一致。
- 新增 `AndreaNovelHelper.timeStats.repairSummary` 命令，可从文件追踪数据库重建统计摘要，处理历史汇总异常。

## 🧭 设置向导不再误判完成

之前设置向导在首次提示时就会写入“已提示”状态。如果用户误关面板、Webview 没加载完或异常退出，下次也不会再弹。

v0.5.4 改为只有以下明确动作才会标记为已处理：

- 点击“暂不使用”
- 关闭向导
- 应用向导设置
- 保存向导设置

同时新增命令 `andrea.openSettingsWizard`，可以随时从命令面板打开设置向导。

## 🎭 角色树跳转更稳定

修复从角色树跳转 JSON5 可视化角色编辑器时的一个时序问题：

- 当用户先打开 Markdown 格式角色，再点击 JSON5 格式角色时，已打开但刚恢复可见的可视化编辑器可能还没有完成布局。
- 以前第一次跳转可能滚到错误卡片附近，第二次才正确。
- 现在跳转会等待目标卡片展开，并跨多个动画帧重试测量滚动容器，保证第一次也能定位到正确角色卡。

## 🍎 Intel Mac 本地构建

补充 macOS 虚拟机构建脚本，方便没有容器环境时直接在 macOS VM 中编译。

- 新增 `scripts/macos-vm-build.sh`
- 支持通过 pixi 准备构建环境
- 面向 `darwin-x64` / Intel Mac 构建链路
- 降低对 GitHub Actions 容器构建的依赖

## ✅ 建议升级

如果你正在使用写作统计仪表盘、图形化设置向导或 JSON5 角色可视化编辑器，建议升级到 v0.5.4。这个版本主要修复交互和数据一致性问题，不改变角色文件格式。
