## 🎭 包管理器、角色树与预览面板增强

### 包管理器视图增强

包管理器现在能**在角色承载文件下直接展示其定义的角色列表**：

- **文件+角色一体化**：`.md` / `.json5` / `.ojson5` 等角色文件旁显示角色数量，展开后列出该文件中的全部角色
- **拖放/复制过滤**：拖放、复制、剪切操作自动过滤掉角色层级节点，只操作文件系统节点，避免误操作
- **常用功能节点**：新增"常用功能"根节点，收纳项目初始化向导、项目设置、引用维护、外部资源、Copilot 文档释放、功能引导、文档中心等快捷入口
- **项目设置文件节点**：新增"项目设置文件"根节点，直接展示 `anhproject.md` 和 `project-config.json5` 的存在状态

### 角色树视图增强

角色层级视图（侧边栏"角色"面板）获得多项渲染能力升级：

- **SVG 图标支持**：角色数据含 `svg` 字段时，可渲染为节点图标（需开启设置）
- **角色名称着色**：开启后角色名旁显示颜色预览色块，颜色字段值也以色块展示
- **详情展开控制**：支持配置角色属性节点是否可展开、自动折行宽度等

### 预览面板角色类型着色

阅读器预览新增**角色类型多选开关**，可选择只对特定类型进行高亮：

- 只给**主角**着色？可以。
- 只给**主角+正则表达式**着色？也可以。
- 敏感词、词汇不想着色？关掉即可。

内置类型默认色：主角（金 `#FFD700`）、配角（淡蓝 `#ADD8E6`）、联动角色（淡绿 `#90EE90`）、正则表达式（橙 `#FFA500`）。

### 角色查询键系统（Lookup Key）

新增**多语言角色索引系统**，让角色可以用多种语言和拼写形式被检索：

- **查询键家族**：自动识别 `lookupKeys` / `searchKeys` / `queryKeys` / `keywords` / `检索键` / `索引键` 等字段
- **拼音自动生成**（`pinyin-pro`）：中文姓名 → 无调拼音（如"林克" → `lin ke` / `linke` / `lk`）
- **日文假名罗马字**（`wanakana` / `kuroshiro`）：日文假名/汉字 → Hepburn 罗马字
- **通用罗马字**（`transliteration`）：多语种文本转写
- **智能 LLM 转写**：本地 LLM 为韩文、日文难译姓名生成候选转写
- **扩展前缀**：自定义 `refkeys`、`tagkeys` 等字段，也被识别为查询键家族成员

> 以上自动生成选项默认关闭，需在设置中开启 `lookupKeys.autoGeneratePinyin` / `lookupKeys.autoGenerateRomanized`。

### 多段前缀匹配补全

针对中文等**无空格语言**的智能补全优化：

> 以前输入"愤怒的孙悟空"，系统只尝试用"空"匹配，导致无法补全。现在系统会从光标前提取最多 **8 个分词段**、最长 **48 个字符**的组合作为候选前缀，依次尝试"愤怒的孙悟空"→"的孙悟空"→"孙悟空"，找到最长有效匹配并正确替换整个前缀。

### 项目配置增强

`project-config.json5` 新增两项配置：

- **默认角色索引键**：新建角色时自动补齐指定空数组字段（如 `lookupKeys_jp`、`lookupKeys_en`）
- **扩展索引键前缀**：自定义前缀（如 `refkeys`、`tagkeys`）被系统识别为查询键家族成员

## 📊 文件追踪与写作统计可靠性升级

### 文件追踪全面异步化

核心 API 从同步阻塞改为异步，侧边栏和状态栏不再卡顿。

### SQLite 后端初始化保护

- 给予最多 **15 秒**初始化窗口，期间操作排队缓存
- 超时未就绪则**自动回退 JSON 分片存储**，扩展始终可用
- 就绪后自动 Drain 排队操作并导入旧数据

### 智能路径修复

新增 `AndreaNovelHelper.fileTracking.repairPathKeys` 命令，一键修复：

- Windows 大小写混乱
- 绝对/相对路径混用
- 同一路径映射到多个 UUID 的冲突
- 元数据丢失时从磁盘重新扫描重建

### 写作统计高性能数据层

为统计仪表板设计的**轻量摘要系统**：

- **项目级摘要**：总时长、今日统计、24小时热力图、日粒度历史
- **单文件索引**：每文件的 CPM、字符增减、活跃时间、最后活跃时间
- **秒开体验**：Dashboard 直接从摘要读取，无需遍历所有文件
- **增量更新**：单文件修改只更新该文件摘要，防抖重建避免频繁写盘

## 🖥️ UI / UX 全面升级

### 项目设置页面（Webview）

命令：`Andrea Novel Helper: 打开项目设置`

- 图形化编辑 `anhproject.md`（项目信息、作者、标签、封面图、UUID）
- 同时编辑 `project-config.json5`（资源路径、默认索引键、扩展前缀）
- 文件不存在时自动创建，存在时加载现有内容
- 支持直接打开底层文件手动编辑

### 图形化项目初始化向导

替代了原来纯命令行弹窗的向导，改为**单页 Webview 表单**：

- 一页内同时填写项目信息、Git 配置、文件结构、忽略规则
- 自动检测 Git 安装状态和用户名/邮箱
- 一键创建 `novel-helper/` 示例资源结构
- 自动配置 `.gitignore` 和 `.wcignore`

### 交互式功能引导

命令：`Andrea Novel Helper: 打开功能引导`

- 以卡片形式展示 ANH 各项核心功能
- 每个功能带直达按钮，点击即可执行对应命令
- 与文档中心互通，形成学习闭环

### 文档查看器系统

命令：`Andrea Novel Helper: 打开文档中心`

- 五大分类：入门、核心概念、角色与资源、写作辅助、高级功能
- 涵盖 20+ 个主题的详细说明
- 支持一键释放到 `novel-helper/docs/` 本地查阅

### 图形化快速设置

命令：`Andrea Novel Helper: 打开图形化快速设置`

- **六大分组**：换行与显示、段落排版、智能编辑、字数统计、状态栏、其他
- **实时预览**：调整字体大小时预览区实时变化，调整自动换行时模拟编辑器展示效果
- 支持全局/工作区作用域一键切换

### Markdown 样式与自定义主题

**预览面板增强**：

- 标题样式开关 + 对齐方式选择（左对齐/居中）
- 列表样式开关 + 呈现形式选择（传统列表/流式文本）
- TTS 朗读时自动跳过列表标记符号
- 行内样式渲染：**粗体**、*斜体*、~~删除线~~、`行内代码`
- 引用块、代码块独立样式
- 自定义阅读主题：背景色 + 前景色自由设置
