## 🔍 智能功能说明

### 补全 / 着色 / 跳转行为

| 资源 | 触发方式 | Hover | 跳转定义 | 备注 |
|------|----------|-------|----------|------|
| 角色 & 别名 | 文本输入前缀 | 展示类型/从属/描述/颜色 | 跳至源 JSON5 / Markdown | 别名合并补全池 |
| 敏感词 | 完整词匹配 | 警示 + 描述 | 定位 JSON5 / Markdown | 支持高亮诊断集合 |
| 词汇 | 前缀 | 描述 | 源位置 | 与角色独立，不着色冲突 |
| 正则 | 模式匹配 | 规则说明 | 规则定义 | 高亮任意结构文本 |
