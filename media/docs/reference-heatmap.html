引用维护与角色出场分析是什么

这是 ANH 的角色出场分析工具。它通过圆圈打包（Circle Packing）可视化展示每个角色在小说中的出场次数，并提供出场趋势图。同时提供引用索引的维护功能。

什么时候会用到

  • 长篇小说角色众多时，直观看出哪些角色戏份多、哪些戏份少
  • 检查各角色在不同章节的出场分布是否符合预期
  • 维护角色引用索引（重建索引、清理过期路径）

如何打开

  1. 按 Ctrl+Shift+P
  2. 输入"引用维护"或"角色热力图"
  3. 选择相应命令

怎么看

  • 圆圈越大，表示该角色在整个项目中出场总次数越多
  • 圆圈按角色类型（主角、配角、反派等）分组嵌套
  • 下方的折线图展示每个角色在各文件/章节中的出场次数变化趋势

功能概述

引用维护与角色出场分析包含两部分：角色出场的可视化分析，以及角色引用索引的维护。

角色出场可视化

使用 D3.js Circle Packing 布局（非传统热力图）展示角色出场数据：

  • 圆圈大小 — 表示角色在整个项目中的出场总次数（所有文件累加），不是单章节数据
  • 圆圈分组 — 按 role.type（如主角、配角、反派）分组嵌套显示
  • 颜色 — 由角色类型名称的哈希值决定，不表示出场频率
  • 出场趋势图 — 可视化下方的折线图（TimeSeriesChart）展示每个角色在各文件中的出场次数变化

筛选与设置

  • 过滤敏感词角色（默认隐藏）
  • 最小出场次数阈值（低于阈值的角色不显示）
  • 显示/隐藏出场趋势折线图
  • 图表高度、气泡间距、最小标签半径等可视化参数

引用索引系统

ANH 维护一个角色出场索引（RoleUsageStore），记录每个角色在每个文件中的出场位置（行列范围）和次数：

  • 索引构建 — RoleUsageIndexer 扫描工作区文件，使用 Aho-Corasick 算法匹配角色名、别名、修复词、查询键和正则模式
  • 持久化 — 索引存储在 VS Code workspace state 中，包含反向索引（角色→文件映射）
  • 编辑器集成 — 实现 VS Code ReferenceProvider 接口，右键角色名可查找所有引用位置

引用维护面板

AndreaNovelHelper.showReferenceMaintenance 打开 QuickPick 菜单，提供三项维护操作：

  • 清理数据库中的绝对路径 — 清除文件追踪中的过期绝对路径
  • 重建角色引用索引 — 从头扫描所有文件重建出场索引
  • 打开角色出场可视化 — 打开 Circle Packing 可视化面板

数据命令

  • AndreaNovelHelper.circlePacking.getCompleteDataset — 获取完整数据集
  • AndreaNovelHelper.circlePacking.getRoleReferenceData — 获取角色引用数据
  • AndreaNovelHelper.circlePacking.getFileTimelineData — 获取文件时间线数据
  • AndreaNovelHelper.circlePacking.exportToJson — 导出为 JSON
Circle Packing 可视化使用 Webview 渲染，数据由 circlePackingDataProvider 分批处理（每批 50 个文件）。出场总次数为 0 的角色会被排除在可视化之外。系统不提供"断裂引用检测"（未定义角色名匹配）或"孤立角色检测"（未出场角色查找）功能。
