大纲是什么

大纲是 ANH 提供的故事大纲编辑工具。你可以为每个章节文件或文件夹创建一份独立的大纲 Markdown 文件，用来写情节梗概、角色规划、章节笔记等内容。系统会同时打开两个大纲：

  • 上面：目录大纲 — 针对当前文件夹的大纲，适合写整个篇章/卷的总体规划
  • 下面：文件大纲 — 针对当前文件的大纲，适合写这一章的情节梗概、角色出场安排等

什么时候会用到

  • 写长篇小说时，提前规划每章的情节走向
  • 为每个文件夹（卷/篇）写整体构思和角色发展线索
  • 边写边记录灵感、待修改事项、伏笔埋设等

如何打开

有两种打开方式，可以在功能引导页的大纲卡片上找到对应按钮：

  • 打开双重大纲 — 在右侧分栏同时打开当前文件的目录大纲和文件大纲，上下排列。适合日常写作时同时查看章节规划和整体脉络
  • 选择大纲 — 弹出选择菜单，可以单独打开当前文件大纲、当前目录大纲，或浏览目录树选择任意文件/目录的大纲。适合只需要看某一个大纲的场景

也可以通过命令面板 Ctrl+Shift+P 输入"打开双重大纲"或"打开大纲"来触发。

这张图重点看：右侧上下两个面板分别是不同层级的大纲；标题里的“目录大纲 / 文件大纲”就是区分整体规划和当前章节规划的关键；它们本质上还是可编辑 Markdown，不是只读树。

大纲存在哪里

大纲文件是普通的 Markdown 文件，存储在项目的 novel-helper/outline/ 目录下。目录大纲命名为 文件夹名_dir_outline.md，文件大纲命名为 文件名_outline.md。首次打开时自动创建，内容只有标题模板，其余由你自己填写。

懒加载

大纲默认开启懒加载：只有当你打开大纲面板时才会加载内容，平时不占用资源。如果大纲内容没更新，可以用"刷新目录大纲"或"刷新文件大纲"命令手动刷新。

大纲系统概述

ANH 的大纲系统为小说创作提供配套的故事大纲编辑环境。它不是自动生成的文件树或标题导航——大纲文件是用户手动编写的 Markdown 文档，用于记录情节规划、章节梗概、角色线索等创作内容。

系统为当前打开的文件自动生成一对空的大纲模板文件（目录大纲 + 文件大纲），并通过虚拟文件系统和分栏视图提供便捷的编辑体验。

打开方式

  • 双重大纲：AndreaNovelHelper.openDoubleOutline — 在第二编辑组纵向拆分，同时打开当前文件的目录大纲和文件大纲
  • 大纲选择器：AndreaNovelHelper.openOutlinePicker — 弹出 QuickPick 菜单，可选择打开当前文件大纲、当前目录大纲，或交互式浏览目录树选择任意文件/目录的大纲
  • 重定向大纲：AndreaNovelHelper.redirectOutlineHere — 仅在 andrea-outline:// 文档激活时可用（右键菜单），将当前大纲标签切换到其他目标文件/目录的大纲

大纲文件创建与内容

大纲文件首次打开时由 ensureOutlineFileExists() 自动创建，内容仅为两行标题模板：

  • 目录大纲：# 📁目录大纲 + > 目录：{文件夹名}
  • 文件大纲：# 📄文件大纲 + > 文件：{文件名}

之后所有内容由用户手动编写。系统不会自动填充文件列表或标题层级——大纲文件就是普通的可编辑 Markdown。

自动跟随切换

当你在不同的小说文件之间切换时，大纲面板会自动更新为当前文件对应的大纲（不会覆盖已有内容）。触发时机：

  • 切换活动编辑器（onDidChangeActiveTextEditor）
  • 保存文件（onDidSaveTextDocument）
  • 1 秒轮询兜底检测活动文件变化
  • 当前活动文件本身是大纲文件时跳过（避免循环）

懒加载模式

默认开启（AndreaNovelHelper.outline.lazyMode）。大纲文件仅在编辑器可见时才加载，面板隐藏时暂停，重新可见时自动刷新。可手动调用 AndreaNovelHelper.refreshOutlineDir / AndreaNovelHelper.refreshOutlineFile 强制刷新。

存储与虚拟文件系统

大纲 .md 文件存储在 novel-helper/outline/ 目录下（可通过 AndreaNovelHelper.outlinePath 配置）。系统使用 MemoryOutlineFSProvider（基于 memfs 内存文件系统）提供 andrea-outline:// 虚拟文件方案，写入操作同时更新内存和磁盘。虚拟路径 /目录大纲.md 和 /文件大纲.md 映射到当前文件对应的大纲；/direct/ 路径支持访问任意大纲文件。

文件命名规则

  • 目录大纲：<文件夹名>_dir_outline.md（如 chapter1_dir_outline.md），根目录为 root_dir_outline.md
  • 文件大纲：<文件名>_outline.md（如 chapter1.md 对应 chapter1_outline.md）
大纲文件是用户编写的创作内容，不是自动生成的结构索引。系统仅提供空模板、虚拟文件系统编辑环境和自动跟随切换机制。outline/ 目录被排除在角色扫描和其他文件系统遍历之外。
