什么是项目初始化向导

项目初始化向导就像一个新建小说项目的问卷。你只需要回答几个问题，ANH 就会自动帮你创建好所有需要的文件和文件夹。不用手动一个个去创建。

什么时候会自动弹出

当你打开一个新的工作区（文件夹）并启用 ANH 后，如果 ANH 检测不到任何角色库、词汇表、敏感词库等描述文件，会自动弹窗询问："未检测到角色/词汇/敏感词等描述文件，是否运行项目初始化向导？"

你也可以随时通过命令面板手动打开：按 Ctrl+Shift+P → 输入"项目初始化向导"。

向导会帮你做什么

向导一共 8 步，每一步都很简单，有默认值，看不懂的直接跳过即可：

  1. 欢迎 — 告诉你这个向导能做什么
  2. 项目信息 — 填写小说名字、作者名字、简介
  3. 项目配置 — 默认即可，是关于文件识别的设置
  4. Git 账户 — 如果你用 Git 备份，填写用户名和邮箱（可选）
  5. Git 仓库 — 设置远程仓库地址（可选）
  6. 项目文件 — 自动创建文件夹和示例文件
  7. 确认 — 检查一遍，没问题就点完成
  8. 完成 — 可以直接打开功能引导页面开始探索

向导会创建什么

  • anhproject.md — 小说项目的"身份证"，里面有名字、作者等信息
  • project-config.json5 — 项目的功能配置表
  • novel-helper/ — 放所有角色、词汇、敏感词的文件夹
  • .gitignore — 告诉 Git 哪些文件不用备份
  • .wcignore — 告诉字数统计哪些文件不用统计

什么时候需要重新运行向导

通常只需要运行一次。如果你之前跳过了某些步骤（比如没设 Git），之后可以手动修改相关文件，不需要重新运行向导。

向导流程

初始化向导共 8 步，引导你完成从零到可写的项目搭建。每一步都有清晰的说明和默认值，你可以随时修改：

  • 欢迎 — 介绍向导功能和后续流程
  • 项目信息 — 填写项目名称、作者、描述。这些信息会写入 anhproject.md
  • 项目配置 — 设置默认写入目标（角色文件保存位置）、角色索引键、文件识别关键词。均有默认值，可直接跳过。此步骤还可配置「写作统计数据库是否纳入版本控制」
  • Git 账户 — 配置 Git 用户名和邮箱，用于自动提交的签名
  • Git 仓库 — 初始化本地仓库、设置远程地址（可选）
  • 项目文件 — 创建 novel-helper/ 目录结构、示例角色文件、.gitignore、.wcignore
  • 确认 — 检查所有配置项，确认无误后执行
  • 完成 — 可直接打开功能引导页面，开始探索 ANH

生成的文件

  • anhproject.md — 项目元数据，包含名称、作者、描述、UUID、封面、摘要、标签
  • project-config.json5 — 项目级配置，包含资源路径、索引键、文件关键词
  • novel-helper/ — 资源根目录，内含示例角色库和包结构
  • .gitignore — 自动排除写作过程中的临时文件和缓存
  • .wcignore — 排除 .vscode/ 和 .out-of-code-insights/ 等目录，避免字数统计误计入
向导执行的所有操作均可手动撤销或修改。如果你已有项目，也可以直接创建 anhproject.md 和 project-config.json5 来激活 ANH。
