字数统计看哪里

ANH 的字数统计主要有两个入口：底部状态栏显示当前正在写的文件，左侧 VS Code 资源管理器里的写作资源管理器（小说助手）显示整个工作区的文件和文件夹字数。

状态栏显示什么

  • 当前速度 — 你最近一段时间的输入速度，单位可以是 CPM（字/分钟）或 CPH（字/小时）
  • 累计用时 — 当前文件已经记录到的写作时间
  • 当前文件字数 — 默认按“词计”显示，即中文按字、英文按单词
  • 活跃状态 — 笔形表示正在写，睡眠标记表示已经闲置

把鼠标悬停在状态栏统计项上，可以看到中文字符、英文单词、含标点、不含标点、会话数、文件路径等详细信息。点击状态栏统计项会打开写作统计仪表板。

写作资源管理器

在 VS Code 左侧活动栏点击资源管理器图标，然后找到写作资源管理器（小说助手）。这里会显示工作区内支持统计的文件和文件夹，文件夹会自动汇总下级内容。

  • 展开文件夹 — 查看章节和子目录
  • 点击文件 — 打开该文件
  • 右键文件/文件夹 — 新建、重命名、删除、复制、剪切、粘贴、导出、强制重算
  • 拖拽 — 移动文件，或在手动排序模式下调整顺序

新建和整理章节

每个文件夹末尾都有两个快捷节点：+ 新建文章和+ 新建文件夹。也可以右键文件夹创建文章或文件夹。新建文章支持 Markdown 和 TXT。

哪些文件会统计

默认统计 Markdown、TXT、JSON5、CSV、OJSON5、RJSON5、TJSON5 等 ANH 支持的文本资源。图片、PDF、Office 文档、思维导图等可以显示为参考资料，但不会计入字数。

不想统计某些文件

在工作区根目录创建 .wcignore，写入要排除的路径或文件名。默认也会遵循 .gitignore。当 .wcignore 或 .gitignore 变化时，ANH 会自动刷新字数统计。

.wcignore 语法

.wcignore 使用与 .gitignore 相同的语法：

# 注释行
*.tmp
drafts/
secret-*.md
!important-draft.md    # 取消排除（取反）
**/temp/               # 递归匹配所有 temp 目录
chapter-*.md           # 通配符匹配
  • # 开头为注释
  • ! 开头为取反（取消排除）
  • * 通配符匹配任意字符
  • ** 递归匹配任意目录层级
  • 每行一个规则，空行会被忽略

Typst 导出字数

使用 Typst 模板导出时，字数统计信息会自动传递给模板。你可以在 Typst 模板中引用字数数据来显示统计信息。

  • 命令面板 → "ANH: 使用 Typst 模板导出" 或右键文件选择导出
  • 字数数据包含 CJK 字符数、英文单词数、总字数等
  • 可通过 AndreaNovelHelper.wordCount.exportTypst 命令导出

统计口径

ANH 内部统计多组数值，状态栏显示哪一组由配置决定：

  • excludePunct — 词计：中文 CJK 字符 + 英文单词，默认推荐
  • includePunct — 含标点：所有非空白字符
  • nonWSNoPunct — 不含标点：非空白且排除标点

显示格式由 AndreaNovelHelper.wordCount.displayFormat 控制，支持 raw、wan、k、qian。

写作资源管理器行为

  • 位置：注册在 VS Code 原生资源管理器视图组内，视图名是写作资源管理器（小说助手）
  • 目录聚合：文件夹节点显示下级文件的合计字数，目录聚合有内存缓存并在文件变化后增量刷新
  • 参考文件：AndreaNovelHelper.wordCount.referenceVisibleExtensions 中的扩展名只显示不计数
  • 资源目录标记：目录内存在 ANH 资源标记文件时，树节点会按资源目录提示
  • 自动定位：切换活动编辑器时，若字数视图可见，会尝试在树中定位当前文件

右键菜单

  • 新建：新建文章、新建文件夹、在当前节点上方/下方插入文章或文件夹
  • 打开：打开文件、Open With、在系统资源管理器中显示
  • 文件操作：重命名、删除、复制、剪切、粘贴
  • 排序：启用/关闭手动排序、按文件名生成索引、手动设置索引、清除索引、批量重建索引
  • 重算：强制重算当前节点或整个工作区，重扫目录内资源文件
  • 导出：复制纯文本、导出 TXT、使用 Typst 模板导出

手动排序

默认是自动排序。对文件夹启用手动排序后，可以拖拽调整同一父目录下的顺序。排序数据使用内部索引保存，不会改真实文件名；如果开启 AndreaNovelHelper.wordCount.order.showIndexInLabel，树节点前会显示连续序号。

缓存与性能

  • Worker 统计：文件字数通过后台 Worker 计算，避免阻塞编辑器
  • 持久化缓存：字数缓存写入文件追踪数据库，位置在 novel-helper/.anh-fsdb/
  • GitGuard：存在 Git 仓库时，会结合 Git 状态判断缓存可信度
  • 无 Git 仓库：启动后会强制刷新字数缓存，并提示建议执行 git init
  • 大文件估算：超过 AndreaNovelHelper.wordCount.largeFileThreshold 时先显示估算，再排队精确统计
  • 启动优化：skipStartupStatCheck 可以跳过启动校验，速度更快但风险更高；parallelStatCheck 控制并行校验

常用配置

  • AndreaNovelHelper.supportedFileTypes — 被 ANH 视为支持文本的语言/文件类型
  • AndreaNovelHelper.wordCount.primaryUnit — 状态栏首要字数单位
  • AndreaNovelHelper.wordCount.statusBar.mode — detailed、semi、compact
  • AndreaNovelHelper.wordCount.statusBar.speedUnit — cpm 或 cph
  • AndreaNovelHelper.wordCount.respectGitignore — 是否遵循 .gitignore
  • AndreaNovelHelper.wordCount.respectWcignore — 是否遵循 .wcignore
  • AndreaNovelHelper.wordCount.maxWorkers / maxWorkersUpperLimit — 后台统计并发控制
  • AndreaNovelHelper.wordCount.order.step / padWidth / autoResequence — 手动排序索引参数
字数统计负责“当前项目文本有多少”；写作时间统计负责“你什么时候写、写了多久、写作速度如何”。两者共享部分状态栏显示和内部文件追踪数据。
