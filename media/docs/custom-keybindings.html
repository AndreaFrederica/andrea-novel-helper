自定义快捷键是什么

ANH 提供了一些内置快捷键，你也可以通过 VS Code 的快捷键设置自定义它们。ANH 还提供了一个 Enter 键覆盖功能，确保在 Markdown 编辑器中按 Enter 时使用 ANH 的智能换行而不是其他扩展的。

内置快捷键

ANH 注册了以下命令，你可以在 VS Code 的快捷键设置中为它们分配按键：

  • andrea.smartEnter — 智能换行
  • andrea.toggleSmartExit — 切换智能跳出引号
  • andrea.formatDocument — 格式化文档
  • andrea.toggleAutoPairs — 切换自动配对
  • andrea.toggleSmartEnter — 切换智能换行
  • andrea.autoScroll.toggleMenu — 自动滚动菜单
  • andrea.quickSettings — 快速设置

怎么修改快捷键

  1. 打开命令面板输入"Preferences: Open Keyboard Shortcuts (JSON)"
  2. 在 keybindings.json 中添加规则
  3. 保存后立即生效

实现

快捷键管理由 src/keybindings/keybindingsIO.ts 和 src/keybindings/ensureEnterOverride.ts 实现。

Enter 键覆盖

ensureEnterOverride 功能会自动检测其他扩展（如 Markdown All in One）是否注册了 Enter 键绑定，并确保 ANH 的 andrea.smartEnter 具有更高优先级。这保证了在 Markdown 编辑器中按 Enter 时使用 ANH 的智能换行。

快捷键 I/O 工具

keybindingsIO.ts 提供了读写 keybindings.json 的工具函数：

  • readUserKeybindings() — 读取当前 Profile 的快捷键配置
  • writeUserKeybindings(doc, rules) — 写入快捷键配置
  • upsertRule(rules, rule) — 添加或更新规则
  • removeRule(rules, command, key?) — 移除规则

支持多 Profile

VS Code 支持多 Profile（如"写作"、"编程"），每个 Profile 有独立的 keybindings.json。ANH 的快捷键工具会自动识别当前 Profile 的配置文件路径。

JSONC 解析

keybindings.json 使用 JSONC 格式（支持注释和尾逗号）。ANH 使用 jsonc-parser 解析，确保兼容性。

示例：添加自定义 Enter 绑定

{
  "key": "enter",
  "command": "andrea.smartEnter",
  "when": "editorTextFocus && !suggestWidgetVisible && !inlineSuggestionVisible"
}

注意事项

  • 修改 keybindings.json 需要重启或重新加载窗口才能完全生效
  • ANH 的 Enter 覆盖只在 Markdown 和纯文本文件中生效
  • 如果其他扩展也注册了 Enter 键，可能会产生冲突。ANH 的覆盖机制会自动处理常见的冲突
