VS Code 最常用的几个区域

如果你以前没用过 VS Code，先记住这几个地方就够开始写作：

  • 活动栏 — 最左边一列图标，用来切换资源管理器、搜索、Git、扩展、ANH 等侧栏
  • 侧边栏 — 活动栏点开后的面板，例如文件列表、搜索结果、Git 改动列表
  • 编辑器 — 中间写正文的区域，可以同时打开多个标签页
  • 状态栏 — 最底部一条，显示编码、行列、Git 分支、ANH 字数/时间统计等信息
  • 命令面板 — 按 Ctrl+Shift+P 打开，几乎所有功能都能从这里搜索执行

资源管理器：管理文件

资源管理器就是 VS Code 的文件管理器。点击活动栏最上方的文件图标即可打开。

  • 打开项目：菜单选择“文件 → 打开文件夹”，打开你的小说项目根目录
  • 新建文件：在资源管理器里右键文件夹，选择“新建文件”
  • 新建文件夹：右键文件夹，选择“新建文件夹”
  • 重命名/删除：右键文件或文件夹，选择对应操作
  • 拖拽移动：把文件拖到另一个文件夹即可移动

ANH 还会在资源管理器里增加写作资源管理器（小说助手）和当前文章角色，前者看章节字数，后者看当前文章出现的角色。

搜索：找正文和设定

点击活动栏的放大镜，或按 Ctrl+Shift+F 打开全局搜索。

  • 普通搜索：输入角色名、地点名、章节标题，查所有文件
  • 区分大小写/全词匹配：搜索框右侧有开关
  • 正则搜索：点击 .* 开关后可以用正则表达式
  • 限定范围：在“要包含的文件”里写 docs/**/*.md 这类路径模式
  • 替换：展开替换框，可以批量替换；大批量替换前建议先提交 Git

Git 集成：保存版本

Git 是版本控制工具。它可以记录每次修改，方便回退、对比和同步。

  • 打开 Git 面板：点击活动栏的分支图标，名字通常是“源代码管理”
  • 查看改动：面板里会列出已修改、新增、删除的文件
  • 暂存：点击文件旁的 +，表示准备把这个文件放进下一次提交
  • 提交：在消息框写一句说明，例如“完成第一章初稿”，点击提交
  • 同步：有远程仓库时，可以推送和拉取远端改动

ANH 的项目初始化向导可以帮你检查 Git、设置用户名邮箱、创建初始提交。不了解 Git 时，至少养成“写完一段就提交一次”的习惯。

设置：改编辑器和 ANH 行为

设置有两种层级：

  • 用户设置 — 影响你电脑上所有 VS Code 项目
  • 工作区设置 — 只影响当前小说项目，适合写作格式、ANH 功能开关

打开方式：点击左下角齿轮 → 设置，或按 Ctrl+,。搜索框输入关键词，例如 word wrap、font size、AndreaNovelHelper。

推荐先改的设置

  • 自动换行：搜索 word wrap，开启后长段落不会横向滚动
  • 字体大小：搜索 font size
  • 迷你地图：搜索 minimap，写小说时可关闭
  • 自动保存：搜索 auto save，按习惯开启或关闭
  • 编码：中文写作推荐 UTF-8

资源管理器和 ANH 视图

VS Code 原生资源管理器显示真实文件系统；ANH 包管理器显示 novel-helper/ 资源包；写作资源管理器显示可统计的正文文件和参考资料。三者用途不同：

  • VS Code 资源管理器：项目所有文件，最通用
  • 写作资源管理器（小说助手）：章节、文件夹字数、排序、新建文章、导出
  • 包管理器：角色库、词汇表、敏感词、正则、关系图、时间线等设定资源

搜索细节

  • Ctrl+F — 当前文件内搜索
  • Ctrl+Shift+F — 全工作区搜索
  • Ctrl+H — 当前文件替换
  • 包含/排除：可以用 novel/**/*.md、!node_modules 这类 glob 模式
  • 搜索结果：点击结果会跳到对应文件和行；替换前可以逐个预览

Git 面板基础流程

  1. 确认左下角或状态栏显示当前分支，例如 main
  2. 写作或修改设定文件
  3. 打开“源代码管理”，检查改动文件列表
  4. 点击文件查看差异：左侧旧内容，右侧新内容
  5. 暂存需要提交的文件
  6. 输入提交说明并提交
  7. 需要同步到远端时再执行同步/推送

不要把 node_modules/、构建输出、临时文件提交进仓库。ANH 初始化向导会帮你写入常见 .gitignore 规则。

设置 JSON

设置页面右上角可以打开 JSON。常见位置：

  • 用户设置 JSON：全局生效
  • 工作区设置 JSON：当前项目的 .vscode/settings.json
  • ANH 项目设置：工作区根目录的 anhproject.md 和 project-config.json5

不熟悉 JSON 时，优先使用设置图形界面或 ANH 的项目设置页。手改 JSON 时注意逗号和引号。

ANH 快速设置

按 Ctrl+Alt+I 或从命令面板执行“ANH 快速设置”，可以直接修改常用写作选项：

  • 段间空行数、首行缩进、去尾空格
  • 智能引号、智能回车、跳出括号
  • Word Wrap、迷你地图、字体大小
  • 字数单位、粘贴统计、.wcignore 管理
  • 角色显示、里程碑提醒、错别字相关设置

常用快捷键

  • Ctrl+Shift+P — 命令面板
  • Ctrl+P — 快速打开文件
  • Ctrl+, — 设置
  • Ctrl+S — 保存
  • Ctrl+F / Ctrl+Shift+F — 文件内搜索 / 全局搜索
  • Ctrl+` — 终端
  • Ctrl+B — 显示/隐藏侧边栏
把 VS Code 当成“带版本管理和全文搜索的写作文件夹”即可。先会资源管理器、搜索、Git 提交、设置这四件事，再逐步使用 ANH 的包管理器、角色补全和统计功能。
