时间线是什么

时间线是用来记录小说中事件先后顺序的工具。你可以把它想象成一个"故事日历"，把重要事件按时间排列，还能把角色和地点关联到每个事件上。

什么时候会用到

  • 整理复杂的时间线（如穿越、轮回、多时间线）
  • 追踪角色在不同时间点的位置和行动
  • 确保事件顺序不出错

如何创建

  1. 在包管理器中右键目录节点
  2. 选择"创建时间线文件 (.tjson5)"
  3. 输入文件名，ANH 会自动生成模板

可视化编辑器

双击 .tjson5 文件会打开可视化编辑器：

  • 事件以卡片形式显示在时间轴上
  • 可以拖拽调整顺序和位置
  • 支持不同连线类型：正常顺序、闪回、梦境、平行世界等
  • 可以关联角色和地点

甘特视图

如果你更习惯按章节或阶段规划，可以打开时间线甘特图编辑器。它会把事件横向排列，适合查看剧情阶段、任务持续时间和多个线索之间的重叠关系。

  • 把事件当作可规划的条目查看
  • 适合安排章节推进、伏笔回收和长期任务
  • 可以在创作工作台中作为组件使用

时间格式很自由

不需要用真实日期，可以用任何你喜欢的时间体系：

  • "第一章"、"第二章"
  • "2024年春"
  • "第三纪元"
  • "早/中/晚"

时间线文件格式（.tjson5）

时间线文件使用 .tjson5 扩展名，采用 JSON5 格式定义故事中的事件序列。支持注释、尾随逗号等 JSON5 特性。

根结构：

{
  events: [],      // 事件数组
  connections: []  // 事件连接数组
}

事件（event）字段：

  • id — 事件唯一标识（必填）
  • title — 事件名称（必填）
  • description — 事件描述
  • date — 发生时间，支持任意自定义时间体系（如"第一章"、"2024年春"、"第三纪元"）
  • endDate — 结束时间，支持时间区间事件
  • timeless — 布尔值，标记为无时间事件
  • type — 事件类型：main（主线）或 side（支线）
  • data.type — 详细类型：如 condition（条件/状态节点）
  • color — 事件节点颜色
  • position — 布局坐标 { x, y }
  • width / height — 节点尺寸
  • parentNode — 父节点 id，支持嵌套事件
  • extent — 嵌套范围
  • expandParent — 是否扩展父节点
  • bindings — 绑定数组，统一存放角色、地点、物品等关联：
    • uuid — 绑定对象标识
    • type — 绑定类型：character（角色）、location（地点）、item（物品）、article（文章）、other
    • label — 显示标签
    • status — 状态
    • documentTitle — 关联文档标题

连接（connection）字段：

  • source — 起始事件 id（必填）
  • target — 目标事件 id（必填）
  • connectionType — 连接类型：
    • normal — 正常顺序
    • time-travel — 时间穿越
    • reincarnation — 转世/轮回
    • parallel — 平行世界
    • dream — 梦境
    • flashback — 闪回
    • other — 其他
  • sourceHandle / targetHandle — 条件节点手柄 ID（如条件节点的 'true'/'false' 输出）

时间线甘特图编辑器

时间线甘特图编辑器是 .tjson5 的另一种视图，适合从“计划排布”角度编辑事件。与普通时间线画布相比，它更关注时间跨度、顺序和阶段关系。

  • 横向计划 — 事件按时间轴或排序字段横向展开
  • 任务化管理 — 适合把剧情事件当作章节任务、修改任务或阶段目标管理
  • 工作台集成 — 甘特组件可嵌入创作工作台，和任务列表、年度计划、计时器一起使用
  • 同步/保存拆分 — 编辑器内部区分状态同步和文件保存，减少多个视图同时打开时互相覆盖

完整示例：

{
  events: [
    {
      id: "event1",
      title: "幻想乡建立",
      date: "1885年",
      description: "博丽大结界建立，幻想乡与外界隔绝。",
      type: "main",
      bindings: [
        { uuid: "reimu", type: "character", label: "博丽灵梦" },
        { uuid: "hakurei", type: "location", label: "博丽神社" }
      ]
    },
    {
      id: "event2",
      title: "第一次异变",
      date: "春",
      type: "side"
    }
  ],
  connections: [
    { source: "event1", target: "event2", connectionType: "normal" }
  ]
}

GUI 编辑器

ANH 为时间线文件提供了可视化编辑器（TimelineJson5EditorProvider）：

  • 时间轴布局 — 事件按时间顺序排列在时间轴上，支持水平/垂直切换
  • 事件卡片 — 每个事件以卡片形式展示，包含标题、时间、描述
  • 连接可视化 — 不同连接类型使用不同样式（实线/虚线/曲线/颜色）
  • 拖拽编辑 — 支持拖动事件调整顺序和位置，拖拽创建连接
  • 条件节点 — 支持条件分支，通过 sourceHandle/targetHandle 连接 true/false 分支
  • 嵌套事件 — 通过 parentNode 实现事件层级嵌套
  • 绑定管理 — 在编辑器中直接关联角色、地点、物品
  • 自动保存 — 布局变更自动写回 .tjson5 文件

打开方式：双击 .tjson5 文件即可打开可视化时间线编辑器。

创建时间线文件

在包管理器中右键目录节点 → "创建时间线文件 (.tjson5)"，输入文件名即可生成带模板的 .tjson5 文件。

时间线支持完全自定义的时间体系，不要求使用真实日期。事件使用 title 而非 name，时间使用 date 而非 time。角色和地点统一放在 bindings 数组中，通过 type 区分。
