批注管理器是什么

批注管理器用于集中查看和处理小说中的批注。它适合管理伏笔、修改意见、审稿反馈、待补资料和临时想法。

什么时候会用到

  • 章节里散落了很多 TODO 和修改意见，需要集中清理
  • 想快速跳回某条批注所在的原文位置
  • 需要区分开放批注和已解决批注
  • 审稿或自改时，需要逐条处理反馈

基本用法

  1. 打开批注管理器视图
  2. 在列表中选择批注线程
  3. 点击跳转回原文位置
  4. 处理完成后标记为解决或继续回复

数据模型

批注以线程为单位存储。每个线程包含所在文档、锚点位置、正文片段、回复列表、解决状态和更新时间。这样即使批注有多轮回复，也可以作为一个整体管理。

锚点与跳转

  • 批注会记录文档 UUID 和位置锚点，用于在文件移动或重命名后尽量保持关联
  • 管理器跳转时会打开目标文档并定位到对应段落或范围
  • 如果原文发生大幅改写，可能需要人工重新绑定批注位置

和编辑器内批注的关系

编辑器内批注用于就地查看和编辑；批注管理器用于跨文件汇总和批量处理。两者读写同一套批注数据。

适合的工作流

  • 写作中：在正文里添加“这里还要补伏笔”的批注
  • 修改时：打开批注管理器，按文件或状态逐条处理
  • 审稿后：把外部反馈录入为批注，统一跟踪解决进度
批注管理器不会替代正文注释语法。正文注释适合不需要线程和状态的小备注；批注适合需要跳转、回复和解决状态的修改任务。
