角色关系图谱是什么

角色关系图谱是面向整个角色库的Obsidian 风格网络图。它会把角色作为节点，把引用和关系作为连线，帮助你查看人物之间的应用关系。

它和 .rjson5 关系图有什么区别

  • .rjson5 关系图：编辑一张具体的关系表，适合手工画“人物关系图”。
  • 角色关系图谱：聚合整个角色库和关系表，适合查看“所有角色之间实际形成了什么网络”。

从哪里打开

  • 在包管理器顶部展开常用功能，点击 + 角色关系图谱
  • 在命令面板搜索“角色关系图谱”

图上显示什么

  • 节点 — 角色库中的角色
  • 连线 — 角色引用、角色文件内标记关系、关系表关系
  • 节点大小 — 连接数越多，节点越大
  • 颜色 — 根据角色类型或角色颜色显示

数据来源

第一版图谱只读取合法包目录内的资源，避免把正文共现误当作关系。边来源包括：

  • 角色内引用 — 一个角色文件内容中提到另一个角色，记为一次引用边
  • relations 标记 — 角色对象中的 relations 或 relationships 字段
  • 关系表 — 已加载的 .rjson5 / .json5 关系数据

角色文件中的关系标记

角色可以用 relations 或 relationships 显式标注关系。支持数组或对象写法：

{
  name: "安德莉亚",
  type: "主角",
  relations: [
    { target: "雪奈", type: "同伴", label: "旅行同伴", strength: 3, directed: false },
    { targetUuid: "role-uuid-001", type: "导师", directed: true }
  ]
}

对象写法会把 key 当作目标：

{
  name: "雪奈",
  relationships: {
    "安德莉亚": { type: "同伴", label: "共同旅行" }
  }
}

布局策略

  • 力导向 — 适合默认探索，节点会根据关系自然展开
  • 环形 — 适合查看全体角色分布
  • 中心层级 — 高连接角色靠近中心
  • 按类型分组 — 根据角色类型或阵营分带展示
  • 选中角色放射 — 以选中角色为中心展示一跳和二跳关系

显示策略

  • 显示孤立角色 — 控制没有连线的角色是否显示
  • 悬停高亮邻居 — 鼠标悬停时突出一跳节点和连线，可单独关闭
  • 选中角色后只显示一跳网络 — 适合在大型图中聚焦某个角色
  • 连线显示 — 可选全部、只显示高亮、只看选中角色、隐藏自动引用边或智能聚焦
  • 显示关系标签 — 在连线上显示关系类型，图很密时建议关闭

角色 Hover 卡片

角色 Hover 卡片参考正文 Monaco Hover 的渲染方式，显示角色名称、描述、类型、从属、别名、修复、包路径、源文件、扩展字段、颜色和一级关系。它可以单独开关，也可以设置是否跟随鼠标。

如果 Hover 内容很长，可以设置滚动捕获快捷键。默认是 Ctrl + 滚轮 滚动卡片，不会影响图谱缩放；也可以改为 Alt、Shift、Command/Win、直接滚轮或关闭捕获。

选中角色与关系元数据

点击角色后，左侧面板会显示该角色的一跳关系。点击关系卡片可以查看来源、类型、权重、方向、字段命中、来源文件等元数据。

.rjson5 关系文件格式

关系表使用 .rjson5 或 *relationship*.json5 扩展名。双击会打开关系图编辑器。

{
  // 关系节点（角色）
  nodes: [
    { id: "reimu", label: "博丽灵梦", type: "character", color: "#e94152" },
    { id: "marisa", label: "雾雨魔理沙", type: "character", color: "#FFD700" }
  ],
  // 关系连线
  edges: [
    {
      source: "reimu",
      target: "marisa",
      label: "朋友",
      type: "friendship",
      strength: 3,       // 关系强度 1-5
      directed: false     // 是否有向
    }
  ]
}

关系节点字段

  • id — 节点唯一标识（必填）
  • label — 显示名称（必填）
  • type — 节点类型：character（角色）、location（地点）、item（物品）
  • color — 节点颜色
  • position — 布局坐标 { x, y }

关系连线字段

  • source — 起始节点 id（必填）
  • target — 目标节点 id（必填）
  • label — 连线标签（如"朋友"、"敌人"）
  • type — 关系类型：friendship、enemy、family、romantic、other
  • strength — 关系强度，1-5（影响连线粗细）
  • directed — 是否有向（默认 false）
角色关系图谱主要用于观察关系网络，不直接修改角色文件或关系表。需要编辑单张关系图时，请打开对应的 .rjson5 文件。
