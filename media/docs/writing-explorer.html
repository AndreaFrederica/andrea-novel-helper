写作资源管理器是什么

ANH 在 VS Code 的侧边栏和资源管理器中添加了几个专用面板，帮你更方便地管理写作资源：

  • 当前文章角色 — 在资源管理器侧栏显示当前文档中出现的角色信息
  • 写作资源管理器 — 在资源管理器侧栏显示项目文件的字数统计、文件管理和导出功能
  • 所有角色 — 在 ANH 侧栏显示项目中所有已定义的角色

当前文章角色

在 VS Code 左侧资源管理器面板中，你会看到一个"当前文章角色"区域。它显示当前打开的 Markdown 文件中出现的所有角色：

  • 按所属（组织/阵营）分组
  • 每个所属下按角色类型（主角、配角等）分组
  • 角色类型顺序可自定义，例如让“主角”固定显示在“配角”上方
  • 点击角色可以跳转到角色的定义文件
  • 展开角色可以看到详细信息（描述、别名、颜色等）

写作资源管理器

在资源管理器侧栏中，"写作资源管理器"面板显示项目中所有文件夹和文件的字数统计和文件管理功能：

  • 文件夹显示总字数，文件显示各自字数
  • 支持手动排序和自动排序
  • 右键文件可以复制纯文本、导出 TXT、Typst 导出
  • 右键文件夹可以新建章节

所有角色

在 ANH 侧栏（点击活动栏的 ANH 图标）中，"所有角色"面板显示项目中所有已定义的角色：

  • 按类型分组：主角、配角、联动角色、词汇、敏感词、正则表达式
  • 点击角色跳转到定义文件
  • 展开角色查看详细信息

如何找到这些面板

  1. 当前文章角色和写作资源管理器：点击 VS Code 左侧资源管理器图标（文件图标），在侧栏底部找到
  2. 所有角色：点击 ANH 图标（活动栏中的 ANH 图标），在侧栏中找到

一、当前文章角色视图

视图 ID：docRolesExplorerView，注册在 VS Code 资源管理器面板中。

节点层级：

  • 所属节点（顶层）— 按角色的 affiliation/package 分组
  • 类型节点（二级）— 按角色类型分组（主角、配角等）
  • 角色节点（三级）— 单个角色
  • 详情节点（四级）— 角色的每个属性（key/value 对）
  • 详情行节点（五级）— 长文本内容的换行显示

特殊分组："词汇 / 敏感词 / 正则表达式"会聚合所有相关类型的跨所属角色。

当第一级或第二级分组实际代表角色类型时，排序会读取 AndreaNovelHelper.docRoles.typeOrder。当该层级代表从属/阵营时，仍按中文自然顺序排序，避免类型排序误影响从属分组。

功能：

  • 点击角色 → 运行 AndreaNovelHelper.openDocRoleDefinition，跳转到角色定义文件
  • 支持自定义 SVG 图标（配置 docRoles.display.useRoleSvgIfPresent）
  • 支持角色名颜色化图标（配置 docRoles.display.colorizeRoleName）
  • 颜色字段显示色块图标（配置 docRoles.details.showColorOnValue）
  • 每个文档独立保存展开状态（配置 docRoles.inheritExpandedFromPrevious 控制切换文档时是否继承）

配置项：

  • docRoles.useCustomGroups — 自定义分组模式
  • docRoles.typeOrder — 角色类型显示顺序
  • docRoles.display.useRoleSvgIfPresent — 使用角色 SVG 图标
  • docRoles.display.colorizeRoleName — 角色名颜色化
  • docRoles.inheritExpandedFromPrevious — 切换文档时继承展开状态
  • roles.details.enableRoleExpansion — 允许展开角色详情
  • roles.details.alwaysExpandable — 始终显示展开按钮
  • roles.details.wrapColumn — 详情文本换行宽度

二、写作资源管理器视图

视图 ID：wordCountExplorer，显示名称"写作资源管理器（小说助手）"，注册在 VS Code 资源管理器面板中。

功能：

  • 树形显示项目文件夹和文件的字数
  • 支持手动排序（拖拽调整顺序）
  • 支持复制/剪切/粘贴文件（内部剪贴板，非系统剪贴板）
  • 右键菜单：复制纯文本、导出 TXT、Typst 导出、新建章节等
  • 点击文件跳转到编辑器

文件操作命令：

  • AndreaNovelHelper.wordCount.copy — 复制文件
  • AndreaNovelHelper.wordCount.cut — 剪切文件
  • AndreaNovelHelper.wordCount.paste — 粘贴文件（自动处理重名）
  • WordCount.copyPlainText — 复制文件纯文本到剪贴板
  • WordCount.exportTxt — 导出为 TXT 文件
  • AndreaNovelHelper.wordCount.exportTypst — Typst 批量导出

三、所有角色视图

视图 ID：docRolesView，注册在 ANH 自定义侧栏面板中（活动栏 ANH 图标）。

与"当前文章角色"功能基本相同，但显示的是项目中所有已定义的角色（不限于当前文档）。它可以同步 docRoles.* 设置，也可以关闭同步后使用 AndreaNovelHelper.allRoles.* 独立配置，包括 allRoles.typeOrder。

四、与 VS Code 原生功能的关系

  • 资源管理器：ANH 的"当前文章角色"和"写作资源管理器"面板嵌入在 VS Code 原生资源管理器侧栏中
  • 搜索：ANH 的引用维护功能可以替代部分搜索需求（查找角色在哪些文件中被引用）
  • 源代码管理：ANH 的 Git 集成会与 VS Code 原生的源代码管理面板协同工作
如果你看不到"当前文章角色"或"写作资源管理器"面板，可能是因为资源管理器侧栏被折叠了。点击资源管理器图标展开侧栏，向下滚动即可看到。
