这是什么文件

anhproject.md 是 ANH 项目的项目元数据文件。你可以把它理解成小说项目的封面页和身份证：它描述“这个项目是谁、叫什么、有哪些标签、用什么关键词识别资源文件”。

它和正文不是一回事

它不是章节正文文件，也不是角色库。它的作用是给 ANH 提供项目级信息。

默认模板长什么样

# 我的小说

## 项目名称
我的小说

## 项目描述
这是一个小说项目

## 作者
作者

## 项目UUID
xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

## 封面

## 项目简介
项目简介

## 标签
小说, 创作

你最常改的字段

标题 作用
## 项目名称 项目显示名
## 项目描述 较详细的项目说明
## 作者 作者名或团队名
## 项目UUID 项目唯一标识；一般不要手改
## 封面 封面图片路径
## 项目简介 短摘要
## 标签 可用逗号或换行分隔

它还可以放哪些项目关键词

除了上面这些元数据，它还支持四组“文件识别关键词”：角色文件关键词、敏感词文件关键词、词汇文件关键词、正则文件关键词。它们决定 ANH 如何根据文件名猜测资源类型。

如果你主要是想改“具体资源文件路径”，那更常去改的是 project-config.json5；anhproject.md 更偏项目名片和关键词识别。

解析规则

  • 按二级标题 ## 标题名 分段解析
  • 标题下面的内容就是该字段值
  • 标签支持逗号分隔、换行分隔，并会忽略 // 注释行
  • 如果缺少 UUID，系统会自动生成新的 UUID

兼容别名

源码里为了兼容旧项目，还接受一些别名标题，例如：

  • 项目标识 / uuid
  • 简介 / summary
  • name / description / author

常见错误

  • 把字段标题写成三级标题 ###，导致不被识别
  • 手动改坏 UUID 格式
  • 把正文内容写进这个文件里，导致项目元数据和章节混在一起
  • 标签写成一句长文本，而不是列表 / 逗号分隔

什么时候应该改它

  • 项目刚初始化完，要补齐信息
  • 改项目名、封面、简介、标签
  • 你想调整资源文件的命名识别关键词
