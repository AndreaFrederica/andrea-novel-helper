WebDAV 同步是什么

WebDAV 同步就是 ANH 的网盘备份功能。它可以把你的小说项目自动同步到云端存储（如坚果云、ownCloud 等），防止数据丢失。

为什么不用普通网盘

普通网盘（如百度网盘、OneDrive）是整文件夹同步，而 WebDAV 同步更精细：ANH 会智能判断哪些文件变了、哪些没变，只同步需要同步的文件。

如何设置

  1. 按 Ctrl+Shift+P，输入"WebDAV"
  2. 选择"管理 WebDAV 账户"
  3. 输入服务器地址、用户名、密码
  4. 关联当前项目到这个账户

密码安全

密码存储在 VS Code 的安全存储区里，不会明文保存在设置文件中。

自动同步

可以设置自动同步：每隔一段时间自动检查变更并同步。也可以手动触发同步。

同步方向

  • 双向同步 — 本地和云端互相更新
  • 仅上传 — 只把本地改动传上去
  • 仅下载 — 只把云端改动拉下来

功能

ANH 的 WebDAV 同步支持将项目文件同步到任意支持 WebDAV 协议的云存储（如坚果云、ownCloud、Nextcloud 等）。采用账户管理器模式，支持多账户和项目关联。

账户管理

WebDAV 采用账户管理器模式，而非在 settings.json 中直接填写服务器信息：

  • 管理账户 — 命令 andrea.webdav.manageAccounts 打开账户管理面板
  • 添加账户 — 在面板中输入服务器地址、用户名、密码。密码存储在 VS Code 的 SecretStorage 中，安全可靠
  • 项目关联 — 每个工作区可以与特定 WebDAV 账户关联，实现多项目对应不同云端
  • 多账户支持 — 可配置多个 WebDAV 账户，不同项目使用不同账户

同步机制

  • 智能比较 — 通过文件大小、修改时间、内容哈希综合判断文件是否需要同步
  • 时间容差 — AndreaNovelHelper.webdav.sync.timeTolerance 处理文件系统时间精度差异
  • 侧车元数据 — AndreaNovelHelper.webdav.sync.enableMetadataSidecar 使用 .anhmeta.json 存储本地文件的同步状态，避免重复传输未变更文件。后缀可通过 metadataSidecarSuffix 自定义
  • 差异对比表 — AndreaNovelHelper.webdav.sync.showDiffTable 在同步前显示文件差异列表
  • Worker 线程 — 同步操作在后台执行，不阻塞 UI

同步策略

AndreaNovelHelper.webdav.sync.strategy 控制如何判断文件是否需要同步：

  • timestamp — 仅比较修改时间
  • size — 仅比较文件大小
  • both — 同时比较时间和大小
  • content — 比较内容哈希（最精确，但开销最大）

自动同步

  • AndreaNovelHelper.webdav.sync.autoSync.enabled — 自动同步开关
  • AndreaNovelHelper.webdav.sync.autoSync.intervalMinutes — 自动同步间隔（分钟）
  • AndreaNovelHelper.webdav.sync.autoSync.method — 自动同步方向：
    • bidirectional — 双向同步
    • upload — 仅上传
    • download — 仅下载

忽略规则

  • AndreaNovelHelper.webdav.sync.ignoredDirectories — 忽略的目录列表（默认包含 .git、node_modules、.vscode、.anh-fsdb 等 20+ 个）
  • AndreaNovelHelper.webdav.sync.ignoredFiles — 忽略的文件模式
  • AndreaNovelHelper.webdav.sync.ignoreAppDataDirectories — 是否忽略应用数据目录

文件浏览器

ANH 提供 WebDAV 文件浏览器侧边栏，支持以下操作：

  • 浏览远程文件和目录结构
  • andrea.webdav.openFile — 打开远程文件
  • andrea.webdav.uploadFile — 上传本地文件到远程
  • andrea.webdav.deleteFile — 删除远程文件
  • andrea.webdav.createFolder — 创建远程文件夹
  • andrea.webdav.renameFile / copyFile — 重命名/复制

其他配置

  • AndreaNovelHelper.webdav.sync.skipDatabaseAccess — 跳过数据库访问（用于故障排查）

手动同步

即使关闭了自动同步，也可以通过命令面板手动触发："ANH: WebDAV 同步"。同步前会自动检测冲突并提示处理方案。

WebDAV 密码存储在 VS Code 的 SecretStorage 中，不会明文保存在 settings.json 里。首次使用需要先通过账户管理器添加账户。
