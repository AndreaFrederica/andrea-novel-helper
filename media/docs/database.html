数据库是什么

ANH 使用数据库来存储各种运行时数据，比如文件追踪记录、写作统计、角色分组等。你可以选择使用 JSON 格式或 SQLite 格式的数据库后端。

两种后端

  • JSON 后端（默认）— 数据存储在 novel-helper/.anh-fsdb/ 目录下的 JSON 文件中。简单直观，适合小型项目
  • SQLite 后端 — 数据存储在 novel-helper/.anh-fsdb/tracking.db 文件中。性能更好，适合大型项目

什么时候需要切换

  • 项目文件很多（几百个以上），JSON 后端可能会变慢
  • 需要更好的并发性能
  • 需要更小的磁盘占用

实现

数据库系统由 src/database/ 目录下的文件实现：

  • DatabaseFactory.ts — 根据配置创建合适的后端
  • IDatabaseBackend.ts — 后端接口定义
  • JSONShardedBackend.ts — JSON 分片后端
  • SQLiteBackend.ts — SQLite 后端
  • DatabaseMigration.ts — 数据迁移工具

配置项

  • AndreaNovelHelper.database.backend — 后端类型：json（默认）或 sqlite
  • AndreaNovelHelper.database.sqlite.enableWAL — SQLite WAL 模式（默认 true，推荐开启）
  • AndreaNovelHelper.database.sqlite.cacheSize — SQLite 缓存大小（默认 2560 页）
  • AndreaNovelHelper.database.sqlite.enableMmap — SQLite 内存映射 I/O（默认 true）
  • AndreaNovelHelper.database.debug — 调试日志（默认 false）

数据目录

所有数据库文件存储在 novel-helper/.anh-fsdb/ 目录下：

  • JSON 后端：多个 .json 分片文件
  • SQLite 后端：tracking.db 文件
  • 其他数据：role-tracking.json、tag-role-bindings.json 等

相关命令

  • AndreaNovelHelper.database.switchBackend — 切换数据库后端
  • AndreaNovelHelper.database.migrate — 执行数据迁移
  • AndreaNovelHelper.database.showStatus — 显示数据库状态
  • AndreaNovelHelper.database.healthCheck — 健康检查
  • AndreaNovelHelper.database.optimize — 优化数据库
  • AndreaNovelHelper.database.compare — 比较不同后端的数据

切换后端

使用命令 AndreaNovelHelper.database.switchBackend 可以在 JSON 和 SQLite 之间切换。切换时 ANH 会自动迁移现有数据。

注意事项

  • SQLite 后端需要系统支持原生模块（扩展已包含预编译的二进制文件）
  • WAL 模式提供更好的并发读性能，但需要文件系统支持
  • 大文件阈值设置（AndreaNovelHelper.hugeFile.thresholdBytes）会影响数据库操作的性能优化策略
