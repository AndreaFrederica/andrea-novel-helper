角色追踪是什么

角色追踪让你把角色分组管理。比如你可以创建"本卷出场"、"已退场"、"需要补充设定"等分组，把角色拖到对应的组里，方便管理和查看进度。

怎么使用

  1. 在活动栏点击 ANH 侧边栏图标
  2. 找到"角色追踪"视图
  3. 右键可以创建新分组、重命名、删除
  4. 拖拽角色到不同分组即可移动

默认分组

ANH 会自动创建一个"默认追踪"分组，所有未手动归类的角色都会显示在这里。这个默认分组不能被删除，但可以重命名。

可以做什么

  • 创建自定义分组（如"主线角色"、"支线角色"、"龙套"）
  • 在分组间拖拽移动角色
  • 从分组中移除角色（不影响角色本身）
  • 重命名分组
  • 删除不需要的分组

实现机制

角色追踪的数据存储在 novel-helper/.anh-fsdb/role-tracking.json，由 src/language/roleTrackingStore.ts 管理。

数据格式

{
  "version": 1,
  "groups": [
    {
      "id": "default",
      "name": "默认追踪",
      "order": 0,
      "roleUuids": ["uuid-1", "uuid-2"]
    },
    {
      "id": "group-abc123",
      "name": "本卷出场",
      "order": 100,
      "roleUuids": ["uuid-3"]
    }
  ]
}

分组字段

  • id — 分组唯一标识（default 为默认分组，新建分组使用时间戳+随机字符串）
  • name — 分组显示名称
  • order — 排序值，数字越小越靠前
  • roleUuids — 该分组中的角色 UUID 列表（保持插入顺序）

相关命令

  • andrea.roleTracking.refresh — 刷新追踪数据
  • andrea.roleTracking.addGroup — 新建分组
  • andrea.roleTracking.renameGroup — 重命名分组
  • andrea.roleTracking.deleteGroup — 删除分组
  • andrea.roleTracking.addRole — 添加角色到分组
  • andrea.roleTracking.removeRole — 从分组移除角色
  • andrea.roleTracking.moveRole — 移动角色到另一个分组
  • andrea.roleTracking.openRole — 打开角色文件
  • andrea.roleTracking.showReferences — 查看角色引用

排序规则

分组按 order 值升序排列，相同 order 值时按名称的中文 locale 排序。新分组的 order 值为当前最大值 +100。

注意事项

  • 角色追踪使用角色的 UUID 而非名字来引用角色，所以重命名角色不会影响追踪关系
  • 默认分组（id 为 default）不能被删除，但可以重命名
  • 一个角色可以同时出现在多个分组中
  • 删除分组不会删除其中的角色，只是取消分组关系
