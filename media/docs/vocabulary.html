词汇表是什么

词汇表是用来管理你小说里的专有名词的：地名、组织名、魔法术语、科技名词、种族名等。

你可以把它理解为小说的"术语词典"。跟角色库类似，但专门用来存放非人物的名词。

词汇和角色有什么区别

本质上没有区别，ANH 用同一套系统管理它们。唯一的不同是"类型"字段：角色是"主角/配角"，词汇是"词汇"。

这意味着词汇享有和角色完全一样的能力：自动提示、高亮显示、Ctrl+Click 跳转、查找引用等。

创建词汇表

  1. 在包管理器中右键目录节点
  2. 选择"创建词汇库 (MD/JSON5/TXT)"
  3. 选择 Markdown 格式（推荐）

推荐用法

  • 把所有世界观核心词汇统一放在一个包里
  • 给重要词汇设置颜色，在正文中一眼识别
  • 利用别名功能管理外文译名

用途

词汇表用于管理世界观中的专有名词：地名、组织名、魔法术语、科技名词、种族名等。在 ANH 的统一对象模型中，词汇的 type 为 词汇，与角色共享同一套底层机制。

文件格式规范

词汇表支持 Markdown、JSON5、CSV 三种格式（不支持纯 TXT），命名规则包括 vocabulary.md、*_vocabulary.md、*_vocab.md、*_term.md、*_词汇.md、*_术语.md。

使用方式

  • 自动补全 — 在编辑器中输入词汇名或别名时，会自动弹出补全列表。支持拼音首字母匹配
  • 高亮显示 — 词汇名在编辑器中按定义的 color 高亮，支持前景色和背景色样式
  • 跳转定义 — Ctrl+Click 词汇名可直接跳转到定义文件
  • 查找引用 — 查看词汇在哪些文件中被引用，配合引用维护功能使用
  • 角色卡编辑器 — 与角色完全相同的可视化编辑器，支持所有字段编辑

查询键

词汇也支持查询键字段，用于补全匹配：

  • lookupKeys_pinyin — 拼音查询键
  • lookupKeys_romanized — 罗马字查询键
  • lookupKeys_spelling — 拼写查询键

可通过 AndreaNovelHelper.lookupKeys.autoGeneratePinyin / autoGenerateRomanized 配置自动生成。

与角色的异同

词汇和角色共享同一套能力（补全、高亮、跳转、引用、角色卡编辑器），区别仅在于 type 字段的值。在"所有角色"树视图中，词汇会按类型分组显示，不会与角色混淆。

配置项

  • AndreaNovelHelper.vocabularyFile — 默认词汇文件路径（默认 novel-helper/vocabulary.json5）

创建词汇表

在包管理器中右键目录节点 → "创建词汇库 (MD/JSON5/TXT)"，选择格式（推荐 Markdown），输入文件名即可创建。

建议将世界观核心词汇统一放在一个包中（如 novel-helper/worldbuilding/vocabulary.md），方便管理和复用。
