👋 ANH 是什么

Andrea Novel Helper（ANH）是一个帮你写小说的 VS Code 插件。你可以把它想象成一个智能写作助手——它帮你记住所有角色名字、自动给角色名上色、还能在你忘记某个词怎么写的时候自动提醒。

核心理念很简单：把你的角色、地名、敏感词、特殊用语放进一个"资料集"里，然后 ANH 会在你写作时自动调用这些资料。就像你写作时旁边放了一本"设定百科全书"，ANH 会帮你自动翻阅。

5 分钟快速上手

不需要任何技术基础，跟着下面的步骤做，5 分钟后你就能体验到 ANH 的核心功能。

第 1 步：创建你的小说项目

  1. 打开 VS Code，按 Ctrl+Shift+P 搜索"打开 ANH Hello"进入 Hello 首页
  2. 点击"新建写作工作区"，选择一个空文件夹（或在对话框内新建文件夹后选中），ANH 会打开该工作区并直接自动弹出项目初始化向导
  3. 跟着向导填写：项目名称、你的名字（其他都可以跳过）
  4. 完成后，ANH 的视图（包管理器、字数统计等）就会出现在侧边栏中

如果你习惯手动操作，也可以直接打开一个空文件夹，ANH 检测到没有角色/词汇等描述文件时，会弹窗询问是否运行项目初始化向导。

第 2 步：创建你的第一个角色

  1. 在左侧活动栏点击 ANH 图标，打开"包管理器"，右键 novel-helper/main/ 目录节点
  2. 选择"创建角色库 (MD/JSON5/TXT)" → 选择 Markdown 格式 → 输入文件名 my-characters
  3. 在打开的文件中写入你的第一个角色： 
    # 我的角色

## 林小满

### 类型
主角

### 颜色
#FF6B6B

### 别名
小满

### 描述
一个喜欢雨天咖啡店的女孩。
  4. 按 Ctrl+S 保存文件

第 3 步：体验角色自动提示

  1. 新建一个 Markdown 文件（如 chapter1.md）
  2. 输入角色名的一部分（如 林），会弹出补全列表，里面有"林小满"
  3. 选择"林小满"，名字会自动插入到文档中
  4. 你也可以直接输入别名（如 小满），同样会弹出提示
默认补全模式是 loose（模糊匹配），输入任意字符即可触发。你也可以在设置中切换为 symbolLoose 等模式，使用 @ 前缀触发补全。下方动画可以切换不同模式体验区别。

第 4 步：观察魔法上色效果

  1. 在文档中写一段文字： 
    林小满推开咖啡店的门，风铃轻轻响了一声。

"今天还是老样子？" 老板问。

"嗯，美式加一份浓缩。" 林小满笑着坐下。
  2. 你会发现"林小满"三个字变成了你设定的颜色（珊瑚红）
  3. 双引号 "" 也会被自动着色（金色）——这是初始化时自带的正则匹配规则在工作
  4. 把鼠标停在"林小满"上，会显示你写的描述
  5. 按住 Ctrl 点击"林小满"，会直接跳转到角色资料
初始化时自带的正则匹配规则：项目初始化时会自动创建正则规则库，内置了中文引号 ""、书名号 《》、单引号 ''、角引号 「」 的着色规则。你可以在 novel-helper/ 下找到并自定义这些规则。

第 5 步：实时预览你的章节

  1. 按 Ctrl+Shift+P，输入"打开预览"
  2. 选择"ANH: 打开 Markdown/TXT 预览"
  3. 右侧会出现预览面板，实时显示你的内容
  4. 预览中"林小满"也会以珊瑚红色高亮显示

第 6 步：查看写作字数

  1. 看 VS Code 底部状态栏，会显示当前字数（如 1.2k）
  2. 点击字数可以切换统计方式
  3. 继续写作，观察字数变化

ANH 架构概览

Andrea Novel Helper 是一个围绕"Package / Role"统一对象模型构建的 VS Code 扩展。所有资源（角色、词汇、敏感词、正则规则）共享同一套底层机制：Aho-Corasick 自动机匹配、Decoration API 高亮、CompletionItemProvider 补全、ReferenceProvider 引用追踪。

核心模块

  • Package Manager — TreeDataProvider，管理 novel-helper/ 目录下的包结构，支持 Markdown/JSON5/CSV/TXT 四种格式
  • Role Service — 统一角色接口，通过 type 字段区分资源类型。运行时样式平级存储，编辑器保存时收敛到 style 对象
  • Typo Service — 段落级 FNV-1a 哈希缓存 + 批量并发检测。支持外部 HTTP 服务（macro/llm）和客户端直连 LLM 两种模式
  • Word Count — 多级缓存（内存 + 持久化分片 + Worker 线程），GitGuard 校验缓存有效性
  • Webview Panels — 文档中心、角色卡编辑器、时间线/关系图编辑器、设置面板等均基于 Webview API

配置体系

三层优先级：project-config.json5 > VS Code 工作区设置 > 插件默认值。项目配置可覆盖同名 VS Code 设置，实现多项目隔离。

扩展点

  • Custom Text Editor — 角色卡 JSON5 编辑器、时间线编辑器、关系图编辑器
  • CompletionItemProvider — 角色/词汇补全
  • DocumentLinkProvider / ReferenceProvider — 跳转定义与查找引用
  • TreeDataProvider — 包管理器、字数统计、所有角色
ANH 通过检测 anhproject.md 或 novel-helper/ 目录来识别项目根目录。确保直接打开项目文件夹而非父目录。
