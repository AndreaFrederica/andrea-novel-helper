外部资源是什么

外部资源就是把你电脑上的其他文件夹"挂载"到当前项目里。这些文件夹里的角色和词汇也能在当前项目中使用，就像它们是项目的一部分一样。

什么时候会用到

  • 多个小说项目共享同一套世界观设定
  • 把以前作品的角色借用到新作品中
  • 管理跨作品的"联动角色"

如何添加外部资源

  1. 按 Ctrl+Shift+P
  2. 输入"外部资源管理"
  3. 在面板中输入或选择工作区外的目录路径
  4. ANH 会自动扫描该目录中的角色文件

注意事项

  • 外部目录列表不会保存到设置中，每次启动时自动重新扫描
  • 如果外部资源和项目内有同名角色，项目内的优先
  • 修改外部资源文件后，所有挂载了该目录的项目都会自动生效

使用场景

当你有多个项目共享同一套角色库或词汇表时，可以将公共资源目录挂载为外部资源，避免重复复制。外部资源中的角色与项目内角色享有完全相同的补全、高亮和引用能力。

配置方式

外部资源目录通过以下方式管理：

  • 命令 — AndreaNovelHelper.showExternalResourceManage 打开外部资源管理面板
  • 添加路径 — 在面板中输入或选择工作区外的目录路径
  • 自动扫描 — 添加后 ANH 会自动扫描该目录中的所有角色文件（支持 .ojson5/.rjson5/.ojson/.rjson/.tjson5 扩展名）
  • 自动发现 — 每次启动时自动扫描，结果保存在内存变量中，不持久化到 VS Code 全局状态

文件识别

外部资源目录支持以下识别方式：

  • 扩展名识别 — .ojson5、.rjson5、.ojson、.rjson、.tjson5 文件会被自动识别
  • 关键词匹配 — 文件名包含项目配置中的识别关键词时会被识别
  • Markdown 库标记 — 受 enableMdLibraryNameMarkers 设置控制，识别 character-gallery.md 等特定文件名
  • __init__.ojson5 — 兼容初始化标记文件

忽略规则

  • 扫描时会跳过 novel-helper/ 目录以及 .git、.vscode、node_modules 等默认忽略目录
  • 可通过在工作区放置 .anh-ignore 文件排除特定目录
  • 配置项 AndreaNovelHelper.externalFolder.ignoredDirectories / markerKeywords / enableMdLibraryNameMarkers

优先级

外部资源目录中的角色在合并时会获得优先级加成。当同名角色发生冲突时，项目内角色的优先级高于外部角色。

外部资源非常适合管理跨作品的"联动角色"或共享的世界观设定。修改外部资源文件后，所有挂载了该目录的项目都会自动生效。注意：外部目录列表不会持久化到设置中，每次启动时自动重新扫描。
