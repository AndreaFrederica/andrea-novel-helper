外部资源是什么

外部资源最常见的用法，不是“挂一个完全在项目外的目录”，而是：把当前工作区里那些不放在 novel-helper/ 下的资料目录，标成可识别资源包。当然，ANH 也支持手动挂载工作区外目录，但那通常是更进阶的共享场景。

这一页偏“怎么用”。如果你想弄清楚外部包为什么会被识别、哪些文件会触发识别、__init__.ojson5 和 .anh-ignore 分别起什么作用，请直接看 包机制与外部包详解。

什么时候会用到

  • 你想在当前工作区里单独放一个 资料库/、imports/ 或 archive-packages/，但又希望 ANH 识别它
  • 你把旧项目拆出一个“迁移包”，暂时不想塞进 novel-helper/
  • 多个小说项目共享同一套世界观设定，需要再进一步挂工作区外目录

如何添加外部资源

  1. 按 Ctrl+Shift+P
  2. 输入"外部资源管理"
  3. 优先选择当前工作区里一个不在 novel-helper/ 下的目录，例如 资料库/公共设定/
  4. 让 ANH 为它创建 __init__.ojson5 标记文件
  5. ANH 会重新扫描该目录，并把它显示到包管理器顶层

注意事项

  • 外部目录不是靠“设置列表”保存的，而是靠工作区重新扫描再次识别；你手动添加目录时，ANH 通常会在目录里创建 __init__.ojson5 作为标记
  • 如果你明确不想让某个目录再被识别，可以让 ANH 创建 .anh-ignore 来排除它
  • 默认加载顺序下，项目内角色通常先成为基础对象，外部角色更常见的行为是补充缺失字段；只有开启自定义优先级策略后，位置权重才会参与比较
  • 修改外部资源文件后，所有挂载了该目录的项目都会自动生效

使用场景

对大多数用户，更推荐把外部资源理解成“工作区里的非 novel-helper/ 包”。例如你有：

当前工作区/
├── novel-helper/
├── 资料库/
│   └── 旧项目迁移包/
└── imports/
    └── Excel导入角色包/

这时你可以只给 资料库/旧项目迁移包/ 或 imports/Excel导入角色包/ 创建外部包标记，而不是把它们直接搬进 novel-helper/ 根目录。只有当你确实要跨多个不同工作区共享时，才更适合挂工作区外目录。

配置方式

外部资源目录通过以下方式管理：

  • 命令 — AndreaNovelHelper.showExternalResourceManage 打开外部资源管理面板
  • 添加路径 — 在面板中选择目录；确认后可以创建 __init__.ojson5 标记文件
  • 自动扫描 — 添加后 ANH 会重新扫描该目录；以后每次启动时也会重新扫描工作区，寻找符合规则的外部资源目录
  • 移除目录 — 可以删除标记文件，或创建 .anh-ignore 阻止该目录再次被自动识别

文件识别

外部资源目录支持以下识别方式：

  • 扩展名识别 — .ojson5、.rjson5、.ojson、.rjson、.tjson5 文件会被自动识别
  • 关键词匹配 — 文件名包含外部资源标记关键词，且扩展名属于允许列表时会被识别
  • Markdown 库标记 — 受 AndreaNovelHelper.externalFolder.enableMdLibraryNameMarkers 控制，识别 character-gallery.md、sensitive-words.md、vocabulary.md 等特定命名
  • __init__.ojson5 — 兼容初始化标记文件

忽略规则

  • 扫描时会跳过 novel-helper/ 目录以及 .git、.vscode、node_modules 等默认忽略目录
  • 可通过在工作区放置 .anh-ignore 文件排除特定目录
  • 相关配置项是 AndreaNovelHelper.externalFolder.ignoredDirectories、AndreaNovelHelper.externalFolder.markerKeywords、AndreaNovelHelper.externalFolder.enableMdLibraryNameMarkers

优先级

默认策略下，外部资源目录不会自动获得额外优先级加成。ANH 默认按加载顺序处理：项目内 novel-helper/ 先扫，外部目录后扫，所以同 UUID 冲突时，通常是项目内角色先成为基础对象，外部角色补充缺失字段。只有你显式启用了自定义优先级策略，并打开位置优先级后，外部/内部的位置权重才会参与比较。

外部资源非常适合管理跨作品的“联动角色”或共享世界观设定。修改外部资源文件后，所有挂载了该目录的项目都会自动生效。想看更完整的识别规则、加载顺序和冲突处理，请直接看 包机制与外部包详解。
