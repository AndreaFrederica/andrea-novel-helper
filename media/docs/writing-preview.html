预览功能是什么

预览功能让你在发布前看到小说在网站上的最终效果。很多小说网站不支持 Markdown 排版（加粗、标题、引用等），预览可以帮你确认发布后的纯文本效果。

注意：编辑器本身已经提供了角色名上色功能。预览中的上色和 Markdown 格式渲染可以独立开关——因为大多数小说网站不支持这些排版。

核心用途

  • 确认发布效果 — 关闭 Markdown 渲染后，预览显示的就是纯文本，接近网站上的实际效果
  • 检查角色名 — 可以开启或关闭角色名上色，确认角色名在正文中的分布
  • 阅读体验 — 翻页模式、调整字体和排版，以读者视角审视你的作品
  • 语音朗读 — 听一遍自己的文字，发现眼睛看不到的问题
  • 导出 — 复制纯文本或导出 TXT 文件

如何打开预览

  1. 按 Ctrl+Shift+P 打开命令面板
  2. 输入"打开预览"
  3. 选择"ANH: 打开 Markdown/TXT 预览"

预览面板会出现在编辑器右侧。切换编辑其他文件时，预览会自动跟随显示新文件。

关闭 Markdown 渲染

点击预览右下角齿轮按钮，可以逐项关闭 Markdown 渲染（标题、加粗、斜体、引用块、列表、代码块等）。全部关闭后，预览显示的就是纯文本效果——和大多数小说网站上的显示一致。

关闭角色名上色

齿轮设置中也可以关闭角色名着色。编辑器本身已经提供了角色名上色，预览中的着色是额外的视觉辅助，按需开关即可。

Typst 排版预览（进阶）

如果你需要印刷级别的排版效果（如实体书排版），可以使用 Typst 预览。需要安装 Tinymist Typst 扩展。

一、预览架构

ANH 使用完全自研的 Markdown 解析器（不依赖 markdown-it、marked 等第三方库），配合增量更新引擎，即使十万字长文也能流畅预览。

  • 解析器：将 Markdown 源码转为纯文本文块（paragraph、heading、list、blockquote、code），同时记录行内样式范围
  • 渲染器：将文块转为 HTML，注入到 webview 中显示
  • 增量更新：仅重渲染变化的段落，80ms 防抖。变更超过 60% 或 2000 行时回退到全量渲染
  • 滚动同步：基于滚动比例 + 行号的双向同步，带死区过滤和回声抑制

二、支持的 Markdown 语法

预览支持以下 Markdown 语法，但这些渲染都可以独立关闭（齿轮设置中）：

块级元素：

  • ATX 标题（# ~ ######）— 可关闭，关闭后只显示纯文字
  • 引用块（>）— 可关闭
  • 无序/有序/任务列表 — 可关闭，关闭后列表标记消失
  • 围栏代码块（```）— 可关闭
  • 表格（管道符分隔）
  • 水平线（---、***、___）
  • 图片（![alt](src)）— 相对路径自动解析

行内元素：

  • **加粗** — 可关闭，关闭后标记符号消失，只留纯文字
  • *斜体* — 可关闭
  • ***加粗斜体*** — 可关闭
  • ~~删除线~~ — 可关闭
  • `行内代码`
  • [文字](url) — 链接被剥离，只显示文字

注释（渲染时剥离）：

  • <!-- HTML 注释 -->
  • %% Obsidian 注释 %%

不支持的语法：嵌套列表、脚注、定义列表、LaTeX 数学、Mermaid 图表。

三、角色名着色

编辑器本身已经提供角色名上色（基于 Aho-Corasick 算法实时匹配）。预览中的着色是独立的额外功能，可以在设置中开关。

默认类型颜色：

  • 主角 — 金色 #FFD700
  • 配角 — 浅蓝 #ADD8E6
  • 联动角色 — 浅绿 #90EE90
  • 正则表达式 — 橙色 #FFA500
  • 未指定类型 — 蓝色 #7AA2F7（可配置）

控制选项：

  • 预览设置面板中可开关角色名着色
  • 可按类型过滤（只显示主角、只显示配角等）
  • 角色库中定义的 style 对象会覆盖默认颜色

四、阅读模式设置

点击预览右下角齿轮按钮打开设置面板：

排版设置：

  • 显示模式：滚动（连续）或翻页（PgUp/PgDn）
  • 文字对齐：左对齐或两端对齐
  • 栏数：1 栏或 2 栏
  • 字体：字号（12-30px）、字体家族、行高、段间距、内边距

主题：

  • 跟随 VS Code（auto）
  • 纯白 / 纯黑 / 自定义颜色

Markdown 渲染开关（推荐小说作者全部关闭）：

  • 标题 — 关闭后 # 标题只显示纯文字
  • 列表 — 关闭后列表标记消失
  • 加粗、斜体、加粗斜体、删除线 — 各自独立开关
  • 引用块、代码块

全部关闭后，预览效果接近纯文本小说网站上的显示。

预设系统：

  • 保存/加载/删除命名预设
  • 例如可以创建一个"网站预览"预设（全部 Markdown 关闭）和一个"编辑预览"预设（全部开启）

五、TTS 语音朗读

  • 底部控件：播放、暂停、停止
  • 语音选择下拉菜单
  • 当前朗读位置以金色背景高亮
  • 可朗读全文或选中文本
  • 翻页模式下朗读会跨页继续

六、导出功能

  • 右键预览 → "复制纯文本" — 复制到剪贴板
  • 右键预览 → "朗读选中文本" — TTS 朗读选区
  • 导出为 TXT 文件

七、Typst 排版预览

将 Markdown 转换为 Typst 格式进行专业排版预览（适用于实体书排版）：

  • 需要安装 Tinymist Typst 扩展
  • 支持模板选择，内置多种排版模板
  • 支持内存模式和文件模式
  • 命令：AndreaNovelHelper.openTypstPreview

八、打开方式

  • 命令面板 Ctrl+Shift+P：输入"打开预览"→ "ANH: 打开 Markdown/TXT 预览"
  • 命令 ID：myPreview.open（Markdown/TXT）
  • 命令 ID：AndreaNovelHelper.openTypstPreview（Typst）
  • 状态栏点击预览按钮（如果已启用）
预览面板使用 retainContextWhenHidden 策略，隐藏时不会销毁。面板状态（文档 URI、滚动位置）会在 VS Code 重启后自动恢复。建议创建两个预设：一个全开（编辑时参考），一个全关（模拟网站发布效果）。
