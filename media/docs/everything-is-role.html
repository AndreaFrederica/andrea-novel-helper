万物皆角色

ANH 最核心的设计理念是：所有资料都用同一种格式管理。不管是角色、敏感词、世界观词汇，还是着色规则，本质上都是"角色"，只是类型不同。

这对你意味着什么

  • 一套工具管所有 — 不需要学不同的工具来管理不同类型的资料
  • 统一的能力 — 所有资料都支持自动提示、高亮、跳转、引用统计
  • 统一的编辑器 — 用同一个可视化编辑器管理所有资料

六种内置类型

  • 主角 — 主要角色，用于角色名高亮、补全、引用统计
  • 配角 — 次要角色，与主角享有相同能力
  • 联动角色 — 跨作品/联动角色，用于引用其他作品的角色
  • 敏感词 — 需要标记或替换的词汇，附带修复建议
  • 词汇 — 世界观术语和专业名词
  • 正则表达式 — 自定义着色规则，用正则匹配文本并着色

除以上六种内置类型外，你还可以自定义任意类型名称。

共享的能力

不管哪种类型，都享有以下能力：

  • 别名支持
  • Ctrl+Click 跳转定义
  • 查找引用
  • 自动提示
  • 高亮显示
  • 可视化编辑器

统一对象模型

ANH 中所有资源类型都由同一个 Role 接口表示，通过 type 字段区分。这是 ANH 最核心的设计理念：

  • 主角 / 配角 / 联动角色 — 角色人物，用于写作中的角色名高亮、补全、引用
  • 敏感词 — 需要标记或替换的词汇，附带 fixes 修复建议数组
  • 词汇 — 世界观术语和专业名词
  • 正则表达式 — 自定义着色规则，用 regex + regexFlags 定义匹配模式

Role 接口定义

核心字段（定义在 src/extension.ts）包括：

  • name — 角色/资源的唯一标识名称（必填）
  • type — 类型，内置或自定义字符串（必填）
  • uuid — 可选唯一标识符
  • aliases — 别名数组，编辑器中自动识别
  • description — 描述/简介
  • color — 前景色（HEX/RGB/HSL/HSV）
  • backgroundColor — 背景色
  • bold / italic / strikethrough / underline — 文本样式开关
  • priority — 着色器优先级，数字越小优先级越高，默认 999
  • affiliation — 从属标签（阵营/组织）
  • regex / regexFlags — 正则表达式类型专用
  • fixes — 敏感词类型专用，修复候选数组
  • wordSegmentFilter — 是否启用分词过滤，避免单字误匹配
  • packagePath — 角色所在的包路径（相对于 novel-helper 目录）
  • sourcePath — 角色来源文件路径（完整路径）

样式字段说明

运行时中样式属性以平级字段形式存在（如 role.backgroundColor、role.bold）。角色卡编辑器在保存时会将旧版独立字段收敛到 style 对象中（style.color、style.backgroundColor 等），style.color 会覆盖顶层 color。

// 运行时读取（兼容旧格式）
role.color, role.backgroundColor, role.bold

// 编辑器保存后的新格式
style: { color: "#E60033", backgroundColor: "#FFF0F0", bold: true }

查询键系统

以下查询键由 roleLookupKeyGeneration.ts 自动生成，不是用户直接在 Role 接口中定义的字段：

  • lookupKeys_pinyin — 自动生成的拼音查询键
  • lookupKeys_romanized — 自动生成的罗马字查询键
  • lookupKeys_spelling — 自动生成的拼写查询键

可通过 AndreaNovelHelper.lookupKeys.autoGeneratePinyin / autoGenerateRomanized / treatPinyinAsAlias / treatRomanizedAsAlias 控制生成行为。

共享能力

无论哪种 type，所有"角色"都享有同一套能力：

  • 别名 — 支持多个别名，编辑器中自动识别
  • 跳转定义 — Ctrl+Click 直接跳转到角色定义文件
  • 查找引用 — 查看角色在哪些文件中被引用
  • 自动补全 — 输入 @ 或角色名时弹出补全，支持拼音首字母匹配
  • 高亮装饰 — 编辑器中自动按颜色标记
  • 角色卡编辑器 — 可视化编辑所有字段
  • Aho-Corasick 自动机 — 底层使用高性能多模式匹配算法，实时扫描文本

扩展字段

除了核心字段，ANH 还支持大量扩展字段（age、gender、occupation、personality、appearance、background、relationship、skill、weakness、goal、motivation、fear、secret、quote、note、tag、category、level、status、location、origin、family、education、hobby 等）。这些字段在角色卡编辑器中自动归类到"扩展"分类，也可通过自定义字段添加任意键值对。

这意味着你不需要学习不同的工具来管理不同类型的资源。一个角色卡编辑器、一套补全系统、一种高亮机制、一组引用统计，统一管理所有写作资产。
