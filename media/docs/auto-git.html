自动 Git 是什么

自动 Git 让 ANH 在后台自动监控文件变化，定期把修改提交到 Git 仓库。你不需要手动频繁 commit，ANH 会帮你打理好版本控制。

它能做什么

  • 自动检测文件变化并定期提交
  • 使用模板化的提交信息（如"自动保存：新增 3 个文件，修改 5 个文件"）
  • 可选自动 push 到远程仓库
  • 可选自动 pull 最新更改
  • 在状态栏显示 Git 和 WebDAV 的同步状态

怎么使用

  1. 确保项目已初始化 Git 仓库
  2. 在设置中开启自动 Git（AndreaNovelHelper.autoGit.enabled）
  3. ANH 会在后台自动运行

状态栏

状态栏的 "ANH:Sync" 按钮会显示 Git 和 WebDAV 的同步状态。点击可以查看详细信息。

实现

自动 Git 由 src/sync/autoGitService.ts 实现，配合 src/utils/Git/autoGitUtils.ts 和 src/utils/Git/gitHeadMonitor.ts。

工作原理

  • HEAD 监听 — 使用 GitHeadMonitor 定期检查 Git HEAD 变化和工作区状态
  • 文件监听 — 通过 FileSystemWatcher 监听文件变化
  • 自动提交 — 检测到变化后按配置的间隔自动提交
  • 状态栏更新 — 实时更新同步状态到状态栏

配置项

  • AndreaNovelHelper.autoGit.enabled — 是否启用自动 Git（默认 false）
  • AndreaNovelHelper.autoGit.checkIntervalSeconds — 检查间隔（秒，默认 30）
  • AndreaNovelHelper.autoGit.commitMessageTemplate — 提交信息模板
  • AndreaNovelHelper.autoGit.autoPull — 是否自动 pull（默认 true）
  • AndreaNovelHelper.autoGit.autoPush — 是否自动 push（默认 true）
  • AndreaNovelHelper.autoGit.includeUntracked — 是否包含未跟踪文件（默认 false）
  • AndreaNovelHelper.autoGit.excludePatterns — 排除模式列表
  • AndreaNovelHelper.autoGit.compactStatus — 状态栏简洁模式（默认 true）

相关命令

  • AndreaNovelHelper.setupGitIdentity — 设置 Git 身份信息

侧边栏视图

自动 Git 在 ANH 侧边栏中提供了一个树视图，显示：

  • 当前 Git 分支
  • 待提交的文件列表
  • 远程仓库状态
  • 快捷操作（提交、推送、拉取）

安全考虑

  • 自动 push 默认关闭，需要手动开启
  • 提交信息模板支持排除特定文件和目录
  • 可以在状态栏随时查看和控制同步状态
