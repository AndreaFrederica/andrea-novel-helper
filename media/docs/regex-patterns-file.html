这是什么文件

regex-patterns.* 是项目的正则着色规则文件。初始化默认创建 novel-helper/regex-patterns.json5，用于给引号、书名号、特殊文本等内容做正则匹配和着色。

这和普通角色库有什么区别

普通角色库是“按词条匹配”；正则规则是“按模式匹配”。适合“凡是长得像某种格式的内容都处理一下”。

典型场景

  • 给对话引号上色
  • 给书名号、特殊标记上色
  • 识别一类格式化文本，而不是单个固定词

每条规则最常见的字段

  • name
  • type（通常是 正则表达式）
  • regex
  • regexFlags
  • color
  • priority
如果你想学“正则本身怎么写”，直接看 正则表达式入门；如果你想看这个文件在 ANH 里怎么工作，继续看 正则着色。

最小 JSON5 示例

[
  {
    name: '中文对话',
    type: '正则表达式',
    regex: '「[^」]*」',
    regexFlags: 'g',
    color: '#fbdc98ff',
    priority: 100,
  }
]

文件级建议

  • 把项目里长期使用的规则放进文件，不要散落在临时实验里
  • 规则多时写上 description
  • 重叠规则提前规划 priority，不要靠运气
