Obsidian 兼容性是什么

ANH 提供了与 Obsidian 类似的 Markdown 增强功能，让你在 VS Code 中也能使用 Obsidian 风格的双链语法和标签。

Wiki 链接

你可以使用 [[文件名]] 语法创建文档间的链接：

  • [[角色设定]] — 链接到名为"角色设定"的文件
  • [[角色设定#外貌]] — 链接到"角色设定"文件中的"外貌"标题
  • [[角色设定|显示文本]] — 链接并自定义显示文本

标签补全

在编辑器中输入 # 后，会自动弹出项目中所有已知标签的补全列表，方便快速输入。

文件链接

Wiki 链接会自动解析为可点击的链接。Ctrl+Click 即可跳转到目标文件。

实现

兼容性功能由 src/language/obsidianCompat.ts 和 src/language/obsidianIndex.ts 实现，提供三个语言服务提供者：

文档链接提供者

ObsidianDocumentLinkProvider — 将 [[...]] 语法渲染为可点击的文档链接。支持解析文件名、标题锚点和别名语法。

定义提供者

ObsidianDefinitionProvider — Ctrl+Click [[...]] 时跳转到目标文件的对应位置。解析优先级：

  1. 精确路径（含 / 或文件扩展名）→ 按相对路径查找
  2. Obsidian 索引 → 按文件名匹配
  3. 工作区搜索 → 按文件名模糊匹配

补全提供者

ObsidianCompletionProvider — 提供两种补全：

  • Wiki 链接补全 — 输入 [[ 后列出项目中的文本文件（.md, .markdown）。输入 # 后列出目标文件中的标题
  • 标签补全 — 输入 # 后列出项目中所有已知标签

支持的语法

  • [[文件名]] — 基本链接
  • [[文件名#标题]] — 标题链接
  • [[文件名|别名]] — 带别名的链接
  • ![[文件名]] — 嵌入引用（图片等）
  • #标签名 — 标签语法
  • #父级/标签名 — 层级标签

索引机制

ANH 维护一个 Obsidian 兼容的索引（src/language/obsidianIndex.ts），包含：

  • 项目中所有文本文件的路径和标题
  • 每个文件中使用的所有标签
  • 文件间的链接关系

索引会缓存到 novel-helper/.anh-fsdb/obsidian-index.json，启动后优先读取缓存，并延迟在后台增量更新，避免和插件启动阶段争用磁盘。

如果不需要全局标签、标题和双链补全，可以关闭设置 AndreaNovelHelper.obsidian.index.enabled。关闭后，预览和导出中的双链/标签渲染仍然可用，但不会在启动时扫描工作区建立索引。

兼容性说明

  • 链接解析大小写不敏感
  • 支持省略 .md 扩展名
  • 同名文件会优先匹配同目录下的文件
  • 支持相对路径和绝对路径语法
