这是什么文件

roles.md 是一种Markdown 版角色资源文件。如果你更喜欢“像写文档一样写角色卡”，而不是在 JSON5 里对括号和逗号，它通常是最舒服的方案。

基本结构

# 角色库

## 林小满

### 类型
主角

### 颜色
#FF6B6B

### 别名
小满
小林

层级怎么读

  • #：文件标题
  • ##：一个条目（通常是一个角色）
  • ###：该条目的字段名

为什么很多人喜欢它

  • 可读性好
  • 适合边看边改
  • 更像写设定手册，不像写配置文件
如果你的角色字段很多，而且以后还想做批量处理，JSON5 往往更稳；如果你更在意可读性和手工整理体验，roles.md 更舒服。

适合 roles.md 的场景

  • 手工维护几十个以内的重要角色
  • 你会经常阅读设定，而不只是把它当数据库
  • 你习惯 Markdown 工作流

不太适合的场景

  • 要批量导入几百条简单数据
  • 要做复杂程序处理或导出
  • 字段高度结构化、机器优先

最常见错误

  • 把字段标题写错层级
  • 忘了“类型”字段
  • 把多个角色写进同一段自然语言里，失去结构
