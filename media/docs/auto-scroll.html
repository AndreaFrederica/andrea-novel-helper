自动滚动是什么

自动滚动让你在写作时，编辑器自动跟随光标滚到文档末尾附近。这样你不用手动翻页，打字时光标始终保持在屏幕的指定位置。

怎么使用

  1. 点击状态栏的"自动滚动"按钮
  2. 或者用命令面板输入"自动滚动"相关命令
  3. 在弹出的菜单中选择"启用/禁用"、"设置比例"或"立即滚动"

滚动比例

滚动比例控制光标在屏幕中的位置：

  • 100%（默认）— 光标始终在屏幕最底部
  • 70% — 光标在屏幕下方 30% 处
  • 50% — 光标在屏幕中间
  • 30% — 光标在屏幕上方 30% 处
  • 也可以自定义 0.1 ~ 0.7 之间的值

使用场景

  • 边写边看 — 启用后写作时不用手动翻页
  • 直播式写作 — 适合屏幕分享或演示时使用
  • 长文续写 — 继续在文档末尾写作时非常方便

实现

自动滚动由 src/Provider/autoScrollProvider.ts 实现，监听文档变化事件并按配置的延迟时间自动滚动。

命令

  • andrea.autoScroll.toggleMenu — 打开自动滚动设置菜单
  • andrea.autoScroll.toggle — 切换启用/禁用
  • andrea.autoScroll.setRatio — 设置滚动比例
  • andrea.autoScroll.scrollNow / andrea.autoScroll.scrollToEnd — 立即滚动到末尾

配置项

  • AndreaNovelHelper.autoScroll.enabled — 是否启用自动滚动（默认 false）
  • AndreaNovelHelper.autoScroll.ratio — 滚动比例，0.1-1.0（默认 1.0，即最底部）
  • AndreaNovelHelper.autoScroll.debounceDelay — 防抖延迟，毫秒（默认 0，即立即滚动）。设为大于 0 的值可避免频繁滚动

工作原理

  • 监听 onDidChangeTextDocument 事件
  • 只在文档行数增加或同一行内有内容变化时触发滚动
  • 使用防抖机制避免频繁滚动影响性能
  • 切换活动编辑器时也会触发一次滚动
  • 配置保存为全局设置，属于个人使用习惯

状态栏显示

状态栏显示当前启用状态和比例：启用时显示 ↓ 自动滚动 70%，禁用时显示 ↻ 自动滚动 70%。点击可打开设置菜单。
