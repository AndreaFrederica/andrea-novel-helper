写作时间统计是什么

写作时间统计会记录你在文件中实际输入的时间、字数变化和速度。它不需要手动开始计时：打开支持的文件并开始输入后，ANH 会自动进入写作会话。

从哪里打开

  • 状态栏 — 点击底部的写作统计/字数统计项，打开写作统计仪表板
  • 功能引导 — 打开 ANH 功能引导，找到“写作时间统计”卡片
  • 里程碑通知 — 达成字数里程碑后，通知按钮可以打开统计面板

状态栏怎么看

状态栏会显示当前速度、平均速度、峰值速度、累计用时和当前文件字数。显示模式可以切换为详细、半精简或精简。

  • CPM — 每分钟写了多少字
  • CPH — 每小时写了多少字
  • 笔形标记 — 当前正在写
  • 睡眠标记 — 超过闲置阈值后暂停计时

仪表板有什么

  • 全文件累计用时 — 项目里所有有统计数据的文件累计写作时间
  • 今日已码用时 — 今天实际写作的时间
  • 今日平均/峰值速度 — 今日速度统计
  • 当前文件速度曲线 — 当前活动文件的 CPM 曲线
  • 今日按小时 — 今天每小时写了多少字
  • 今日热力图 — 24 小时 × 4 刻钟的细粒度分布
  • 7 天窗口、月度统计、年度热力图 — 查看长期写作节奏

粘贴内容怎么算

默认情况下，大段粘贴不会计入写作速度，但会计入新增字数。这样可以避免复制资料时把速度冲得很高。你可以在设置里改变这个行为。

数据保存在哪里

统计数据保存在 novel-helper/.anh-fsdb/。项目初始化向导会询问这个目录是否纳入 Git 版本控制；一般个人本地统计可以忽略，跨设备同步时再考虑纳入。

会话判定

TimeStats 监听文本变更、活动编辑器、窗口焦点、文档关闭/保存/重命名等事件。只有文件系统中的工作区文件会进入统计，未命名文件、输出面板、非工作区路径会跳过。

  • 支持语言：默认 markdown 和 plaintext，由 AndreaNovelHelper.timeStats.enabledLanguages 控制
  • 闲置阈值：idleThresholdMs 默认 30000ms，超过后停止当前会话
  • 退出闲置：exitIdleOn 可设为 text-change、window-focus、editor-change
  • 输入法防抖：imeDebounceMs 默认 350ms，避免中文输入法预编辑状态误计
  • 预览/批注面板：预览和批注面板获得焦点时不会直接打断写作统计

状态栏模式

状态栏由 TimeStats 创建，但显示选项放在 AndreaNovelHelper.wordCount 下：

  • AndreaNovelHelper.wordCount.statusBar.mode — detailed 显示当前/平均/峰值速度、用时和详细字数；semi 显示速度和总字数；compact 只显示总字数
  • AndreaNovelHelper.wordCount.statusBar.speedUnit — cpm 或 cph
  • AndreaNovelHelper.wordCount.primaryUnit — 词计、含标点、不含标点
  • AndreaNovelHelper.timeStats.statusBar.alignment / priority — 状态栏位置和优先级

仪表板数据来源

仪表板会优先读取项目级写作统计摘要；如果摘要不可用，会退回到文件追踪概览；再不行则只显示当前文件。标题旁会显示“跨文件汇总”“跨文件粗略汇总”或“仅当前文件”。

  • 当前文件速度曲线：来自当前文件的时间桶数据
  • 今日统计：聚合今天的会话、时间桶和新增字数
  • 热力图：按日期或 15 分钟粒度聚合新增字数
  • 面板设置：可调整图表色系、按钮色系、显示组件和组件顺序

粘贴判定

  • AndreaNovelHelper.timeStats.pasteThresholdChars — 一次变更新增字符数达到阈值，或包含换行时，视为粘贴
  • includePasteInSpeed — 粘贴是否计入速度，默认 false
  • includePasteInAddedCounters — 粘贴是否计入新增字数，默认 true
  • includePaste — 旧的统一开关；设置后会覆盖上面两个拆分配置

里程碑

里程碑按文件记录，只有从未达成过的目标会触发通知；达成记录会持久化，避免每次打开都重复提醒。

  • AndreaNovelHelper.timeStats.milestone.enabled — 开关，默认开启
  • AndreaNovelHelper.timeStats.milestone.targets — 目标字数数组，默认包含 1000、2000、5000、10000、20000、50000、100000
  • AndreaNovelHelper.timeStats.milestone.notificationType — information 或 modal
  • 快速配置：打开 ANH 快速设置，选择“配置：字数里程碑提醒”

大文件与忽略规则

  • 大文件近似：超过 timeStats.largeFile.thresholdBytes 且开启 largeFile.approximate 时，先用近似值，之后按变更次数或时间间隔做精确校准
  • 超大文件提示：超过 AndreaNovelHelper.hugeFile.thresholdBytes 会提示已启用近似统计
  • .wcignore：timeStats.respectWcignore 默认关闭；开启后被 .wcignore 忽略的文件不进入全局写作统计
  • 只读会话：persistReadOnlySessions 控制只读场景是否持久化

导出与调试

  • AndreaNovelHelper.exportTimeStatsCSV — 导出当前文件的时间统计 CSV 到 novel-helper/
  • AndreaNovelHelper.timeStats.debug — 输出 TimeStats 调试日志
  • AndreaNovelHelper.timeStats.bucketSizeMs — 速度和热力图时间桶大小，默认 60000ms
  • AndreaNovelHelper.timeStats.typoDelay.enabled / windowMs — 连续编辑时延迟错别字扫描请求
TimeStats 统计的是“活动输入造成的变化”。如果你用外部工具批量改文件，字数统计会更新文件总字数，但写作时间统计不会把外部批量改动当成一次写作会话。
