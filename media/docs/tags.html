标签系统是什么

标签系统让你用 #标签名 的方式给文档中的内容打标签，并且可以把标签和角色绑定起来。绑定后，标签就和角色关联了——在标签浏览器里能看到角色信息，角色追踪里也能看到标签。

标签和角色怎么关联

有两种方式：

  1. 自动匹配 — 如果标签名和某个角色的名字或别名相同，ANH 会自动关联
  2. 手动绑定 — 在标签浏览器里右键标签，选择"绑定到角色"，从列表中选择目标角色

怎么使用标签

在 Markdown 文件里直接写 #角色名 就行了。ANH 会自动识别标签，并在标签浏览器侧边栏中列出所有标签。

标签浏览器

在活动栏点击标签图标可以打开标签浏览器。它会：

  • 列出项目中所有用到的标签
  • 显示每个标签在哪些文件中出现
  • 显示已绑定的角色信息
  • 支持按类型或颜色分组

标签支持的操作

  • 绑定角色 — 把标签关联到一个已有角色
  • 解绑角色 — 取消标签和角色的关联
  • 从标签创建角色 — 如果标签没有对应角色，可以直接创建一个
  • 跳转到文件 — 打开标签所在的文件
  • 查看引用 — 查看标签在哪些地方被使用

标签-角色桥接

标签系统的核心实现在 src/language/tagRoleBridge.ts，通过持久化的绑定文件 novel-helper/.anh-fsdb/tag-role-bindings.json 存储标签到角色 UUID 的映射。

标签解析优先级

当遇到一个标签时，ANH 按以下顺序尝试解析对应角色：

  1. 显式绑定 — 检查 tag-role-bindings.json 中是否有该标签的绑定记录
  2. 名字匹配 — 将标签名（去掉 #）与角色 name 字段比对（大小写不敏感）
  3. 别名匹配 — 将标签名与角色 aliases 数组中的值比对

标签路径解析

标签支持路径语法 #父级/标签名。ANH 会取路径最后一段作为角色名候选，前面的部分作为归属信息。例如 #势力/博丽 会解析出角色名候选"博丽"和归属"势力"。

绑定数据格式

{
  "version": 1,
  "bindings": {
    "博丽灵梦": {
      "tag": "博丽灵梦",
      "roleUuid": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
      "roleNameSnapshot": "博丽灵梦",
      "createdAt": 1700000000000,
      "updatedAt": 1700000000000
    }
  }
}

相关命令

  • andrea.tags.refresh — 刷新标签索引
  • andrea.tags.openFile — 打开标签所在文件
  • andrea.tags.showReferences — 查看标签引用
  • andrea.tags.createRoleFromTag — 从标签创建角色
  • andrea.tags.bindRole — 绑定标签到角色
  • andrea.tags.unbindRole — 解绑标签和角色
  • andrea.tags.openRole — 打开标签关联的角色文件

标签补全

在编辑器中输入 # 后会触发标签补全，列出项目中所有已知标签。这由 src/language/obsidianCompat.ts 中的 ObsidianCompletionProvider 提供。

配置

标签-角色绑定数据存储在工作区的 novel-helper/.anh-fsdb/tag-role-bindings.json 中。该文件支持版本号，便于后续格式升级。

标签系统与 Obsidian 的标签语法兼容。如果你有从 Obsidian 迁移过来的笔记，里面的标签可以直接被 ANH 识别和使用。
