这是什么文件

.wcignore 是 ANH 的字数统计 / 文件扫描忽略清单。它不是 Git 文件，而是给 ANH 自己用的。

它和 .gitignore 的区别

最简单的理解是：

  • .gitignore 决定“Git 看不看”
  • .wcignore 决定“字数统计和某些 ANH 文件选择逻辑算不算”

初始化时常见内容

.vscode/
.out-of-code-insights/

为什么要忽略这些目录

  • .vscode/：工作区配置，不应该混进正文统计
  • .out-of-code-insights/：扩展数据目录，不属于创作正文

什么时候你应该改它

  • 你有素材目录、备份目录，不想被统计
  • 你把导出文件放在项目里，不想影响字数
  • 你想让大纲重定向 / 文件选择器避开某些目录
如果你发现字数统计莫名其妙多了很多，先不要怀疑正文，先检查是不是没把素材或导出目录写进 .wcignore。

它会影响哪些地方

  • 启用相关配置后，影响字数统计是否把某些路径计入
  • 影响某些文件浏览 / 选取命令对路径的过滤
  • 不影响 Git 跟踪，不影响远端同步

常见用法

.vscode/
.out-of-code-insights/
exports/
archive/
assets/reference/

推荐策略

  • 把“非正文、非创作资产”的目录放进去
  • 别把真正章节目录误忽略掉
  • 项目结构一变，就回头检查一次

常见误区

  • 以为写进 .wcignore 以后 Git 也会忽略
  • 把当前写作目录也忽略了，导致统计变成 0
  • 素材目录和正文目录混在一起，结果很难精确过滤
