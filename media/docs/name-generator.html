名字生成器是什么

名字生成器帮助你快速生成符合不同文化背景的角色名字。当你为角色起名犯难时，可以按文化、性别、风格批量生成候选名，从中挑选或直接插入到角色文件中。

如何使用

  1. 打开命令面板（Ctrl+Shift+P）
  2. 输入"生成随机名字"或"Generate Random Names"
  3. 按提示选择文化背景、性别、风格和数量
  4. 从生成结果中选择喜欢的名字

快速生成

如果不想一步步选择，可以使用"快速生成名字"命令，它会用默认设置直接生成 5 个名字供你挑选。

支持的文化

名字生成器支持 30+ 种文化背景，包括中文（简体/繁体）、英文（美式/英式）、法文、德文、西班牙文、意大利文、葡萄牙文、俄文、日语、韩文、阿拉伯文、印地文、北欧语言、东欧语言等。

生成风格

  • 现代 — 当代常见名字
  • 经典 — 传统/古典风格名字
  • 奇幻 — 奇幻小说风格名字
  • 科幻 — 科幻作品风格名字（仅英文）
  • 历史 — 历史时期风格名字

角色生成

除了单独生成名字，还可以使用"随机生成角色"命令一次性生成包含名字、性别等信息的完整角色。"分步生成角色"命令则会逐步引导你完成角色创建。

名字生成服务

名字生成基于 src/services/nameGeneratorService.ts 实现，使用可插拔的策略架构。内置三种生成策略：

  • Faker 本地化策略 — 基于 @faker-js/faker，支持所有 faker 本地化，是大部分文化的默认策略
  • 奇幻策略 — 从音节库组合生成奇幻风格名字，支持高等奇幻和黑暗奇幻子风格
  • 回退策略 — 当其他策略失败时使用的基础名字列表

命令列表

  • andrea-novel-helper.generateRandomNames — 打开完整对话框，逐步选择文化、性别、风格、数量
  • andrea-novel-helper.quickGenerateName — 用默认设置快速生成 5 个名字
  • andrea-novel-helper.generateRandomCharacter — 随机生成完整角色
  • andrea-novel-helper.generateStepByStepCharacter — 分步引导生成角色
  • andrea-novel-helper.showNameGeneratorStats — 显示生成统计信息

生成选项

  • culture — 文化代码（如 zh_CN、en_US、ja、fantasy）
  • gender — 性别：male、female、neutral、any
  • style — 风格：modern、classic、fantasy、sci-fi、historical、high-fantasy、dark-fantasy
  • count — 生成数量
  • includeSurname — 是否包含姓氏

生成结果字段

  • fullName — 完整名字（中文：姓+名；西方：名+姓）
  • firstName — 名字部分
  • lastName — 姓氏部分
  • culture — 文化代码
  • gender — 性别
  • style — 风格
  • origin — 生成来源（Faker/Fantasy/Fallback）
  • alternativeFullName — 替代全名（如日语的带空格版本）

中文名字特别说明

中文名字采用"姓+名"格式（如"张伟"），日语和韩语同理。西方语言采用"名 姓"格式（如"John Smith"）。日语会额外生成带空格的替代全名（如"佐藤 誠"），可用于别名字段。

依赖

名字生成依赖 @faker-js/faker 包，该包在扩展安装时自动包含。奇幻策略为内置实现，不依赖外部包。

生成的名字仅作为灵感参考。如果你需要生成更符合特定文化细节的名字，可以考虑结合 LLM 脚本进行二次加工。
