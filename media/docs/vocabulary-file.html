这是什么文件

vocabulary.* 是项目的词汇表 / 术语表。初始化默认是 novel-helper/vocabulary.json5。

默认的 vocabulary.json5 主要是起步样例。对大多数“世界观术语”“译名表”“地名表”这类资料，长期维护其实更推荐 Markdown；如果原始来源是 Excel 或表格，再优先落 CSV。

它适合放什么

  • 世界观名词
  • 组织名、地名、器物名
  • 项目内部约定译名

什么时候词汇表比角色库更合适

当条目不是“人 / 角色”，而是“概念 / 术语 / 名词”时，应该优先放词汇表，不要硬塞进角色库。

把词汇表维护好，最大的收益不是“好看”，而是整本书的专有名词能保持一致。

最小 JSON5 示例

[
  {
    name: '星辉议会',
    type: '词汇',
    aliases: ['议会'],
    description: '世界观中的核心组织',
  }
]

推荐做法

  • 术语统一放一个地方，不要在正文里临时发挥
  • 别名写全，帮助补全和检索
  • 如果有中英 / 多语写法，可以配合索引键字段管理
  • 如果你是长期手工维护，优先考虑 vocabulary.md
  • 如果你是从表格导入，先用 vocabulary.csv，后面再决定要不要转 Markdown
