Patchouli 新预览是什么

Patchouli 新预览是 ANH 新增的阅读器式预览面板，基于 AndreaFrederica/patchouli.js 改造并作为本项目的本地子包集成。它保留 ANH 原预览的核心能力，同时提供更接近阅读器的滚动和分页体验。

如果你只是想模拟小说网站发布效果，继续使用普通写作预览也可以；如果你需要更强的分页、页边距、角色 hover 和阅读器设置，可以打开 Patchouli 新预览。

如何打开

  1. 打开一篇 Markdown 或 TXT 正文。
  2. 按 Ctrl+Shift+P 打开命令面板。
  3. 输入 Patchouli 预览，选择 打开 Patchouli 预览。

命令 ID：myPreview.openPatchouli。打开后，预览面板会跟随当前编辑器中的文章切换，并能被 ANH 的分组锁识别为预览窗口。

右下角设置

点击右下角齿轮可以打开设置面板。新预览的设置和老预览相互独立，不会互相覆盖。

  • 外观：字体、字号、行间距、段落间距、页面宽高、主题。
  • 页边距：支持上、右、下、左分别调整，也可以锁定上下或左右成组联动。
  • 显示方式：滚动模式和分页模式。
  • Markdown：标题、列表、粗体、斜体、引用、代码等样式可分别开关。
  • 角色：角色着色、类型过滤、Hover 模式和 Hover 内容量。
  • 调试：可查看分页数量、页面高度、内容分组等调试信息。

角色 Hover

角色着色开启后，鼠标悬停在角色名上可以查看角色信息。Hover 有三种模式：

  • 自定义：使用 ANH 自己绘制的浮层，位置会尽量贴近鼠标并利用可用屏幕空间。
  • 原生：使用浏览器默认 title 提示。
  • 关闭：不显示 Hover。

自定义 Hover 还可以调整内容量：精简、标准、完整。完整模式会显示更多调试字段，内容太长时会在浮层内部滚动。

分页和滚动

  • 滚动模式：连续阅读，可以用鼠标滚轮上下滚动。
  • 分页模式：按页面高度切分内容，可以用底部翻页按钮、键盘或鼠标滚轮翻页。
  • 同步：编辑器滚动时，预览会尝试同步到相近位置。

如果分页数量明显不对，可以在设置面板的调试区域查看 totalPages、pageHeight、sourceChildren、groups 等字段。

实现说明

Patchouli 新预览由三层组成：

  • packages/patchouli-reader：本地子包，封装从 Patchouli.js 改造来的阅读器组件。
  • packages/webview/src/pages/PatchouliPreviewPage.vue：ANH webview 页面，负责设置、TTS、角色着色、Hover、滚轮翻页和 VS Code 消息交互。
  • src/Provider/view/previewPane.ts：VS Code 侧面板管理，负责打开、恢复、跟随活动文档、发送 HTML 和角色高亮信息。

与普通预览的关系

普通预览仍然存在，Patchouli 新预览是独立入口。两者的设置、面板状态和 webview 路由彼此分离。普通预览继续用于轻量发布效果确认；Patchouli 新预览用于更完整的阅读器式调试。

角色着色和 Monaco 保持一致

新预览的角色高亮数据由 VS Code 扩展侧统一计算，复用与 Monaco 编辑器一致的角色匹配范围。预览页面只负责把这些范围映射回渲染后的文本节点，避免预览和编辑器使用两套不同的正则规则。

Markdown 代码块规则

ANH 的定制 Markdown 解析规则中，只有围栏代码块（例如 ```）会被当成代码块。单纯由空格或 Tab 缩进的行会作为带缩进的正文处理，以适配小说正文中常见的缩进写法。

调试建议

  • 分页异常时，先看设置面板中的调试 JSON，确认 totalPages、pageStarts 和 maxElementHeight 是否合理。
  • 需要命令行复现时，可以使用 scripts/preview-pagination-smoke.js 读取指定 Markdown 文件进行分页烟测。
  • 角色着色异常时，先确认角色着色开关、类型过滤和 Hover 模式；再对比 Monaco 编辑器中的高亮结果。

Patchouli.js 资源
