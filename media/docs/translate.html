翻译功能是什么

ANH 的翻译功能可以帮你把选中的文字翻译成其他语言。就像选中一段文字，右键选择"翻译"，然后选择目标语言。

使用方式

  1. 在编辑器中选中一段文字
  2. 右键 → "翻译选中文本"
  3. 选择目标语言（如 English / 日本語 / 한국어）
  4. 选择处理方式：
    • 替换选区 — 直接覆盖原文
    • 在新标签页显示 — 保留原文，译文新开一个页面
    • 复制到剪贴板 — 译文复制到剪贴板

需要什么前提

翻译使用 AI 大语言模型完成，所以你需要先配置好 AI 接口：

  1. 打开 ANH 设置
  2. 找到"拼写检查"分类下的 clientLLM 设置
  3. 开启 typo.clientLLM.enabled
  4. 填写 API 地址、密钥和模型名称

配置好后，翻译功能就能直接使用了，不需要额外设置。

姓名会智能处理

中译英时，ANH 会自动保留角色的姓名特征。比如"博丽灵梦"会译为"Hakurei Reimu"而不是字面意思。

使用方式

ANH 的翻译功能集成在编辑器右键菜单中：

  • 选中文本 → 右键 → "翻译选中文本"（命令 andrea.typo.translateSelection）
  • 翻译结果的处理方式：
    • 替换选区 — 直接用译文覆盖选中的原文
    • 在新标签页显示 — 打开新编辑器标签页展示译文，保留原文不变
    • 复制到剪贴板 — 译文进入剪贴板，原文不变

语言与模型

翻译通过 LLM 实现，使用与校对系统相同的客户端 LLM 配置（AndreaNovelHelper.typo.clientLLM.*）。这意味着你不需要单独配置翻译服务的 API 密钥——只要配置好了 typo 的 clientLLM，翻译就能直接使用。

支持的目标语言由配置中的 targets 数组决定，常见如中、英、日、韩、德、法等。

配置项

  • AndreaNovelHelper.translate.targets — 目标语言列表（字符串数组），如 ["en", "ja", "ko"]
  • AndreaNovelHelper.translate.defaultTarget — 默认目标语言，如 "en"
  • AndreaNovelHelper.translate.alwaysUseDefaultTarget — 是否始终使用默认目标语言，跳过语言选择步骤
  • AndreaNovelHelper.translate.defaultAction — 默认处理方式：
    • replaceSelection — 替换选区
    • openInNewTab — 在新标签页显示
    • copyToClipboard — 复制到剪贴板
  • AndreaNovelHelper.translate.alwaysUseDefaultAction — 是否始终使用默认处理方式，跳过处理方式选择

姓名翻译与罗马字

ANH 内置了 LLM 姓名翻译和罗马字转写功能：

  • 中译英时，会自动保留角色的姓名特征（如"博丽灵梦" → "Hakurei Reimu"）
  • 支持日文名的罗马字转写
  • 支持文化映射，确保翻译结果符合目标语言的文化习惯

使用示例

假设你配置好了 clientLLM，然后：

  1. 在编辑器中选中一段中文：「今天天气真好，我们去神社吧。」
  2. 右键 → "翻译选中文本"
  3. 如果配置了多个目标语言，弹出选择列表（如 English / 日本語 / 한국어）
  4. 如果配置了多个处理方式，弹出选择列表（替换 / 新标签页 / 复制）
  5. 选择后等待 LLM 返回译文
翻译功能依赖 clientLLM 配置。如果翻译不可用，请检查 AndreaNovelHelper.typo.clientLLM.enabled 是否为 true，以及 apiBase/apiKey/model 是否配置正确。
