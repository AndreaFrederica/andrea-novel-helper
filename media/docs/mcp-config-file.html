这是什么文件

mcp.json 是项目里给 MCP 服务用的配置文件。就 ANH 当前实现来说，内置 MCP 配置编辑入口默认操作的是 novel-helper/mcp.json。

它解决什么问题

它告诉 ANH：有哪些 MCP 服务器、默认用哪个、每个服务器是 HTTP 还是 stdio、是否启用。

最小示例

{
  "mcpServers": {
    "chrome-mcp-server": {
      "type": "streamableHttp",
      "url": "http://127.0.0.1:12306/mcp",
      "enabled": true
    }
  },
  "defaultServer": "chrome-mcp-server"
}

最常见的字段

键 作用
mcpServers 所有可选 MCP 服务的集合
defaultServer 默认使用哪一个服务
type 常见是 streamableHttp 或 stdio
url HTTP 型 MCP 服务地址
command / args stdio 型 MCP 的启动命令
enabled 是否启用该服务
如果你现在并不用 MCP，可以先忽略这页。它属于高级配置，不是 ANH 基础写作流程的前置条件。

两种最常见接法

  • streamableHttp：已有本地或远程 HTTP MCP 服务，直接填 URL
  • stdio：通过命令启动一个本地进程型 MCP 服务

stdio 示例

{
  "mcpServers": {
    "my-server": {
      "type": "stdio",
      "command": "node",
      "args": ["./bin/my-mcp.js"],
      "enabled": true
    }
  },
  "defaultServer": "my-server"
}

注意点

  • 内置配置文件路径默认是 novel-helper/mcp.json
  • 如果默认服务器没启用，系统会退回到第一个启用的服务
  • 写错 type、url 或命令路径时，最常见表现就是“连不上”
