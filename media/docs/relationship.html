关系图是什么

关系图是用来绘制角色之间关系的工具。就像画一张人物关系网：谁是谁的朋友、恋人、敌人，一目了然。

什么时候会用到

  • 人物众多时理清关系
  • 设计复杂的人际网络
  • 追踪关系变化（如从朋友变敌人）

如何创建

  1. 在包管理器中右键目录节点
  2. 选择"创建关系文件 (.rjson5)"
  3. 输入文件名，ANH 会自动生成模板

可视化编辑器

双击 .rjson5 文件会打开可视化编辑器：

  • 拖拽节点调整位置
  • 拖拽节点边缘的连接点创建关系线
  • 内置关系类型下拉选择：朋友、恋人、夫妻、师徒、敌对等
  • 支持单向或双向关系
  • 节点和连线都可以自定义颜色

基本结构

关系文件包含两部分：

  • 节点 — 角色（或组织、地点）
  • 连线 — 关系，标明谁和谁有什么关系

小提示

关系线用 source 和 target 表示方向。关系类型放在 data.type 里。如果你把某个节点的 roleUuid 设成角色库里的角色 UUID，就能和角色库联动。

关系文件格式（.rjson5）

角色关系图使用 .rjson5 扩展名，采用 JSON5 格式定义角色之间的关系。支持注释、尾随逗号等 JSON5 特性。

根结构：

{
  nodes: [],    // 节点数组
  lines: [],    // 关系线数组
  rootId: ""    // 可选，根节点 id
}

节点（node）字段：

  • id — 节点唯一标识（必填）
  • text — 显示名称（必填）
  • roleUuid — 关联角色的 UUID（可选，用于与角色库联动）
  • color — 节点背景色
  • borderColor — 边框颜色
  • fontColor — 文字颜色
  • nodeShape — 节点形状（如 rectangle、circle、ellipse）
  • width / height — 节点尺寸
  • x / y — 布局坐标（可视化编辑器自动管理）
  • data.sexType — 性别标记（可选）
  • data.isGoodMan — 人物善恶标记（可选）

关系线（line）字段：

  • source — 起始节点 id（必填）
  • target — 目标节点 id（必填）
  • data.type — 关系类型，如朋友、恋人、夫妻、师徒、敌对 等（必填）
  • startArrow / endArrow — 箭头开关（控制方向）
  • text — 连线描述文本
  • color — 连线颜色
  • lineWidth — 线宽
  • lineShape — 线形（如 straight、curved）
  • isDashed — 是否虚线

完整示例：

{
  nodes: [
    { id: "reimu", text: "博丽灵梦", color: "#E60033", width: 120, height: 40 },
    { id: "marisa", text: "雾雨魔理沙", color: "#FFD700", width: 120, height: 40 }
  ],
  lines: [
    {
      source: "reimu",
      target: "marisa",
      data: { type: "朋友" },
      startArrow: false,
      endArrow: false,
      text: "解决异变的搭档"
    }
  ]
}

预定义关系类型

ANH 内置了常见关系类型，在可视化编辑器中可直接选择：

  • 朋友、恋人、夫妻、父子、母子、兄弟、姐妹
  • 师徒、上司/下属、同事、同学
  • 敌对、竞争、中立、同盟

你也可以输入自定义关系类型，不受内置列表限制。

关系强度与状态

  • 关系强度 — 1 到 10 级，可在编辑器中设置。数值越高表示关系越紧密
  • 关系状态 — 活跃、不活跃、已结束。用于标记关系是否仍然有效

GUI 编辑器

ANH 为关系文件提供了可视化编辑器（RelationshipJson5EditorProvider）：

  • 节点拖拽 — 可在画布上自由拖动节点调整位置
  • 连线创建 — 拖拽节点边缘的连接点创建关系线
  • 关系类型选择 — 内置类型下拉选择，也支持自定义输入
  • 方向控制 — 通过 startArrow / endArrow 设置单向或双向关系
  • 颜色自定义 — 节点、边框、文字、连线均可自定义颜色
  • 形状切换 — 节点可在矩形、圆形、椭圆之间切换
  • 自动保存 — 布局变更自动写回 .rjson5 文件

打开方式：双击 .rjson5 文件即可打开可视化关系图编辑器。

创建关系文件

在包管理器中右键目录节点 → "创建关系文件 (.rjson5)"，输入文件名即可生成带模板的 .rjson5 文件。

关系线使用 source 和 target 表示方向，而不是 from/to。关系类型放在 data.type 中，而不是顶层字段。
