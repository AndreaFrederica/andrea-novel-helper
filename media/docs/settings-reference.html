设置总览

ANH 提供了 267 个配置项，覆盖排版、字数统计、错别字检查、角色管理、导出、同步等各个方面。所有设置都在 VS Code 的"设置"界面中（Ctrl+,），搜索 AndreaNovelHelper 或 andrea 即可找到。

如何修改设置

  1. 图形化快速设置 — 命令面板输入 "ANH: Quick Settings"，提供表单化的高频设置编辑
  2. 快速设置面板 — 按 Ctrl+Alt+I 打开，直接开关排版、字数等功能
  3. VS Code 设置界面 — Ctrl+, 搜索 AndreaNovelHelper
  4. 直接编辑 settings.json — 适合批量修改或导入导出配置

设置的作用域

大部分设置属于全局设置（个人使用习惯），保存在用户级别的 settings.json 中。少数设置（如角色文件路径）属于工作区设置，可以跟随项目走。

设置分类速查

  • 排版（andrea.typeset.*）— 自动格式化、括号配对、智能回车
  • 字数统计（AndreaNovelHelper.wordCount.*）— 统计单位、状态栏显示、性能
  • 写作时间（AndreaNovelHelper.timeStats.*）— 计时、里程碑、粘贴行为
  • 错别字检查（AndreaNovelHelper.typo.*）— LLM 配置、扫描策略、高亮
  • 角色显示（AndreaNovelHelper.docRoles.* / allRoles.* / roles.*）— 分组、排序、图标
  • 批注（AndreaNovelHelper.comments.*）— 样式、悬停、重定位
  • Typst 导出（andrea.typst.*）— 模板、输出格式、字体
  • 自动 Git（AndreaNovelHelper.autoGit.*）— 自动提交、推送、拉取
  • WebDAV 同步（AndreaNovelHelper.webdav.*）— 同步策略、忽略列表
  • 包管理器（AndreaNovelHelper.packageManager.* / package.*）— 目录可见性、拖拽
  • 翻译（AndreaNovelHelper.translate.*）— 目标语言、处理方式
  • Obsidian 兼容（AndreaNovelHelper.obsidian.*）— 双链、标签渲染
  • 脚本（AndreaNovelHelper.scripts.*）— 脚本目录、处理器
  • 数据库（AndreaNovelHelper.database.*）— 后端选择、SQLite 调优
  • 自动滚动（AndreaNovelHelper.autoScroll.*）— 滚动比例、防抖
  • 智能标签锁定（AndreaNovelHelper.smartTabGroupLock.*）— 窗体类型、排除列表
  • 补全（AndreaNovelHelper.completion.* / lookupKeys.*）— 触发模式、拼音
  • 调试（AndreaNovelHelper.debug.*）— 日志开关
以下按功能模块详细列出每个配置项的键名、类型、默认值和说明。配置键以 AndreaNovelHelper. 或 andrea. 为前缀。

排版（andrea.typeset.*）

控制保存文件时的自动格式化行为。排版功能修改文本内容本身，会影响 Git diff。

段首缩进

  • andrea.typeset.indentFirstTwoSpaces — boolean，默认 true。启用段首缩进
  • 缩进量回退到编辑器的 tabSize / insertSpaces 设置。智能避开 Markdown 标题、列表、代码块等结构

段间空行

  • andrea.typeset.blankLinesBetweenParas — integer，默认 1（范围 0-6）。段落之间插入的空行数
  • andrea.typeset.addBlanks.sentenceEnders — array[string]，默认 ["。","！","？","…","；","：","!","?",";",":","."]。句末标点列表，遇到这些标点后才可能插入空行
  • andrea.typeset.addBlanks.trailingClosers — array[string]，默认包含 」、』、》、） 等 19 个后置括号。句末标点后紧跟的括号不触发空行
  • andrea.typeset.addBlanks.leadingOpeners — array[string]，默认包含 「、『、（、《 等 10 个前导括号。段首括号不触发空行

去尾空格

  • andrea.typeset.trimTrailingSpaces — boolean，默认 true。保存时删除行尾多余空格

智能引号补全

  • andrea.typeset.enableAutoPairs — boolean，默认 true。输入左引号/括号时自动补全右引号/括号
  • andrea.typeset.pairs — array[string]，默认 ["()","[]","{}","""","''","「」","『』","《》","〈〉","（）"]。自动配对的括号对列表

智能回车与跳出

  • andrea.typeset.enableSmartEnter — boolean，默认 true。在引号/括号内按回车时自动跳出并换行
  • andrea.typeset.enableSmartExit — boolean，默认 true。输入右括号时，如果光标右侧已有相同括号则自动跳过

中文输入法修复

  • andrea.typeset.enableChineseIMEFix — boolean，默认 false。修复中文输入法与自动配对的冲突
  • andrea.typeset.chineseIMEDelay — number，默认 50（范围 0-500 毫秒）。输入法修复延迟

状态栏

  • andrea.typeset.statusBar.compact — boolean，默认 true。版式状态栏显示为简略模式
  • andrea.typeset.statusBar.alwaysShow — boolean，默认 true。始终显示版式工具条

字数统计（AndreaNovelHelper.wordCount.*）

统计单位与显示

  • AndreaNovelHelper.wordCount.primaryUnit — string，默认 "excludePunct"。首要显示单位：excludePunct（不含标点）、includePunct（含标点）、nonWSNoPunct（非空白不含标点）
  • AndreaNovelHelper.wordCount.displayFormat — string，默认 "wan"。显示格式：raw（原始数字）、wan（万）、k（千 k）、qian（千）

状态栏

  • AndreaNovelHelper.wordCount.statusBar.mode — string，默认 "semi"。detailed（详细）、semi（半详细）、compact（精简）
  • AndreaNovelHelper.wordCount.statusBar.compact — boolean，默认 false。状态栏精简模式
  • AndreaNovelHelper.wordCount.statusBar.speedUnit — string，默认 "cpm"。速度单位：cpm（字/分钟）或 cph（字/小时）

排序与索引

  • AndreaNovelHelper.wordCount.order.showIndexInLabel — boolean，默认 true。在标签中显示章节索引编号
  • AndreaNovelHelper.wordCount.order.step — number，默认 10（最小 1）。索引步长（如每 10 章编号一次）
  • AndreaNovelHelper.wordCount.order.padWidth — number，默认 3（最小 0）。索引编号宽度（前导零填充）
  • AndreaNovelHelper.wordCount.order.autoResequence — boolean，默认 true。文件变化后自动重新排序索引

忽略规则

  • AndreaNovelHelper.wordCount.respectGitignore — boolean，默认 true。写作资源管理器是否遵循 .gitignore
  • AndreaNovelHelper.wordCount.respectWcignore — boolean，默认 true。写作资源管理器是否遵循 .wcignore
  • AndreaNovelHelper.wordCount.referenceVisibleExtensions — array[string]，默认包含 58 种扩展名（tjson5、png、jpg、pdf 等）。显示为参考资料但不计入统计的文件类型

性能

  • AndreaNovelHelper.wordCount.maxWorkers — number，默认 0（自动，范围 0-128）。最大工作线程数
  • AndreaNovelHelper.wordCount.maxWorkersUpperLimit — number，默认 8（范围 1-128）。工作线程上限
  • AndreaNovelHelper.wordCount.largeFileThreshold — number，默认 51200（最小 1024）。大文件阈值（字节），超过此值使用近似统计
  • AndreaNovelHelper.wordCount.largeFileAvgBytesPerChar — number，默认 3（范围 0.5-10）。大文件平均字节数估算
  • AndreaNovelHelper.wordCount.skipStartupStatCheck — boolean，默认 false。危险选项：跳过启动时的 fs.stat 校验
  • AndreaNovelHelper.wordCount.parallelStatCheck — boolean，默认 true。启用并行批量 fs.stat 校验

写作时间统计（AndreaNovelHelper.timeStats.*）

基本配置

  • AndreaNovelHelper.timeStats.enabledLanguages — array[string]，默认 ["markdown","plaintext"]。统计启用的语言类型
  • AndreaNovelHelper.timeStats.idleThresholdMs — number，默认 30000（范围 5000-300000）。闲置阈值，超过此时间无输入则停止计时
  • AndreaNovelHelper.timeStats.bucketSizeMs — number，默认 60000（范围 10000-600000）。统计时间桶大小（毫秒）
  • AndreaNovelHelper.timeStats.imeDebounceMs — number，默认 350（范围 100-2000）。输入法防抖延迟
  • AndreaNovelHelper.timeStats.exitIdleOn — string，默认 "text-change"。退出闲置触发方式：text-change、window-focus、editor-change

里程碑

  • AndreaNovelHelper.timeStats.milestone.enabled — boolean，默认 true。启用字数里程碑通知
  • AndreaNovelHelper.timeStats.milestone.targets — array[number]，默认 [1000,2000,5000,10000,20000,50000,100000]。里程碑目标字数
  • AndreaNovelHelper.timeStats.milestone.notificationType — string，默认 "information"。通知类型：information（通知栏）或 modal（弹窗）

粘贴行为

  • AndreaNovelHelper.timeStats.includePaste — boolean，默认 false。粘贴内容是否计入统计
  • AndreaNovelHelper.timeStats.includePasteInSpeed — boolean，默认 false。粘贴是否计入速度计算
  • AndreaNovelHelper.timeStats.includePasteInAddedCounters — boolean，默认 true。粘贴是否计入新增字符统计
  • AndreaNovelHelper.timeStats.pasteThresholdChars — number，默认 32（范围 1-100000）。粘贴判定阈值，超过此字符数视为粘贴

大文件与性能

  • AndreaNovelHelper.timeStats.largeFile.thresholdBytes — number，默认 65536（最小 4096）。大文件阈值
  • AndreaNovelHelper.timeStats.largeFile.approximate — boolean，默认 true。大文件使用近似统计
  • AndreaNovelHelper.timeStats.largeFile.accurateEveryChanges — number，默认 80（最小 5）。每 N 次变更执行一次精确统计
  • AndreaNovelHelper.timeStats.largeFile.accurateEveryMs — number，默认 60000（最小 5000）。精确统计时间间隔

错别字延迟

  • AndreaNovelHelper.timeStats.typoDelay.enabled — boolean，默认 false。启用变更时间窗口延迟发送错别字请求
  • AndreaNovelHelper.timeStats.typoDelay.windowMs — number，默认 5000（范围 100-1000000）。时间窗口时长

状态栏

  • AndreaNovelHelper.timeStats.statusBar.alignment — string，默认 "left"。对齐方式：left 或 right
  • AndreaNovelHelper.timeStats.statusBar.priority — number，默认 1（范围 -1000 到 1000）。状态栏优先级

其他

  • AndreaNovelHelper.timeStats.respectWcignore — boolean，默认 false。是否遵循 .wcignore 忽略规则
  • AndreaNovelHelper.timeStats.persistReadOnlySessions — boolean，默认 false。只读会话是否持久化
  • AndreaNovelHelper.timeStats.debug — boolean，默认 false。调试模式

错别字检查（AndreaNovelHelper.typo.*）

基本开关

  • AndreaNovelHelper.typo.enabled — boolean，默认 false。启用错别字识别与诊断
  • AndreaNovelHelper.typo.mode — string，默认 "macro"。macro（规则匹配）或 llm（大语言模型）
  • AndreaNovelHelper.typo.autoIdentifyOnOpen — boolean，默认 true。打开文档时自动识别
  • AndreaNovelHelper.typo.autoScanOnChange — boolean，默认 true。编辑变更时自动扫描
  • AndreaNovelHelper.typo.warningLevel — string，默认 "warning"。诊断级别：error、warning、information、hint

高亮显示

  • AndreaNovelHelper.typo.enableHighlight — boolean，默认 false。是否添加标黄背景
  • AndreaNovelHelper.typo.highlightColor — string，默认 "#fff3a3"。标黄背景色（CSS 颜色）
  • AndreaNovelHelper.typo.applyPartialDecorationsImmediately — boolean，默认 false。在 LLM 分段结果阶段是否立即应用高亮（避免闪烁）

角色抑制

  • AndreaNovelHelper.typo.suppressRolesMode — string，默认 "roleNameExact"。角色名抑制模式：
    • none — 不抑制
    • roleNameExact — 错字文本与角色名完全相等时抑制
    • regexContain — 被正则表达式角色完全包含整段时抑制
    • nonSensitiveIntersect — 与任意非敏感角色相交则抑制（旧版）

服务端配置

  • AndreaNovelHelper.typo.service.baseUrl — string，默认 "http://127.0.0.1:8001"。错别字服务 API 地址
  • AndreaNovelHelper.typo.timeoutMs — number，默认 30000（范围 1000-300000）。超时时间
  • AndreaNovelHelper.typo.batchSize — number，默认 30（范围 1-200）。每次批量调用的句子数
  • AndreaNovelHelper.typo.docConcurrency — number，默认 3（范围 1-10）。每个文档并发扫描的最大请求数
  • AndreaNovelHelper.typo.docGroupSize — number，默认 3（范围 1-20）。连续段落的合并扫描组大小

客户端直连 LLM

  • AndreaNovelHelper.typo.clientLLM.enabled — boolean，默认 false。使用本地直连大模型（实验功能）
  • AndreaNovelHelper.typo.clientLLM.apiBase — string，默认 "https://api.deepseek.com/v1"。Chat Completions 兼容 API Base
  • AndreaNovelHelper.typo.clientLLM.apiKey — string，默认 ""。API Key
  • AndreaNovelHelper.typo.clientLLM.model — string，默认 "deepseek-v3"。模型名称
  • AndreaNovelHelper.typo.clientLLM.temperature — number，默认 0（范围 0-2）
  • AndreaNovelHelper.typo.clientLLM.enableThinking — boolean，默认 false。启用深度思考模型的思考过程
  • AndreaNovelHelper.typo.clientLLM.thinkingProvider — string，默认 "auto"。思考参数预设：auto、glm、deepseek、qwen、custom
  • AndreaNovelHelper.typo.clientLLM.customThinkingEnabled — boolean，默认 false。自定义 thinking 字段（仅 custom 模式）
  • AndreaNovelHelper.typo.clientLLM.customThinkingEnabledValue — boolean，默认 true
  • AndreaNovelHelper.typo.clientLLM.customThinkingDisabledValue — boolean，默认 false
  • AndreaNovelHelper.typo.clientLLM.qwenThinkingMethod — string，默认 "parameter"。通义千问 thinking 控制：parameter 或 suffix
  • AndreaNovelHelper.typo.clientLLM.geminiThinkingBudget — number，默认 -1。Gemini 思考预算（-1=动态，0=禁用）
  • AndreaNovelHelper.typo.clientLLM.geminiApiFormat — string，默认 "openai"。Gemini API 格式：openai 或 native

服务端 LLM

  • AndreaNovelHelper.typo.llm.model — string，默认 "deepseek-v3"
  • AndreaNovelHelper.typo.llm.apiKey — string，默认 ""
  • AndreaNovelHelper.typo.llm.apiBase — string，默认 ""

缓存与持久化

  • AndreaNovelHelper.typo.maxDocs — number，默认 10（范围 1-200）。内存数据库最大文档数（LRU 淘汰）
  • AndreaNovelHelper.typo.keepCacheOnClose — boolean，默认 true。关闭编辑器后保留缓存
  • AndreaNovelHelper.typo.persistence.enabled — boolean，默认 false。启用持久化存储
  • AndreaNovelHelper.typo.persistence.autoCleanup — boolean，默认 true。自动清理过期数据
  • AndreaNovelHelper.typo.persistence.maxAgeDays — number，默认 30（范围 1-365）。数据最大保存天数

调试

  • AndreaNovelHelper.typo.debug.llmTrace — boolean，默认 false。输出客户端 LLM 请求与响应
  • AndreaNovelHelper.typo.debug.serverTrace — boolean，默认 false。输出服务端 HTTP 请求概要
  • AndreaNovelHelper.typo.debug.compactTrace — boolean，默认 false。调试输出压缩为单行
  • AndreaNovelHelper.typo.debug.traceMaxLen — number，默认 1200（范围 200-10000）。单条输出最大长度

角色显示

角色在不同视图中的显示方式由三组配置控制：docRoles（当前文章角色）、allRoles（全部角色）、roles（通用显示）。包管理器中的角色节点由 package.roleNodes 控制。

当前文章角色（AndreaNovelHelper.docRoles.*）

  • AndreaNovelHelper.docRoles.groupBy — string，默认 "affiliation"。分组依据：affiliation（归属）、type（类型）、none（不分组）
  • AndreaNovelHelper.docRoles.primaryGroup — string，默认 "affiliation"。第一级别分组
  • AndreaNovelHelper.docRoles.respectAffiliation — boolean，默认 true。遵循归属字段分组
  • AndreaNovelHelper.docRoles.respectType — boolean，默认 true。遵循类型字段分组
  • AndreaNovelHelper.docRoles.typeOrder — array[string]，默认 ["主角","主要角色","反派","配角","联动角色","词汇","敏感词","正则表达式","unknown"]。类型排序
  • AndreaNovelHelper.docRoles.useCustomGroups — boolean，默认 false。启用自定义分组
  • AndreaNovelHelper.docRoles.customGroups — array[object]。自定义分组规则（每项含 name、matchType、patterns）
  • AndreaNovelHelper.docRoles.details.showColorOnValue — boolean，默认 true。值行显示颜色预览色块
  • AndreaNovelHelper.docRoles.details.enableRoleExpansion — boolean，默认 true。允许角色节点展开查看详情
  • AndreaNovelHelper.docRoles.details.alwaysExpandable — boolean，默认 true。角色属性详情总是可展开
  • AndreaNovelHelper.docRoles.details.wrapColumn — number，默认 20（范围 5-200）。详情软折行宽度
  • AndreaNovelHelper.docRoles.display.useRoleSvgIfPresent — boolean，默认 false。优先使用角色 svg 字段作为图标
  • AndreaNovelHelper.docRoles.display.colorizeRoleName — boolean，默认 false。名称旁显示色块标记
  • AndreaNovelHelper.docRoles.inheritExpandedFromPrevious — boolean，默认 true。切换文档时继承上一个文档的展开集合

全部角色（AndreaNovelHelper.allRoles.*）

配置结构与 docRoles 基本一致，额外包含：

  • AndreaNovelHelper.allRoles.syncWithDocRoles — boolean，默认 true。与"当前文章角色"显示设置保持同步

角色通用显示（AndreaNovelHelper.roles.*）

  • AndreaNovelHelper.roles.details.showColorOnValue — boolean，默认 true。值行显示颜色预览
  • AndreaNovelHelper.roles.display.useRoleSvgIfPresent — boolean，默认 false。优先使用 svg 作为图标
  • AndreaNovelHelper.roles.details.alwaysExpandable — boolean，默认 true。总是可展开
  • AndreaNovelHelper.roles.details.enableWrapping — boolean，默认 true。展开后启用软折行
  • AndreaNovelHelper.roles.details.wrapColumn — number，默认 20（范围 5-200）。折行宽度
  • AndreaNovelHelper.roles.details.enableRoleExpansion — boolean，默认 true。允许展开

包管理器角色节点（AndreaNovelHelper.package.roleNodes.*）

配置结构与 roles.* 一致，控制包管理器文件子树中的角色节点显示。

批注（AndreaNovelHelper.comments.*）

  • AndreaNovelHelper.comments.authorName — string，默认 ""。作者显示名（留空用系统用户名）
  • AndreaNovelHelper.comments.showInOverviewRuler — boolean，默认 true。在概览标尺中显示标记
  • AndreaNovelHelper.comments.hoverEnabled — boolean，默认 true。悬停显示批注内容
  • AndreaNovelHelper.comments.showGutterInfo — boolean，默认 true。行号区域显示信息图标
  • AndreaNovelHelper.comments.style.mode — string，默认 "underline"。展示风格：underline（下划线）或 highlight（高亮背景）
  • AndreaNovelHelper.comments.style.underlineStyle — string，默认 "solid"。下划线样式：solid、wavy、dotted、dashed
  • AndreaNovelHelper.comments.style.underlineColor — string，默认 "#0e639c"。下划线颜色
  • AndreaNovelHelper.comments.style.highlightOffset — number，默认 0.06（范围 0-0.5）。高亮背景强度
  • AndreaNovelHelper.comments.relink.strict — boolean，默认 true。严格重定位模式
  • AndreaNovelHelper.comments.cleanup.mode — string，默认 "delete-thread"。无法重定位时的处理：delete-thread、delete-range、mark-resolved、none

翻译（AndreaNovelHelper.translate.*）

  • AndreaNovelHelper.translate.targets — array[string]，默认 ["中文","英文","日语","德语","法语","韩语","繁体中文","拉丁语","希腊语"]。可选目标语言
  • AndreaNovelHelper.translate.defaultTarget — string，默认 "中文"。默认目标语言
  • AndreaNovelHelper.translate.alwaysUseDefaultTarget — boolean，默认 false。跳过语言选择
  • AndreaNovelHelper.translate.defaultAction — string，默认 "replaceSelection"。结果处理方式：replaceSelection（替换选中）、openInNewTab（新标签）、copyToClipboard（复制）
  • AndreaNovelHelper.translate.alwaysUseDefaultAction — boolean，默认 false。跳过处理方式选择

Typst 排版导出（andrea.typst.*）

  • andrea.typst.cliPath — string，默认 "typst"。Typst CLI 路径
  • andrea.typst.templatesDir — string，默认 "${workspaceFolder}/templates/typst"。扩展外置模板目录
  • andrea.typst.externalTemplatesDir — string，默认 "${workspaceFolder}/novel-helper/templates/typst"。项目模板路径
  • andrea.typst.defaultTemplate — string，默认 "sample"。默认模板包
  • andrea.typst.defaultRenderer — string，默认 "internal"。内容生成器
  • andrea.typst.output.format — string，默认 "pdf"。导出格式：pdf、png、svg
  • andrea.typst.output.ppi — number，默认 144。PNG 导出分辨率
  • andrea.typst.pages — string，默认 ""。导出页码范围（如 2,3-6,8-）
  • andrea.typst.font.paths — array[string]，默认 []。额外字体路径
