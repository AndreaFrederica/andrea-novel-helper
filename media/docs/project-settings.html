什么是项目设置

项目设置就是小说的"配置表"，告诉 ANH 你的项目叫什么名字、角色文件放在哪里、哪些文件是角色库等。

ANH 管理两个配置文件：

  • anhproject.md — 小说的"名片"，包含名字、作者、简介等
  • project-config.json5 — 功能配置表，包含文件识别规则等

如何打开项目设置

  1. 按 Ctrl+Shift+P 打开命令面板
  2. 输入"打开项目设置"
  3. 选择后会出现一个可视化表单页面

文件识别关键词是什么

ANH 通过文件名来猜测文件类型。比如文件名包含"character"就认为是角色库，包含"sensitive"就认为是敏感词库。

你可以在项目设置里修改这些关键词，让 ANH 识别你自己命名的文件。

配置优先级

ANH 有三层配置，后面的会覆盖前面的：

  1. 插件默认值（最弱）
  2. VS Code 设置（中等）
  3. 项目配置 project-config.json5（最强）

这意味着不同小说项目可以用不同的设置，互不影响。

配置文件

项目设置管理两个核心文件，二者共同构成 ANH 的项目配置体系：

  • anhproject.md — 项目元数据，采用 Markdown 格式。包含：项目名称、作者、描述、UUID、封面图片路径、摘要、标签列表。此文件由项目初始化向导自动生成，也可手动编辑
  • project-config.json5 — 项目级功能配置，采用 JSON5 格式。包含：资源路径映射、文件识别关键词（角色/敏感词/词汇/正则四类）、默认写入目标、角色索引键等

配置优先级

ANH 采用三层配置合并策略：项目配置（project-config.json5）> VSCode 工作区设置 > 插件默认值。项目配置会覆盖同名的 VSCode 设置，这让不同项目可以使用不同的角色库路径、文件识别规则等。

文件识别关键词

在 project-config.json5 中，你可以配置四类文件识别关键词：

  • 角色关键词 — 文件名包含这些关键词时会被识别为角色库
  • 敏感词关键词 — 识别敏感词库文件
  • 词汇关键词 — 识别词汇表文件
  • 正则关键词 — 识别正则着色规则文件

关键词支持逗号、分号、换行分隔，并自动过滤 // 开头的注释行。

GUI 编辑器

项目设置页面是一个独立的 Webview 面板，以可视化表单方式编辑两个配置文件。面板包含：

  • 项目信息标签页 — 编辑 anhproject.md 中的名称、作者、描述、UUID、封面、摘要、标签
  • 项目配置标签页 — 编辑 project-config.json5 中的文件识别关键词、默认写入目标、角色索引键
  • 显示工作区根路径和两个配置文件的存在状态（存在/未创建）

修改后点击保存即可同步到文件系统。

project-config.json5 支持 JSON5 所有特性（注释、尾随逗号、无引号键），编辑时无需担心语法严格性。
