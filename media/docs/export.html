导出功能是什么

ANH 提供多种方式把你的写作内容导出为不同格式：纯文本复制、TXT 文件导出、Typst 专业排版导出（PDF/PNG/SVG/HTML）。你可以根据用途选择最合适的方式。

快速导出一览

方式 输出格式 适用场景
复制纯文本 纯文本（剪贴板） 粘贴到其他编辑器、发给朋友
导出 TXT .txt 文件 保存纯文本备份、投稿
Typst 导出 PDF / PNG / SVG / HTML 专业排版、印刷、分享

复制纯文本

把 Markdown 文档转为纯文本并复制到剪贴板。会自动去除所有 Markdown 标记（标题符号、加粗标记、列表符号等）。

  1. 打开你要复制的 Markdown 文件
  2. 如果有选中文本，只复制选中部分；没有选中则复制全文
  3. 按 Ctrl+Shift+P，输入"复制纯文本"，选择"ANH: 复制纯文本"
  4. 底部状态栏会提示"已复制纯文本"

也可以在编辑器中右键 → 选择"复制纯文本"。

导出 TXT 文件

  1. 打开你要导出的 Markdown 文件
  2. 按 Ctrl+Shift+P，输入"导出 TXT"
  3. 在弹出的保存对话框中选择保存位置
  4. 文件会以纯文本格式保存

Typst 专业排版导出

如果你需要高质量排版输出（如 PDF 印刷品），可以使用 Typst 导出。需要安装 Tinymist Typst 扩展。

  1. 打开你要导出的 Markdown 文件
  2. 按 Ctrl+Shift+P，输入"导出"
  3. 选择"ANH: 导出：使用Typst模板为PDF/图片"
  4. 按提示选择：模板 → 标题提取方式 → 输出格式 → 保存位置
  5. 导出完成后会自动打开 PDF 文件

在写作资源管理器中导出

在左侧资源管理器的"写作资源管理器"面板中，右键任意文件可以：

  • 复制纯文本 — 直接复制到剪贴板
  • 导出 TXT — 保存为纯文本文件
  • Typst 导出 — 批量导出多个文件为 PDF

在资源管理器中导出

在 VS Code 左侧资源管理器中，右键 .md 或 .txt 文件（或文件夹），选择"导出：使用Typst模板"，可以批量导出多个文件。

一、纯文本渲染

ANH 使用自研的 Markdown 纯文本渲染器（md_plain.ts），将 Markdown 转为保留段落结构的纯文本：

  • 标题符号（#）被去除，标题文字保留
  • 加粗/斜体/删除线标记被去除，文字保留
  • 列表符号被去除，文字保留
  • 引用块（>）被去除，文字保留
  • 代码块内容保留
  • 图片替换为 [image] 占位符
  • 链接只保留文字，URL 被去除
  • Obsidian 双链按显示名或文件名输出，例如 [[设定/星港|星港]] 输出为 星港
  • Obsidian 标签默认保留；关闭 AndreaNovelHelper.obsidian.renderTags 后，#标签 会从预览和导出结果中隐藏
  • \#标签 默认保持转义写法；开启 AndreaNovelHelper.obsidian.renderEscapedTags 后会输出为 #标签
  • 注释（<!-- -->、%% %%）被去除

二、纯文本复制

命令：myPreview.copyPlainText

  • 如果有选中文本，只复制选中部分的纯文本
  • 没有选中时复制全文
  • 在写作资源管理器中右键文件也可触发（WordCount.copyPlainText）
  • 预览面板中也有复制按钮

三、TXT 导出

命令：myPreview.exportTxt（预览面板）或 WordCount.exportTxt（写作资源管理器）

  • 渲染逻辑与纯文本复制相同
  • 弹出系统保存对话框，默认文件名与源文件相同，扩展名改为 .txt
  • 写入文件使用 vscode.workspace.fs.writeFile

四、Typst 导出

Typst 是现代化的排版系统，ANH 通过 Markdown → Typst → PDF/PNG/SVG/HTML 的管线实现专业排版。

导出方式：

  • 从编辑器：命令 andrea.typst.exportCurrent，编辑器标题栏右键菜单
  • 从资源管理器：命令 andrea.typst.exportFromExplorer，右键 .md/.txt 文件或文件夹
  • 从写作资源管理器：命令 AndreaNovelHelper.wordCount.exportTypst，右键文件或文件夹

导出流程：

  1. 选择模板（从 templateRegistry 列表中选择）
  2. 选择标题提取方式：
    • 提取主标题（第一个 H1）
    • 首个标题（任意级别）
    • 文件名（无扩展名）
    • 不提取主标题（不渲染标题）
  3. 选择输出格式：PDF、PNG、SVG、HTML
  4. 选择导出位置：源目录或自定义目录
  5. 编译并输出

配置项：

  • andrea.typst.defaultTemplate — 默认模板
  • andrea.typst.output.format — 默认输出格式
  • andrea.typst.output.ppi — PNG/SVG 输出分辨率
  • andrea.typst.pages — 导出页码范围
  • andrea.typst.font.paths — 自定义字体路径
  • andrea.typst.cliPath — Typst CLI 路径
  • andrea.typst.templatesDir — 模板目录
  • andrea.typst.cleanupTemp — 导出后清理临时文件
  • AndreaNovelHelper.obsidian.renderWikilinks — 预览和导出时把 [[双链]] 渲染为可读文本
  • AndreaNovelHelper.obsidian.renderTags — 预览和导出时是否保留 #标签 文本
  • AndreaNovelHelper.obsidian.renderEscapedTags — 是否把 \#标签 渲染为 #标签

Typst 导出支持的 Markdown 元数据（&Def）：

&Def Title = 小说标题
&Def Subtitle = 副标题
&Def Category = 玄幻

这些元数据会注入到 Typst 模板中，用于标题页、页眉等位置。

五、写作资源管理器的文件操作

写作资源管理器（wordCountExplorer）提供文件管理功能：

  • 复制（AndreaNovelHelper.wordCount.copy）— 复制文件到内部剪贴板
  • 剪切（AndreaNovelHelper.wordCount.cut）— 剪切文件
  • 粘贴（AndreaNovelHelper.wordCount.paste）— 粘贴到目标文件夹，自动处理重名（追加 _copy1、_copy2）
  • 支持多选操作
  • 粘贴时自动维护手动排序索引
Typst 导出需要先安装 Tinymist Typst 扩展。如果未安装，导出时会提示安装。纯文本导出和 TXT 导出不需要任何额外依赖。
