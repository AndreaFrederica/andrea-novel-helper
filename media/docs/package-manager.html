什么是包管理器

包管理器就是 ANH 的资料文件夹浏览器。你可以把它想象成一个"档案柜"，每个"抽屉"（包）里放着不同类型的资料：角色卡、敏感词表、世界观词汇等。

这张图重点看：最上面的“常用功能”是一组直达入口；“项目设置文件”是根目录配置；下面的 novel-helper 才是资源包根；展开角色文件后还能直接看到“1 个角色 / 28 个角色”这类统计。
如果你想知道的不是“这个树怎么点”，而是包到底按什么规则识别、外部包怎么被扫描出来、内部包和外部包冲突时谁生效，请直接看 包机制与外部包详解。那一页是按代码实现写的。

"包"是什么

"包"就是 novel-helper/ 文件夹下的一个子文件夹。每个文件夹可以包含任意数量的资料文件，还可以继续嵌套子文件夹。

在 UI 里你还会看到外部资源目录。它们不属于 novel-helper/，但也会作为顶层资源包显示在包管理器里。

支持哪些文件格式

  • Markdown — 最推荐的格式，就像写普通文档一样，最直观
  • JSON5 — 一种带注释的数据格式，字段最完整
  • OJSON5 / RJSON5 / TJSON5 — 角色卡、关系图、时间线的专用 JSON5 扩展名
  • CSV — 表格格式，适合从 Excel 批量导入
  • TXT — 最简单，一行一个名字
  • TOML — 结构化配置格式，清晰易读，适合手工编辑
完整格式说明见文档中心的"文件格式指南"：包含 Markdown、JSON5、OJSON5、RJSON5、TJSON5、CSV、TXT、TOML 的详细结构和示例。

ANH 如何识别资源文件

文件名关键词主要是触发包管理器把文件当作资源文件扫描和展示，不是角色类型。角色真正的类型来自文件内容里的 type / 类型 字段。

  • 文件名包含 "character" 或 "role" → 作为角色资源文件显示和扫描
  • 文件名包含 "sensitive" → 作为敏感词资源文件显示和扫描
  • 文件名包含 "vocabulary" 或 "词汇" → 作为词汇资源文件显示和扫描
  • 文件名包含 "regex" → 作为正则着色规则显示和扫描
  • 扩展名 .rjson5 → 使用关系图编辑器和关系文件逻辑
  • 扩展名 .tjson5 → 使用时间线编辑器和时间线文件逻辑
例如 vocabulary.md 里也可以有 type: 主角 的条目；文件名只影响资源入口和默认用途，不会覆盖条目自己的类型。
补一条很容易误会的事实：project-config.json5 里的 rolesFile、vocabularyFile、sensitiveWordsFile、regexPatternsFile 主要影响“新建资源时默认写到哪里”，不是包管理器的唯一扫描范围。

推荐怎么整理文件夹

    character-gallery.md      ← 主要角色
    vocabulary.md             ← 世界观词汇
  faction-a/

资源文件自动命名

新版包管理器在创建或重命名角色/敏感词/词汇资源文件时，会默认使用“名称 + 固定英文关键词”的方式命名：

  • 角色资源默认追加 _role
  • 敏感词资源默认追加 _sensitive
  • 词汇资源默认追加 _vocab

例如输入“主角设定”，默认会生成类似 主角设定_role.md。这样做的目的，是让文件既保留人类可读名称，又稳定命中资源识别规则。

这个行为由 AndreaNovelHelper.packageManager.enableAutoKeywordNaming 控制。关闭后会恢复旧行为：你自己完全决定文件名，包管理器不再自动追加固定关键词。

显示过滤与内部目录隐藏

包管理器现在支持把一部分内部目录从资源树里隐藏，避免日常写作时被工作数据打扰。默认会隐藏：

  • outline / free-outline 等大纲存储目录
  • novel-helper/comments 批注目录
  • novel-helper/typo 错别字数据目录

你也可以按需继续隐藏 novel-helper/dashboard 和 novel-helper/docs，或者关闭“显示普通资源文件”，让包管理器只保留会被识别为角色/敏感词/词汇/关系/时间线等资源的文件。

这些开关都可以在 AndreaNovelHelper.packageManager.* 里调整，也可以直接从“图形化快速设置 → 包管理器”里改。切换后包管理器会立即刷新，无需重启窗口。

角色文件变更提示

当包管理器监听到角色文件被创建、修改、删除或重命名时，可以选择是否弹出提示消息。

如果你正在做批量导入或外部脚本同步，觉得提示太频繁，可以关闭 AndreaNovelHelper.packageManager.showRoleFileChangeNotifications；默认是关闭的。

项目设置文件节点

项目设置文件节点按真实路径显示当前工作区根目录下的两个配置文件：

  • anhproject.md — 项目基础信息、书籍目录、库文件路径等
  • project-config.json5 — 资源文件名关键词、角色库/词汇库/敏感词库/正则库的识别配置

如果文件还没有创建，节点会显示"未创建"，点击会打开项目设置页，保存后生成对应文件。

什么是"包"

包管理器中的"包"就是 novel-helper/ 下的一个目录。每个目录可以包含任意数量的资源文件，支持子包嵌套。ANH 启动时会自动扫描 novel-helper/ 目录下的所有包，并解析其中的资源文件。

支持的文件格式

角色/词汇/敏感词资源文件通常使用以下格式；关系图和时间线另有专用扩展名：

  • Markdown — 用二级标题 ## 角色名 分隔角色，三级标题定义字段。最适合习惯用 Markdown 写作的作者，可读性最好
  • JSON5 — 字段最完整，支持注释、尾随逗号、单引号、无引号键。扩展名可以是 .json5 或 .ojson5（外部角色标记）。适合需要程序化生成或使用角色卡管理器的场景
  • OJSON5 — 角色 JSON5 编辑器优先打开；数据结构仍是 JSON5 角色数组
  • RJSON5 / TJSON5 — 关系图和时间线专用格式，不作为普通角色库加载
  • CSV — 标准逗号分隔值，支持表头别名映射。适合从 Excel 批量导入
  • TXT — 一行一个名称，支持 # 和 // 注释。适合最简单的列表场景
  • TOML — 结构化配置格式，用 [[roles]] 数组表定义角色。清晰易读，语法严格，适合手工编辑

更详细的字段、示例和格式选择建议请看"文件格式指南"。

文件识别规则

ANH 通过文件名关键词触发资源文件扫描、树视图归类和默认模板用途；它们不决定角色条目的真实类型。角色、词汇、敏感词、自定义类型等仍以文件内容中的 type / 类型 字段为准。

  • 角色资源触发词 — character-gallery、character、role、roles 等
  • 敏感词资源触发词 — sensitive-words、sensitive 等
  • 词汇资源触发词 — vocabulary、vocab、term、词汇、术语 等
  • 正则规则触发词 — regex-patterns 等
  • 关系文件 — 扩展名 .rjson5、.rjson
  • 时间线文件 — 扩展名 .tjson5
  • 外部角色 — 扩展名 .ojson5、.ojson

你可以在 project-config.json5 中自定义这些识别关键词。

包管理器展开资源文件时显示的角色类型来自条目字段。例如同一个 character-gallery.md 中可以同时包含 主角、配角、词汇 或自定义类型。

项目设置文件

项目设置文件节点会按真实路径列出：

  • anhproject.md — Markdown 项目配置

右键上下文菜单（目录/外部文件夹）

在包管理器中右键目录节点（package 或 externalRoleFolder 类型），弹出的上下文菜单按分组包含：

  • 创建分组：
    • 项目设置 — 打开项目配置

    • 创建敏感词库 (MD/JSON5/TXT/TOML) — 创建敏感词文件
    • 创建词汇库 (MD/JSON5/TXT/TOML) — 创建词汇表文件
    • 创建角色文件 (.ojson5) — 创建单角色定义文件，含 UUID 模板
    • 创建关系文件 (.rjson5) — 创建角色关系定义文件
    • 创建时间线文件 (.tjson5) — 创建时间线配置文件

  • 删除分组：删除节点
  • 打开分组：打开文件、Open With、在资源管理器中显示

右键资源文件节点（resourceFile 类型）时，上下文菜单包含：打开、Open With（可选择角色卡编辑器）、在资源管理器中显示、重命名、复制/剪切，以及切换角色管理器打开模式。

配置项

  • AndreaNovelHelper.package.dragDefaultAction — 拖放默认操作：move / copy / ask
  • AndreaNovelHelper.package.iconStyle — 文件图标样式：auto / theme / custom
  • AndreaNovelHelper.package.mdLibraryNameRecognition — Markdown 库名识别开关
  • AndreaNovelHelper.packageManager.enableAutoKeywordNaming — 创建/重命名资源文件时是否自动追加固定英文关键词
包管理器支持 Markdown、JSON5/OJSON5、CSV、TXT、TOML 等角色资源格式，并识别 RJSON5/TJSON5 这类专用编辑器格式。对大多数手工维护的设定，Markdown 通常最舒服；Excel / 表格来源先落 CSV；字段复杂、样式多、结构化要求高时再用 JSON5。
