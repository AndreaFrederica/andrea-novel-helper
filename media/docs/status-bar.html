状态栏是什么

状态栏是 VS Code 窗口最底部那一整条区域。ANH 会把写作时经常看的信息和经常点的按钮放在这里，例如快速设置、字数速度、错别字识别、同步状态、自动滚动等。

不会用 VS Code 也没关系：你只需要记住，底部这些 ANH 按钮通常可以点击；鼠标停在按钮上会显示说明；不想点了按 Esc 可以退出弹出的菜单。

最重要的按钮

  • 版式 / 版式和快速设置 — 打开快速设置。它是写作时最快的设置入口，比去菜单里找设置更方便
  • 写作统计 — 显示当前文件字数、速度和用时。点击会打开写作统计仪表板
  • Typo — 错别字识别状态。点击会打开错别字识别快速设置
  • ANH:Sync — Git 和 WebDAV 同步状态。点击可以查看当前同步状态
  • 自动滚动 — 控制编辑时是否自动滚到文档后部，适合边写边追随光标或直播式写作
  • 分组锁 — 控制 ANH 的智能标签组锁，避免预览、文档页等工具页被普通文件挤掉

按钮不见了怎么办

  • 有些按钮只在打开 Markdown、TXT 或支持的写作文档时显示
  • 错别字识别关闭时，Typo 按钮可能隐藏
  • Markdown 格式工具只在选中文本时临时出现
  • 翻译和角色加载状态只在任务进行中临时出现
  • 如果状态栏太挤，VS Code 可能把部分按钮挤到右侧；把窗口拉宽或关闭不需要的状态栏项即可

新手推荐

  • 写作时先看底部有没有“版式”按钮，快速设置从这里进
  • 想看今天写了多少、速度如何，点击写作统计状态栏
  • 看到 ANH:Sync 变成警告色或错误色时，先悬停看提示，再点开查看状态
  • 状态栏显示太长时，在快速设置里打开“状态栏显示”精简模式，或打开 ANH:Sync 简洁模式

状态栏总览

以下状态栏项按源码中的实际提供者整理。状态栏项的位置会受 VS Code 自身排序、窗口宽度和其他扩展影响，文档中的“左侧/右侧”表示创建时的对齐方向。

版式和快速设置

  • 来源：src/typeset/layoutStatusBar.ts
  • 显示文本：精简模式显示 $(edit) 版式和快速设置；详细模式显示缩进、首行、段距、去尾、补齐、跳出、切段等状态
  • 点击命令：andrea.quickSettings
  • 用途：打开命令式快速设置，是 ANH 写作设置的最快入口
  • 配置：andrea.typeset.statusBar.compact 控制精简/详细；andrea.typeset.statusBar.alwaysShow 控制是否始终显示
  • 显示条件：默认始终显示；关闭始终显示后，只在支持的写作文档中显示

写作统计状态栏

  • 来源：src/timeStats.ts
  • 状态栏 ID：andrea.timeStats
  • 点击命令：AndreaNovelHelper.openTimeStats
  • 用途：显示当前文档写作速度、累计用时、CJK 字数、英文单词、总字数和空闲状态；点击打开写作统计仪表板
  • 显示模式：detailed 显示当前/平均/峰值速度、用时和详细字数；semi 显示速度和总字数；compact 仅显示总字数
  • 速度单位：cpm 为字/分钟，cph 为字/小时
  • 字数口径：读取 AndreaNovelHelper.wordCount.primaryUnit，可显示词计、含标点、不含标点
  • 配置：AndreaNovelHelper.timeStats.statusBar.alignment、AndreaNovelHelper.timeStats.statusBar.priority、AndreaNovelHelper.wordCount.statusBar.mode、AndreaNovelHelper.wordCount.statusBar.speedUnit
  • Tooltip：悬停可查看当前速度、平均速度、峰值速度、累计用时、当前会话、三种字数口径、文件路径、最后活动时间、会话数和活跃/离开状态

错别字识别状态栏

  • 来源：src/typo/typoService.ts
  • 状态栏 ID：andrea.typoService
  • 显示文本：空闲时类似 $(check) Typo macro 或 $(check) Typo llm；扫描中显示 $(sync~spin) Typo ...
  • 点击命令：andrea.typo.quickSettings
  • 用途：显示错别字识别是否就绪、正在扫描、使用规则模式还是 LLM 模式
  • 显示条件：AndreaNovelHelper.typo.enabled 开启，并且当前活动编辑器是文件型 Markdown 或 plaintext 文档
  • Tooltip：显示模式、扫描状态、客户端直连 LLM 信息、持久化状态，并提示点击打开快速设置

翻译忙碌状态

  • 来源：src/typo/typoService.ts 中的 showTranslationStatus / hideTranslationStatus
  • 状态栏 ID：andrea.translationStatus
  • 显示文本：$(sync~spin) ...
  • 用途：LLM 翻译任务进行中时临时显示，任务结束后自动隐藏

ANH:Sync 同步状态

  • 来源：src/sync/autoGitService.ts
  • 状态栏 ID：andrea.autoGitSync
  • 点击命令：andrea.autoGit.showStatus
  • 显示文本：普通模式为 ANH:Sync Git:ON/OFF WebDAV:ON/OFF/SYNC；简洁模式只显示 ANH:Sync
  • 用途：集中显示 AutoGit 与 WebDAV 自动同步状态
  • 颜色：WebDAV 同步中使用突出背景；Git 和 WebDAV 都启用时使用远程背景；只启用一项时使用警告背景；都关闭时使用错误背景
  • 配置：AndreaNovelHelper.autoGit.compactStatus 控制简洁模式；AutoGit 和 WebDAV 的启用状态分别来自对应功能配置
  • Tooltip：显示 AutoGit 是否启用、WebDAV 自动同步是否启用、WebDAV 当前消息和进度

自动滚动状态栏

  • 来源：src/Provider/autoScrollProvider.ts
  • 点击命令：andrea.autoScroll.toggleMenu
  • 显示文本：自动滚动 100% 这类文本，图标区分启用和禁用
  • 用途：编辑时自动滚动到文档末尾或指定比例位置；菜单中可切换启用、设置比例、立即滚动到末尾
  • 配置：AndreaNovelHelper.autoScroll.enabled、AndreaNovelHelper.autoScroll.ratio、AndreaNovelHelper.autoScroll.debounceDelay
  • 保存位置：源码中保存为全局配置，属于个人使用习惯

智能分组锁状态栏

  • 来源：src/utils/smartTabGroupLockStatusBar.ts
  • 状态栏 ID：andrea.smartTabGroupLock
  • 点击命令：andrea.toggleSmartTabGroupLock
  • 显示文本：禁用或等待时显示 $(unlock) 分组锁；有活动锁定时显示 $(lock) 分组锁
  • 用途：提示智能标签组锁是否启用，以及当前是否有标签组被锁定
  • 配置：AndreaNovelHelper.smartTabGroupLock.enabled

Typst 预览状态栏

  • 来源：src/Provider/typstPreviewStatusBar.ts
  • 状态栏 ID：andrea.typstPreview
  • 点击命令：AndreaNovelHelper.toggleTypstPreview
  • 显示文本：未开启预览时显示 $(eye-closed) Typst预览；已开启预览时显示 $(eye) Typst预览
  • 用途：对当前 Markdown 或 plaintext 文档打开、关闭或管理 Typst 实时预览
  • 显示条件：当前活动文档是 Markdown 或 plaintext
  • Tooltip：显示文件路径、模板和渲染状态

Markdown 选区工具栏

  • 来源：src/Provider/markdownToolbar.ts
  • 状态栏 ID：andrea.markdownToolbar
  • 点击命令：AndreaNovelHelper.showMarkdownFormatMenu
  • 显示文本：$(tools) MD格式: "选中文本..."
  • 用途：选中文本后临时提供 Markdown 格式化入口，例如加粗、斜体等
  • 配置：AndreaNovelHelper.markdownToolbarEnabled
  • 显示条件：Markdown 工具条启用且当前有合适的文本选择；没有选择时隐藏

角色加载状态

  • 来源：src/utils/utils.ts 的角色库异步扫描流程
  • 状态栏 ID：andrea.characterLoading
  • 显示文本：扫描中显示 $(sync~spin) 角色加载中...；完成后短暂显示 $(check) 角色加载完成
  • 用途：提示 ANH 正在扫描 novel-helper 角色库和外部角色目录
  • 显示条件：角色库扫描耗时超过短暂延迟，或扫描完成时需要反馈；完成后约 1.5 秒自动移除

已禁用的旧状态栏

src/Provider/statusBarProvider.ts 里还有旧的写作统计/WebDAV 状态栏提供器，但 src/activate.ts 中已经注释说明“状态栏提供器 - 已禁用，使用 timeStats 中的状态栏”。实际运行时应以 timeStats.ts 和 autoGitService.ts 的状态栏为准。

状态栏太挤时

  • 开启 andrea.typeset.statusBar.compact，让版式按钮显示为精简文本
  • 开启 AndreaNovelHelper.autoGit.compactStatus，让同步按钮只显示 ANH:Sync
  • 把 AndreaNovelHelper.wordCount.statusBar.mode 改为 semi 或 compact
  • 不常用的功能可以在对应设置里关闭，例如错别字识别、Markdown 工具条、自动滚动等
  • VS Code 自身支持右键状态栏隐藏部分状态项；如果误隐藏，可从 VS Code 的状态栏自定义菜单重新显示
