敏感词检测是什么

敏感词检测就像你写作时的自动审查员。如果你在文中写了某些敏感词，ANH 会在这些词下面画波浪线提醒你，并提供一键替换建议。

为什么需要这个功能

  • 有些平台对特定词汇有限制，提前检查可以避免发布后出问题
  • 提醒自己避免使用某些不合适的表达
  • 快速批量替换为更合适的说法

如何创建敏感词库

  1. 在包管理器中右键目录节点
  2. 选择"创建敏感词库 (MD/JSON5/TXT)"
  3. 选择 Markdown 格式（推荐）
  4. 输入文件名，比如 sensitive-words.md

敏感词格式示例（Markdown）

# 敏感词库

## 暴力

### 类型
敏感词

### 修复
打斗
冲突

### 优先级
2

### 颜色
#FF4D4F

### 别名
bao力

关键字段说明

  • 名称 — 敏感词本身
  • 别名 — 变体写法，比如拼音、谐音
  • 修复 — 建议替换的词，可以写多个
  • 颜色 — 高亮显示的颜色
  • 优先级 — 严重程度，数字越小越严重

如何使用

  1. 在编辑器中写文时，敏感词会自动标记波浪线
  2. 点击波浪线或旁边的 💡 灯泡图标
  3. 选择"替换为：xxx"一键替换

角色名不会被误报

如果你把某个词同时设成了角色名和敏感词，ANH 会智能判断，不会在你的角色名上画波浪线。

工作原理

敏感词本质上是 type: '敏感词' 的角色。ANH 使用 Aho-Corasick 自动机对编辑器文本进行实时扫描，匹配 name 和 aliases 字段。匹配到的词汇会在编辑器中用波浪线诊断标记（Diagnostic）高亮显示。

敏感词检测具有以下特性：

  • 实时检测 — 输入时即时标记，延迟极低
  • 角色名误报抑制 — 如果某个"敏感词"实际上是你作品中已定义的角色名，ANH 会自动跳过，避免误报
  • 大文件保护 — 当文件超过 AndreaNovelHelper.hugeFile.thresholdBytes（默认 51200 字节，约 50KB）时，自动降级为轻量模式
  • 分词过滤 — 角色的 wordSegmentFilter 字段可避免单字误匹配

文件格式规范

敏感词库支持 Markdown、JSON5、CSV 三种格式（不支持纯 TXT），命名规则为 sensitive-words.md 或 *_sensitive.md。

Markdown 格式示例：

# 敏感词库

## 暴力

### 类型
敏感词

### 修复
打斗
冲突

### 优先级
2

### 颜色
#FF4D4F

### 别名
bao力

JSON5 格式示例：

[
  {
    name: "暴力",
    type: "敏感词",
    aliases: ["bao力"],
    fixes: ["打斗", "冲突"],
    replacements: ["打斗"],
    priority: 2,
    color: "#FF4D4F",
    wordSegmentFilter: true
  }
]

关键字段

  • name — 敏感词本身，必填
  • aliases — 敏感词的别名变体，如拼音、谐音、缩写
  • fixes / fixs / fix / replacements / replacement — 修复建议列表。右键点击编辑器中的敏感词标记时，会弹出 Quick Fix 菜单，可一键替换为建议词
  • priority — 严重级别，影响标记颜色。数字越小优先级越高，默认 999
  • color — 敏感词的高亮颜色
  • wordSegmentFilter — 是否启用分词过滤，避免单字误匹配

fixes 字段兼容性

ANH 对修复字段有广泛的兼容处理：字段名可以是 fixes、fixs、fix、replacements、replacement，解析时会统一处理为修复候选数组。当你将某个词汇标记为敏感词并提供了修复值后，其他角色的 fixes 值被匹配时不会触发敏感词警告。

创建敏感词库

在包管理器中右键目录节点 → "创建敏感词库 (MD/JSON5/TXT)"，选择格式（推荐 Markdown 或 JSON5），输入文件名即可创建。创建后会自动打开文件供你编辑。

配置项

  • AndreaNovelHelper.sensitiveWordsFile — 默认敏感词文件路径（默认 novel-helper/sensitive-words.json5）
  • AndreaNovelHelper.sensitiveWords.warningLevel — 诊断级别（error/warning/information/hint，默认 error）

GUI 编辑器

敏感词可以通过角色卡编辑器进行可视化编辑。在编辑器中将类型设为"敏感词"后，界面会显示专属的"修复词"输入框，支持逐行添加修复建议。编辑器按 VS Code 的 autoSave 策略保存。

敏感词也支持角色名误报抑制 — 如果某个"敏感词"实际上是你作品中的角色名，ANH 会自动跳过。这避免了正常角色名被错误标记的尴尬。
