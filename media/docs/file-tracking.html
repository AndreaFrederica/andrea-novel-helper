文件追踪是什么

文件追踪是 ANH 的底层功能，自动记录项目中所有文件的创建、修改、删除和重命名。这些追踪数据被多个上层功能使用，比如写作统计、写作仪表板和数据同步。

它在后台工作

文件追踪是自动运行的，你不需要手动操作。它会：

  • 监听工作区内所有文件的变化
  • 按照忽略规则跳过不需要追踪的文件
  • 记录每个文件变化的时间、大小等信息

哪些文件会被追踪

  • 所有 Markdown (.md) 和纯文本 (.txt) 文件
  • 角色文件（.json5, .ojson5 等）
  • 其他项目相关文件

哪些文件会被忽略

  • 符合 .gitignore 规则的文件
  • 符合 .ftignore 规则的文件
  • node_modules、.git 等标准忽略目录

实现

文件追踪由 src/utils/tracker/fileTracker.ts 和 src/utils/tracker/fileTrackingData.ts 实现。

文件追踪器配置

  • workspaceRoot — 工作区根目录
  • respectGitignore — 是否遵循 .gitignore（默认 true）
  • includePatterns — 包含模式（glob）
  • excludePatterns — 排除模式（glob）

.ftignore 文件

与 .gitignore 语法相同的忽略文件，专门用于文件追踪的排除规则。在工作区根目录创建 .ftignore 即可使用。

事件类型

  • create — 文件创建
  • change — 文件修改
  • delete — 文件删除
  • rename — 文件重命名（包含旧路径）

追踪数据

每个文件变化事件包含：

  • type — 变化类型
  • filePath — 文件路径
  • oldPath — 旧路径（仅重命名时）
  • timestamp — 时间戳
  • size — 文件大小
  • mtime — 修改时间

相关命令

  • AndreaNovelHelper.showFileTrackingStats — 显示追踪统计
  • AndreaNovelHelper.fileTracking.repairPathKeys — 修复路径键
  • AndreaNovelHelper.fileTracking.cleanAbsolutePaths — 清理绝对路径
  • AndreaNovelHelper.exportTrackingData — 导出追踪数据
  • AndreaNovelHelper.gcFileTracking — 垃圾回收追踪数据
  • AndreaNovelHelper.cleanupMissingFiles — 清理不存在的文件记录

配置

  • AndreaNovelHelper.fileTracker.ignoredDirs — 额外忽略的目录
  • AndreaNovelHelper.fileTracker.verboseLogging — 是否开启详细日志
