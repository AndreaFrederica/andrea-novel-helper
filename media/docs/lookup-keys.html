检索词是什么

检索词是角色的搜索关键字，用于在编辑器中输入时快速匹配和补全角色名。比如角色"博丽灵梦"的检索词可以是"灵梦"、"Reimu"、拼音"lingmeng"等。

为什么需要检索词

  • 角色全名太长时，用简称也能快速找到
  • 外文角色可以用原文名搜索
  • 拼音检索词让你用拼音首字母也能匹配

怎么设置

在角色文件中添加检索词字段即可：

## 博丽灵梦

### 类型
主角

### 检索词
灵梦
Reimu
lingmeng

自动生成

ANH 可以自动生成拼音和罗马字检索词，无需手动输入。在设置中开启即可。

检索词前缀

ANH 识别以下字段名作为检索词（大小写不敏感）：

  • lookupKeys / lookupKey
  • searchKeys / searchKey
  • queryKeys / queryKey
  • keywords / keyword
  • 查询键 / 查询词
  • 检索键 / 检索词
  • 索引键 / 索引词
  • 反查键 / 反查词
  • 关键词 / 关键字

检索词类型

  • 通用（generic）— 任意文本检索词
  • 拼音（pinyin）— 字段名含 pinyin 或 拼音
  • 罗马字（romanized）— 字段名含 romanized
  • 拼写（spelling）— 字段名含 spelling

自动生成配置

  • AndreaNovelHelper.lookupKeys.autoGeneratePinyin — 自动生成拼音检索词
  • AndreaNovelHelper.lookupKeys.autoGenerateRomanized — 自动生成罗马字检索词

扩展检索词前缀

可以通过 project-config.json5 中的 extendedLookupKeyPrefixes 添加自定义的检索词字段名：

{
  extendedLookupKeyPrefixes: ["别名键", "aliasKey"]
}

实现

检索词系统由 src/utils/roleLookupKeys.ts 和 src/utils/roleLookupKeyGeneration.ts 实现。检索词在角色加载时自动提取，用于补全和搜索匹配。
