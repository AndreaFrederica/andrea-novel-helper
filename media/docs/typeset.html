排版功能是什么

排版功能就是 ANH 的自动格式化工具。保存文件时，它会自动帮你调整格式，让文档看起来更整洁。

支持的功能

  • 首行缩进 — 自动给段落开头加两个空格（或按设置调整）
  • 段间空行 — 自动在段落之间插入空行，避免文字挤在一起
  • 去尾空格 — 删除每行末尾多余的空格
  • 智能引号 — 输入引号或括号时自动配对
  • 智能回车 — 在引号内按回车时自动处理换行
  • 跳出括号 — 输入右括号时如果后面已有相同括号，自动跳过

如何调整

按 Ctrl+Alt+I 打开快速设置面板，可以直接开关各项排版功能、调整空行数。不需要翻复杂的设置页面。

重要提示

排版功能会修改文件内容本身（不只是显示效果），所以会影响 Git 的变更记录。建议先确认这些规则符合你的写作习惯再开启。

排版功能详解

ANH 的排版辅助功能在保存文件时自动执行，也可通过底部状态栏快速开关。所有排版功能都支持独立启用/禁用：

1. 首行缩进

  • andrea.typeset.indentFirstTwoSpaces — 布尔开关，控制是否启用首行缩进
  • 缩进量由 andrea.typeset.firstLineIndentSpaces 控制（未在 package.json 注册，但代码中使用），或回退到编辑器的 tabSize / insertSpaces 设置
  • 智能避开 Markdown 结构（标题、列表、代码块等）

2. 段间空行

  • 自动在段落之间插入空行，保持阅读节奏
  • 支持配置空行数（0-6），通过快速设置面板或 andrea.typeset.blankLinesBetweenParas 调整
  • 智能合并多余空行，避免连续多个空行
  • 可自定义句末标点 addBlanks.sentenceEnders 和前后括号列表

3. 去尾空格

  • 保存时自动删除行尾空格
  • 配置项：andrea.typeset.trimTrailingSpaces

4. 智能引号补全

  • 输入引号或括号时自动配对
  • 支持多种引号对，通过 andrea.typeset.pairs 配置（数组或字符串）
  • 默认包含：()、[]、{}、""、''、「」、『』、《》
  • 输入 " 会配对为 ""，不会自动转为 「」。如需 「」 配对，需手动修改 pairs 配置
  • 配置项：andrea.typeset.enableAutoPairs

5. 智能回车

  • 在引号或括号内按回车时，自动跳出并换行
  • 支持 MAIO 路由（Markdown / Auto-pair / Indent / Other）智能判断当前上下文
  • 配置项：andrea.typeset.enableSmartEnter

6. 跳出括号

  • 输入右括号时，如果光标右侧已有相同括号，则自动跳过而非重复插入
  • 配置项：andrea.typeset.enableSmartExit

7. 中文输入法修复

  • andrea.typeset.enableChineseIMEFix — 修复中文输入法与自动配对的冲突
  • andrea.typeset.chineseIMEDelay — 输入法修复延迟

8. 格式化文档

  • 命令："ANH: Format Document" — 一次性执行所有排版规则
  • 命令："ANH: Format Document (Auto add blank lines)" — 仅添加段间空行

快速设置面板

按 Ctrl+Alt+I 可打开快速设置面板，直接开关各项排版功能、调整空行数、切换缩进宽度等。快速设置面板还支持：

  • 字数单位切换（含标点/不含标点/非空白字符）
  • 粘贴计入统计开关
  • .wcignore 管理
  • 当前文章角色 / 全部角色显示配置，包括角色类型排序和自定义分组
  • 编辑器字体家族管理
  • 一键注入 Enter 按键绑定（覆盖 MAIO）

需要更完整的表单、实时预览、设置向导和数组/对象类配置编辑器时，可打开“图形化快速设置”。它会覆盖同一批高频设置，并额外提供自动补齐括号对、里程碑目标、角色类型排序、角色自定义分组等可视化编辑器。

状态栏配置

  • andrea.typeset.statusBar.compact — 紧凑模式
  • andrea.typeset.statusBar.alwaysShow — 始终显示
排版功能修改的是文本内容本身（而非仅显示效果），因此会影响 Git diff。建议在启用 Git 自动提交前确认排版规则符合你的写作习惯。
