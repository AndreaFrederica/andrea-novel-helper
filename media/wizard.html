欢迎

这个向导会像安装程序一样一步步完成项目初始化。你会先填写项目身份，再配置 Git，最后确认要创建的文件和忽略规则。

如果你不熟悉 Git，按默认推荐项继续即可。向导会在需要时提示你创建本机 Git 用户名和邮箱。

项目信息

这一步用于告诉 ANH 这个项目叫什么、作者是谁。信息会写入 anhproject.md，后续可在项目设置页修改。
支持换行、逗号、顿号、分号分隔。

项目配置

这些配置控制 ANH 如何识别和管理你的项目资源文件。所有项均可选——留空即使用下方显示的默认值。

默认写入目标

这些路径只影响"新增角色/词汇/敏感词/正则"命令默认写入到哪个文件，不是项目资源清单。

角色索引键

索引键用于在补全和角色查找中匹配角色。可填写后缀（如 日文）或完整键名（如 lookupKeys_jp）。

文件识别关键词

ANH 通过文件名关键词自动识别资源类型。如果你的文件命名不在默认识别范围内，可以在这里添加额外关键词。

Git 账户

Git 提交需要作者信息。如果系统里没有配置用户名和邮箱，建议在这里创建全局配置；这不是网页登录账号，只是本机 Git 作者名片。

Git 仓库

这里决定是否把当前文件夹交给 Git 管理。推荐初始化仓库并创建初始提交，之后每次重要改动都可以被追踪和回退。

项目文件

这一步会创建 ANH 推荐的基础结构和忽略规则。你可以先用默认设置，之后通过包管理器继续添加资源文件。

确认执行

请确认下面这些动作。点击"执行初始化"后，向导会写入项目配置文件，并执行你选择的 Git 操作。
