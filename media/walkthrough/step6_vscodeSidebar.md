# 认识 VS Code 侧边栏

VS Code 左侧有**活动栏**，每个图标对应一个功能面板。点击图标即可切换面板。

常用的面板有：

- **资源管理器** — 浏览项目文件和文件夹结构
- **搜索** — 在项目中搜索文件名或文件内容
- **源代码管理** — Git 版本控制，查看改动、提交代码
- **扩展** — 安装和管理 VS Code 扩展

> 写作时最常用的是**资源管理器**（管理文件）和**源代码管理**（Git 提交）。

点击下方按钮打开对应的面板试试看：

<button command="workbench.view.explorer">打开资源管理器</button>
<button command="workbench.view.search">打开搜索</button>
<button command="workbench.view.scm">打开源代码管理</button>
<button command="workbench.view.extensions">打开扩展</button>
