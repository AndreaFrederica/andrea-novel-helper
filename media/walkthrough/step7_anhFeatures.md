# ANH 功能入口

小说助手（ANH）在活动栏注册了多个侧边栏图标，每个图标打开一个独立的功能面板：

| 图标名称 | 说明 |
|---------|------|
| **小说助手:包管理器** | 管理角色、词汇、敏感词等资源文件，是核心入口。内含"当前文章角色"和"角色层级"标签页 |
| **小说助手:批注管理** | 管理写作批注和评论 |
| **小说助手:云同步** | 通过 WebDAV 同步项目文件 |
| **小说助手:脚本运行** | 运行自定义脚本和 MCP 服务器 |
| **小说助手:设置** | 调整 ANH 扩展的各项设置 |

> 在活动栏找到对应的 ANH 图标（通常在下方），点击即可打开对应面板。

除了侧边栏，还有几个重要的独立功能：

<button command="AndreaNovelHelper.showGuideDoc">打开文档中心</button>
<button command="andrea.openGraphicalQuickSettings">打开图形化快速设置</button>
<button command="AndreaNovelHelper.showGuide">打开功能引导</button>

> **文档中心**包含 ANH 所有功能的详细使用说明，遇到问题时可以在这里查阅。
