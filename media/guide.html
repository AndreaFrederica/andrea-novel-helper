功能引导

入门

👋
Hello World
5 分钟快速上手 ANH：初始化项目、创建角色、体验补全与高亮、预览文档。
🚀
项目初始化向导
一步步完成项目配置：填写项目信息、配置 Git、创建基础文件结构和忽略规则。
⚙
项目设置
编辑项目名称、作者、标签、封面、文件识别关键词、默认写入目标、角色索引键等配置。
⚙
插件设置
查看和修改 ANH 的所有配置项，包括校对、翻译、排版、字数统计、Git 等功能的详细参数。
⚙
快速设置
集中调整写作高频选项：自动换行、智能切段、段首缩进、字体、字数单位、.wcignore、角色显示、里程碑等。最快入口在底部状态栏的“版式”按钮。
▬
状态栏功能
说明 VS Code 底部 ANH 状态栏按钮：版式快速设置、写作统计、Typo、ANH:Sync、自动滚动、分组锁、Typst 预览等。
⚙
VS Code 基础
面向新用户说明资源管理器、全局搜索、Git 源代码管理、设置和常用快捷键。
📖
写作预览
侧边预览当前文档，支持 Markdown/TXT 纯文本预览和 Typst 专业排版预览，角色名自动着色。

核心概念

🧠
一切皆角色
ANH 的核心设计理念：角色、敏感词、词汇、正则都统一为"角色"对象，共享同一套编辑和引用能力。
📦
包管理器
侧栏中的资源管理器。"包"即 novel-helper/ 下的目录，每个目录可包含角色库、敏感词库、词汇表等资源文件。
📝
文件格式指南
Markdown、JSON5、OJSON5、RJSON5、TJSON5、CSV、TXT 的完整说明和模板。

角色与资源

🧑
角色管理
通过角色卡编辑器管理角色信息。支持 JSON5、CSV、Markdown 等格式。角色会在编辑器中自动高亮和补全。
在包管理器中右键文件夹可新建角色库
⚠
敏感词检测
定义敏感词库，编辑器会实时标记匹配的词汇。支持自定义严重级别、别名和修复建议。
在包管理器中右键文件夹可新建敏感词库
📚
词汇表
管理世界观术语和专业词汇。支持分类、别名、自动补全和高亮显示。
在包管理器中右键文件夹可新建词汇表
🎨
正则着色
用正则表达式定义自定义着色规则。可匹配对话、书名号、特殊标记等，用颜色直观区分文本类型。
在包管理器中右键文件夹可新建着色规则

写作辅助

⌨
角色补全
输入 @ 或角色名时自动弹出补全列表。支持拼音、别名、索引键匹配，快速插入角色名。
📝
字数统计
状态栏实时显示当前文件字数和写作速度。支持多种统计方式（含标点/不含标点/万字显示）。
⏱
写作时间统计
追踪写作时长和产出量，支持里程碑提醒（如达到 1 万字时通知）。可通过仪表板查看历史趋势。
🔍
校对与纠错
基于规则或 LLM 的错别字检测。支持自动扫描、角色名误报抑制、自定义服务端点。
🌐
翻译
右键选中文本即可翻译。支持中、英、日、德、法、韩等多种目标语言，结果可替换选区或复制。
📐
排版辅助
段落首行缩进、段间空行、智能引号补全、智能回车和跳出括号。底部工具栏可快速切换选项。
大纲
为每个章节和文件夹创建独立的故事大纲 Markdown 文件。同时打开目录大纲和文件大纲，方便规划情节和记录笔记。
📤
导出与复制
复制纯文本到剪贴板、导出 TXT 文件、使用 Typst 模板导出 PDF/PNG/SVG/HTML。支持从编辑器、资源管理器和字数统计视图导出。
📁
写作资源管理器
在 VS Code 资源管理器中显示当前文章角色和字数统计，在 ANH 侧栏中显示所有角色。帮助你快速浏览和管理写作资源。

高级功能

📂
外部资源目录
将工作区外的角色库、词汇表等目录挂载到 ANH 中统一管理，无需移动文件。
🔥
引用维护与热力图
用圆圈打包可视化展示角色出场次数分布，附带各章节出场趋势图。支持重建引用索引和清理过期路径。
🔀
Git 集成
推荐手动使用 Git 管理版本。ANH 提供 Git 身份配置向导、可选的自动提交功能和智能字数统计联动。
🤝
角色关系图
用可视化关系图管理角色之间的关系（亲属、敌对、同盟等）。支持自定义关系类型和方向。
在包管理器中右键文件夹可新建关系文件
🕒
时间线
管理故事中的事件时间线。按时间顺序排列事件，关联涉及的角色和地点。
在包管理器中右键文件夹可新建时间线
⚡
脚本运行时
在 ANH 中运行自定义 JS/TS 脚本，支持 MCP 服务器集成和丰富的运行时上下文注入。
☁
WebDAV 同步
通过 WebDAV 协议同步项目文件到云端，支持多设备协作。可配置同步策略和自动同步间隔。
