# 🎭 随机生成角色功能

## 功能概述

新增的随机生成角色功能提供了一个完整的工作流程，从选择风格到创建角色文件，为小说创作提供便捷的角色命名和创建工具。

## 使用方法

### 方法1：右键菜单（推荐）
在任何编辑器中右键，选择 "🎲 随机生成角色"

### 方法2：命令面板
1. 按 `Ctrl+Shift+P` 打开命令面板
2. 输入 "随机生成角色" 并选择执行

## 工作流程

### 步骤 1/5：选择文化背景
- **中文（简体）** - 生成中文名字
- **英文（美国）** - 生成英文名字
- **日本語** - 生成日语名字
- **奇幻风格** - 生成奇幻风格名字

### 步骤 2/5：选择性别
- **男性** - 生成男性名字
- **女性** - 生成女性名字
- **中性** - 生成中性名字
- **随机** - 随机选择性别

### 步骤 3/5：选择风格
根据选择的文化背景，提供相应的风格选项：
- 中文：现代、经典、奇幻、历史
- 英文：现代、经典、奇幻、科幻
- 日语：现代、经典、奇幻、历史
- 奇幻：奇幻、高等奇幻、黑暗奇幻

### 步骤 4/5：生成并选择名字
- 系统自动生成10个候选名字
- 可以选择 "🎲 重新生成" 获取新的名字列表
- 选择 "📝 从名字列表选择" 进入详细选择界面

### 步骤 5/5：配置角色信息
- 选择角色类型：主角、配角、联动角色
- 输入从属标签（可选）
- 输入角色简介（默认自动生成）
- 输入角色颜色（可选）

## 特性亮点

### 🌍 多语言支持
- **中文**：王、李、张等姓氏 + 伟、强、芳、娜等名字
- **英文**：John、Mary、Michael、Sarah 等经典英文名
- **日语**：佐藤、鈴木等姓氏 + 誠、美咲、翔太等名字
- **奇幻**：Alariel、Morgrath、Galethion 等奇幻风格名字

### 🎯 智能过滤
- 支持性别筛选
- 支持文化背景选择
- 支持风格定制
- 支持重新生成

### 📝 无缝集成
- 复用现有的角色文件管理系统
- 自动刷新角色库和装饰
- 支持 JSON5 和 Markdown 格式
- 遵循现有项目结构

### 🎨 完整信息
- 自动生成角色UUID
- 包含性别、文化背景信息
- 添加生成元数据
- 支持自定义属性

## 示例输出

生成的角色文件将包含：
```json5
{
  name: "李明",
  type: "主角",
  uuid: "a1b2c3d4-e5f6-4g7h-8i9j-k0l1m2n3o4p5",
  gender: "male",
  description: "李明 - Chinese (Faker)",
  origin: "Andrea Novel Helper - 随机生成",
}
```

### 架构设计

- 模块化设计便于维护

## 故障排除

### 常见问题
1. **找不到角色目录** - 系统会自动提示创建
2. **名字不符合预期** - 可以重新生成或调整选择
3. **文件创建失败** - 检查工作区权限和磁盘空间

### 技术支持
如果遇到问题，请检查：
1. 工作区是否正确打开
2. 是否有文件写入权限
3. 扩展是否正常激活
