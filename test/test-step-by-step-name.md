# 分步姓名生成功能测试（支持复合文化姓名）

这是一个测试文档，用于验证新增的分步随机姓名生成功能，特别是复合文化姓名生成。

## 🎯 核心功能

### 1. **灵活的生成顺序**：
- 先随机姓氏，再随机名字
- 先随机名字，再随机姓氏
- 输入自定义姓氏，然后随机名字
- 输入自定义名字，然后随机姓氏

### 2. **🌏 复合文化姓名支持**：
- ✨ **新增功能**：为姓氏和名字选择不同的文化背景
- 🔗 支持文化混合，如：日文姓氏 + 英文名字 = "御門マリア"
- 🧠 智能LLM映射：将复合姓名映射回目标文化背景

### 3. **支持的丰富文化背景**：
- 中文（简体/繁体）：张三、李四
- 英文：John Smith、Mary Johnson
- 日文：佐藤誠、鈴木恵子
- 韩文：김철수、이영희
- 法文、德文、西班牙文等
- 奇幻风格

### 4. **🔀 智能组合逻辑**：
- 根据姓氏文化背景决定组合方式
- 东方文化：姓 + 名（御門マリア）
- 西方文化：名 + 姓（Maria Smith）

### 5. **🤖 LLM文化映射**：
- 自动将复合姓名适配目标文化
- 保持姓名识别度和记忆点
- 示例：御門マリア → 御门玛丽/御门玛利亚

## 📋 测试步骤

### 基础测试：
1. 在编辑器中右键，选择"分步生成角色（姓氏+名字）"
2. 或通过命令面板（Ctrl+Shift+P）搜索"分步生成角色"

### 复合文化姓名测试：
1. 选择"为姓氏和名字选择不同文化背景"
2. 姓氏选择日文，名字选择英文
3. 期望结果：类似"御門マリア"的复合姓名
4. LLM映射：可选择映射为中文风格的姓名

## 💡 使用示例

### 复合文化姓名示例：
- **日文姓氏 + 英文名字**：御門マリア、高橋John
- **中文姓氏 + 韩文名字**：李철수、王영희
- **英文姓氏 + 日文名字**：Smith誠、Johnson恵子

### LLM映射示例：
- 御門マリア → 御门玛丽
- 李John → 李约翰
- Smith明 → 史密斯明

- ✅ 支持复合文化姓名，创造独特角色
- ✅ 智能文化适配，保持姓名合理性
- ✅ 支持翻译别名和双语显示
- ✅ 可插入到文档或创建角色文件
