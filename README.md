## 📖 简介

一个围绕"设定集 / 资料集"组织写作资产的 VS Code 小说写作增强扩展。核心理念：把你的世界观、角色、敏感词、专业词汇、正则高亮规则和章节文件放进一个"包"（Package），由"包管理器"统一可视化管理与快速生成。
